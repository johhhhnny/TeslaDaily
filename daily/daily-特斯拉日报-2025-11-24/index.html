2025-11-24 特斯拉日报

  • FSD全球进展： 埃隆·马斯克就FSD授权向传统车企发出严厉警告；FSD (Supervised) v14.1.4已在韩国推出；在荷兰获得欧洲首次FSD批准的目标日期为2026年2月，但荷兰监管机构RDW澄清为演示日期，而非保证批准；特斯拉在内华达州获得自动驾驶运营许可，正推进Robotaxi商业化。
  • AI芯片： 特斯拉AI5芯片即将流片，AI6芯片已启动研发。
  • 制造与效率： Model X通过数百项改进，成功减重近400磅。
  • 充电网络： 超级充电站导航系统因用户反馈，已撤回一项名称显示更新，并计划在12月进一步优化。
  • 能源业务： TagEnergy将在澳大利亚Golden Plains风电场部署168台Tesla Megapack 2 XL，总容量达150MW/600MWh。
  • 市场表现： 特斯拉在挪威市场接近打破大众汽车的历史年度销量纪录；在瑞典市场则面临销量下滑和工会抗议挑战。
  • 服务拓展： 特斯拉租赁计划在美国多个州扩展，提供无限里程、FSD和免费超充。
  • 新应用： 拉斯维加斯警方正式启用10辆改装版Cybertruck作为警用车辆。
  • 法律诉讼： 一个华盛顿家庭就2018年一起涉及“突然意外加速”的Model 3致命事故对特斯拉提起诉讼。

技术进展

FSD许可与行业格局 特斯拉首席执行官埃隆·马斯克近日在社交平台X上向传统汽车制造商发出严厉警告，指出他们目前不愿授权特斯拉的完全自动驾驶（FSD）系统，或提出了不切实际的合作条件。马斯克将此比作传统车企在电动车转型初期行动迟缓，最终被市场边缘化的历史重演，强调若现在忽视FSD，未来将付出惨重代价。Melius Research分析师Rob Wertheimer在一份报告中指出，自动驾驶是一个价值7万亿美元的巨大市场，特斯拉凭借其在FSD领域的领先地位，预计将在未来几年内捕获数千亿美元的价值，并认为特斯拉将是这一领域唯一的真正赢家。目前，FSD (Supervised) v14版本已在小部分用户中试用，分析师预测其广泛推出将“震惊大多数人”，并指出特斯拉庞大的数据池、2021-2022年转向端到端神经网络以及即将推出的AI5芯片是其技术领先的关键。

  • 判断/建议： 特斯拉对FSD技术抱有极强的信心，并将其视为重塑汽车行业和未来出行服务模式的核心。传统车企的观望态度可能使其错失战略合作的良机，进一步拉大与特斯拉在软件定义汽车时代的差距。FSD的外部授权进展虽然缓慢，但其市场价值和颠覆潜力正被华尔街认可，建议投资者持续关注其技术成熟度和商业模式的推广。

FSD全球部署与区域进展 特斯拉正在加速FSD (Supervised)在全球范围内的部署，近期已在韩国正式推出v14.1.4版本，使其成为FSD可用的第七个国家，目前该版本主要面向配备Hardware 4 (HW4/AI4) 的Model S和Model X车型。在欧洲市场，特斯拉正积极与监管机构合作，目标是争取在2026年2月在荷兰率先获得国家批准，从而为FSD在整个欧洲大陆的推广铺平道路。为此，特斯拉已投入超过12个月时间，在17个欧洲国家进行了超过100万公里的内部FSD测试，并提交了详细的安全报告数据。然而，荷兰车辆批准机构RDW随后澄清，2026年2月是特斯拉演示FSD合规性的目标日期，并非批准承诺，并强调交通安全是其首要考量，请求公众停止通过联系他们来施压。在美国市场，特斯拉也取得了重要进展，已正式完成内华达州的自动驾驶车辆运营自认证程序，获准在该州公共道路上部署和运营自驾车辆，下一步将是申请内华达州交通管理局的许可，以启动商业Robotaxi服务，这也反映了特斯拉今年在多州扩展Robotaxi的积极时间表。

  • 判断/建议： 特斯拉FSD的全球扩张战略持续推进，新市场（如韩国）的开放为其积累了更多实际路况数据，进一步强化了其“训练一次，部署 anywhere”的愿景。然而，欧洲市场的监管复杂性仍是其主要挑战，需要特斯拉投入更多精力和时间去适应当地法规并建立信任。内华达州的运营许可是Robotaxi商业化的关键一步，未来若能获得商业牌照，将为公司带来新的收入增长点和市场想象空间。

AI芯片研发迭代 特斯拉首席执行官埃隆·马斯克确认，公司正接近其AI5芯片的“流片”阶段，同时已着手开发其下一代AI6芯片。在半导体行业中，“流片”意味着芯片设计已最终确定并提交制造商进行物理生产。特斯拉的目标是每12个月推出一代新的AI芯片设计并实现量产，以维持其在人工智能硬件领域的领先地位。目前，特斯拉车辆中搭载的最新版本是AI4芯片。马斯克强调，较早的AI3（Hardware 3）芯片在2019年推出后，已难以满足FSD v12及后续版本中愈发复杂的端到端AI神经网络的计算需求，因此先进的FSD功能已限制在搭载AI4的车辆上。特斯拉的AI芯片和电路板工程团队已存在多年，并已设计和部署了数百万颗AI芯片在车载和数据中心中，这正是特斯拉在真实世界AI领域保持领先的核心所在。

  • 判断/建议： 特斯拉自研AI芯片的快速迭代是其自动驾驶技术持续突破和性能提升的关键驱动力。这种软硬件垂直整合的策略，使其能够针对FSD的计算需求进行深度优化，从而在AI领域形成独特的竞争优势。投资者应关注AI5芯片的量产时间表及其对FSD功能增强的实际影响，这对于特斯拉未来实现完全自动驾驶和Robotaxi愿景至关重要。

工厂与制造

Model X轻量化 特斯拉在车辆工程方面持续追求效率，其副总裁Lars Moravy透露，公司在多年间成功地将Model X的重量减少了近400磅（约181公斤），同时保持了车辆的性能、续航能力和安全性。这一显著的减重并非源于某一次大规模的重新设计，而是通过数百项小型改进累积实现的。例如，在动力总成方面，将后部感应电机替换为永磁设计，并优化半轴，单独节省了约100磅。电池组也进行了重大改进，通过使用更密集的电芯、垂直排列的模块、减少约300个电芯以及结构优化，减重约90磅。内饰方面，通过更新部件、采用新的制造技术、将安全气囊集成到顶棚织物中以及调整座椅配置，也成功减重约80磅。甚至连高压系统布线也通过优化并用铝替代铜，减轻了约44磅，同时冷却系统也简化了30磅。此外，采用新的、更大的前后一体压铸件也减少了零件复杂性并为减重做出贡献。Moravy强调，“质量就是一切”，减重对车辆的安全性、效率、NVH（噪音、振动、声振粗糙度）、能耗和成本等所有方面都至关重要。

  • 判断/建议： 特斯拉在Model X上的大规模轻量化努力，展现了其在工程设计和制造工艺上的深厚实力。这种对细节的极致追求，不仅直接提升了车辆的能效和续航，也为降低生产成本和提升驾驶体验奠定了基础。未来，这一“千刀万剐”式的减重策略，有望推广至更多车型，进一步巩固特斯拉在电动车效率方面的领先地位。

充电与能源

超级充电网络导航系统更新 特斯拉最近对其车载导航系统进行了一项调整，将途经的超级充电站的城市或州名称替换为仅显示商家名称，此举引发了大量车主的抱怨和困惑，尤其是在长途旅行规划中难以识别充电地点。特斯拉超级充电总监Max de Zegher迅速回应，承认这是一次“重大失误”，并表示已在24小时内迅速部署修复。这项修复通过API更新，无需软件版本更新，即可将导航显示恢复到车主熟悉的城市/城镇格式，确保即将到来的假期旅行季的导航体验。特斯拉还计划在12月进行进一步改进，届时导航系统将同时显示充电站的常用名称/设施信息以及具体的街道和城市名称，以提供更全面、清晰的导航指引。

  • 判断/建议： 特斯拉对用户反馈的快速响应和问题纠正能力，体现了其以客户为中心的敏捷运营模式，有效避免了用户体验的长期负面影响。未来导航系统的优化将进一步提升超级充电站的使用便利性，有助于巩固其在全球充电网络中的优势。

Megapack储能项目在澳部署 特斯拉的电网级储能业务持续在全球扩张，TagEnergy公司确认将在澳大利亚维多利亚州的Golden Plains风力发电场部署168台Tesla Megapack 2 XL电池系统。该项目将成为南半球最大的风电和电池组合装置之一，其电池储能系统（BESS）将拥有150兆瓦（MW）的功率容量和600兆瓦时（MWh）的总储能容量，提供四小时的持续供电，旨在支持维多利亚州的傍晚用电高峰需求。Golden Plains风电场预计在2027年中期全面建成，总发电容量将达到1,333兆瓦，可满足维多利亚州约9%的用电需求。特斯拉的Megapack 2 XL不仅提供电池储能，还将通过其电网形成逆变器技术，主动支持电网稳定性、频率控制和电压支持，这对于高可再生能源渗透率的地区至关重要。该电池设施预计明年初动工，目标于2027年中期投入运营。

  • 判断/建议： 特斯拉Megapack在大型可再生能源项目中的持续部署，彰显了其在电网规模储能解决方案领域的领先地位和技术实力，特别是在电网稳定性方面的贡献。这一项目的成功实施将进一步巩固特斯拉在能源转型中的核心地位，并有望成为其新的重要增长引擎。

市场与交付

挪威销量创新高与瑞典市场挑战 特斯拉在挪威市场正逼近其历史性的里程碑，有望打破大众汽车于2016年创下的年度销量纪录（26,572辆）。截至今年目前，特斯拉在挪威已售出26,127辆（不含13辆进口Cybertruck），仅11月就交付了3,732辆，使其有望成为挪威现代汽车史上最成功的汽车品牌之一。这种强劲的需求增长，部分原因在于消费者试图赶在电动车增值税新政生效之前购车，新政实施后畅销的Model Y价格可能上涨5万挪威克朗。然而，特斯拉在瑞典市场则面临截然不同的局面，今年注册量同比大幅下降68%，迄今仅有6,147辆，11月仅交付了291辆。瑞典市场持续受到工会抗议和封锁行动的影响，尽管面临巨大压力，特斯拉瑞典公司仍坚持其立场，拒绝与瑞典工会签署集体协议。

  • 判断/建议： 挪威市场的卓越表现再次证明了特斯拉在电动化程度高、政策支持强劲的市场中具备强大竞争力。但即将生效的增值税变化可能在短期内对挪威销量造成波动。瑞典市场的困境则凸显了特斯拉在欧洲扩张中面临的独特劳工关系和文化挑战，如何有效应对这些非市场因素，将是其在欧洲长期发展的关键。

特斯拉租赁计划拓展 特斯拉正积极扩大其内部车辆租赁计划，继最初在加州成功试点后，现已扩展至德克萨斯州、马萨诸塞州、田纳西州和亚利桑那州等多个主要城市。该计划招聘“租赁准备专员”，提供结合传统租赁与延长试驾的混合模式。其日租价格具有竞争力，Model 3和Model Y为60美元/天，Cybertruck为75美元/天，Model S和Model X为90美元/天。所有租赁均包含无限里程、FSD (Supervised)功能和免费超级充电等额外福利。尽管该计划功能齐全，但其核心定位是销售工具，提供最长7天的租赁期，如果客户在还车后7天内购买特斯拉车辆，将获得250美元的抵扣，相当于一次短期租赁的净折扣。此举旨在通过提供更长时间的FSD体验，提高FSD的购买率，因为短时间的试驾通常不足以让客户充分信任和体验FSD。

  • 判断/建议： 特斯拉的租赁计划是一项创新的营销策略，旨在通过降低体验门槛来提高FSD的普及率和车辆的销售转化率。提供无限里程和免费超充等优惠，增强了其对潜在买家的吸引力。然而，租赁范围仅限于提车州的限制，可能会影响其作为传统长途租赁服务的竞争力，但作为试驾和销售工具，其潜力巨大。

其他值得一提

Cybertruck警用车辆亮相 拉斯维加斯都会警察局（LVMPD）近日发布了其由10辆特斯拉Cybertruck组成的警用巡逻车队，标志着警务领域的独特未来。警长Kevin McMahill高度赞扬了这支技术先进的车队，称其实现了警务的“更安全、更智能、零排放”目标。这些Cybertruck并非直接作为原厂车辆投入使用，而是通过第三方捐赠并与Unplugged Performance公司的UP.FIT Tactical项目合作，进行了专业改装以满足警用需求。报道指出，标准版Cybertruck在座椅设计（需适应警员佩戴厚重装备）、车载办公设备（如笔记本电脑、电台）的固定安装以及武器锁等关键警用设备集成方面存在挑战，因此UP.FIT的改装至关重要。

  • 判断/建议： Cybertruck作为警用车辆的部署，展示了其在公共服务领域的多功能性和未来潜力，有助于提升特斯拉在政府和特殊用途车队市场的影响力。然而，这也表明特斯拉在进入特定行业应用时，需要依赖专业的第三方改装解决方案，以满足严格且独特的行业标准和操作需求。

2018年Model 3致命事故诉讼 一个华盛顿家庭已对特斯拉提起诉讼，指控其在2018年因Model 3的“突然意外加速”（Sudden Uncommanded Acceleration）导致一起致命车祸。诉讼称，车辆在没有警告的情况下突然以最大功率加速数秒，导致驾驶员为避让交通而失控撞上电线杆。事故发生时，紧急制动系统未能启动，车辆在撞击后起火，且因电池断电，旁观者无法打开车门救出被困人员。事故造成妻子当场死亡，丈夫严重烧伤和多处创伤。该诉讼指控特斯拉存在过失，并寻求赔偿金和惩罚性赔偿。特斯拉目前尚未对此诉讼作出回应。

  • 判断/建议： 这起追溯至2018年的诉讼再次将特斯拉车辆的“意外加速”问题推向公众视野，尽管特斯拉通常将此类事件归因于驾驶员误操作，但持续的法律挑战可能对公司的品牌声誉和潜在的法律风险构成影响。此次诉讼的进展和最终判决，将对消费者对自动驾驶辅助系统的信任以及未来的行业标准产生深远影响。
