技术进展

1. MotorTrend将特斯拉FSD (Supervised) 评为2026年最佳驾驶辅助系统

权威汽车杂志MotorTrend在2026年MotorTrend最佳科技奖评选中，将特斯拉的Full Self-Driving (Supervised) V14版本评为“最佳驾驶辅助系统”，并直言竞争对手“毫无可比性”。该杂志表示，经过多年对特斯拉自动驾驶技术的批评，FSD V14已使其“转变为信徒”，实现了从车道到停车位的全程“无需手扶”导航体验，同时确保驾驶员注意力集中于道路。这一评价标志着FSD取得了重大进展，一年前它还被通用汽车的Super Cruise超越，当时编辑们对其不可预测的行为、不必要的变道和突然刹车表示担忧。FSD的独特之处在于其纯视觉系统，能够在城市街道、高速公路和双车道等几乎所有道路上运行，提供其他系统无法比拟的地理自由度。用户体验方面，FSD可通过触摸屏简单激活，系统自行处理转向、刹车和加速，并能学习常用路线。

  • 判断/建议： 这是特斯拉FSD获得的里程碑式认可，显著提升了其在行业中的地位和消费者信心。V14版本的优化证明了特斯拉纯视觉路径的潜力，预计将加速FSD在全球范围内的推广和采纳。

2. 特斯拉FSD 100亿英里目标及推理能力确认

埃隆·马斯克在社交媒体X上更新了实现无人监督FSD（Full Self-Driving）“超人级安全”所需的训练数据目标，从最初《总体规划第二部分》中提及的60亿英里提高到了100亿英里的真实世界驾驶数据。这一调整反映了实现极致自动化所面临的“复杂性的长尾效应”，即解决最后几个百分点的极端情况难度呈指数级增长。同时，特斯拉AI总监Ashok Elluswamy确认，FSD已经集成了“推理能力”，这是AI决策的核心能力，并计划在未来版本中进一步增强。目前，特斯拉FSD车队已累计行驶约71亿英里，相较于2025年3月的36亿英里增长显著。按照当前速度，特斯拉有望在未来六个月内达成100亿英里的目标。

  • 判断/建议： 马斯克提高数据目标表明他对FSD的严谨性和对“超人级安全”的追求。尽管目标更具挑战性，但FSD推理能力的集成和快速积累的里程数，预示着特斯拉在自动驾驶领域仍保持领先，市场应关注其技术迭代和里程碑达成情况。

3. 梅赛德斯-奔驰放弃L3级自动驾驶“Drive Pilot”

梅赛德斯-奔驰正在调整其自动驾驶战略，确认其即将于1月29日首次亮相的S级改款车型和今年晚些时候更新的EQS将不再提供其备受关注的L3级“Drive Pilot”系统。该系统曾被誉为全球首个获批的“手眼皆离”驾驶技术，但在实际应用中，其功能受限于特定的加州和内华达州高速公路、良好的天气条件以及需要前方有车辆等狭窄条件。一旦条件变化，驾驶员必须在10秒内接管。据德国媒体Handelsblatt报道，梅赛德斯认为该系统的高昂成本和有限需求不值得继续投入。公司正转向名为MB.Drive Assist Pro的L2++级系统，其功能与特斯拉的FSD (Supervised) 类似，可在多种场景下辅助驾驶，但要求驾驶员始终保持警觉并准备接管。

  • 判断/建议： 梅赛德斯-奔驰的这一举动突显了实现真正L3级自动驾驶在技术复杂性、法规限制和商业可行性方面面临的巨大挑战。这间接验证了特斯拉专注于L2++级（FSD Supervised）并逐步迭代至更高级别的策略，即在保障安全和责任明确的前提下，追求广泛可用性，为行业提供了一条更务实的路径。

4. 特斯拉Robovan的首个实际应用场景公布

Boring Company总裁史蒂夫·戴维斯透露了特斯拉Robovan最有前景的首个实际应用场景：在拉斯维加斯的大型活动期间，如比赛日和大型演出，疏导大量人流。他表示，一旦Vegas Loop系统扩展到拉斯维加斯大道和市中心，车队规模达到约1200辆特斯拉，Robovan将主要用于可预测的客流高峰期，高效地将大量乘客运送到同一目的地。戴维斯解释说，当需要运送四名乘客及以上且目的地集中时，Robovan比小型车辆更具优势。目前，Vegas Loop的机场服务一期已于上月启动，二期（2.2英里双向隧道）预计在数月内开通，届时车队将增至约160辆。

  • 判断/建议： 为Robovan规划在受控环境下的高密度人流运输场景，是特斯拉将其机器人技术商业化的一个明智且务实的策略。这不仅能有效缓解城市交通压力，也为Robovan积累宝贵的运行经验，为未来更广泛的应用奠定基础，同时与Boring Company的隧道网络形成协同效应。

5. 特斯拉Cybercab“故障”照片系正常预生产测试

近日，一张特斯拉Cybercab被装载到拖车上的照片在网络上流传，引发了关于其是否发生“故障”的猜测。然而，Teslarati分析指出，这很可能属于Cybercab预生产测试阶段的正常情况。Cybercab目前正在进行一系列严格的测试场景，包括续航里程测试和常规公共道路运行，以在正式投产前发现并解决潜在问题。此前，特斯拉Semi电动卡车在三年前的测试阶段也曾出现过类似“路边抛锚”的照片，但该车型后来在早期试点项目中取得了成功。虽然特斯拉官方尚未就此次Cybercab事件发表评论，但此类测试阶段的“故障”被视为建设性的，有助于在车辆投入大规模生产和Robotaxi平台运营前，确保其可靠性和安全性。

  • 判断/建议： 鉴于Cybercab正处于严格的预生产测试阶段，任何所谓的“故障”都应被视为研发过程中的正常环节，而非产品缺陷的早期信号。投资者和公众应关注其整体测试进展和最终表现，而非单一事件，这恰恰是确保产品质量和安全性的必要步骤。

6. Motional Robotaxi重新定位，聚焦AI并在2026年推出无人驾驶服务

在经历近两年的战略调整和挑战后，Motional（现代汽车集团与Aptiv的合资企业）宣布重启其Robotaxi计划，并将其无人驾驶系统全面转向“AI优先”方法，目标在2026年底前于拉斯维加斯推出商业无人驾驶服务。该公司曾错过了与Lyft合作推出无人驾驶服务的最后期限，Aptiv也撤回了资金支持，导致现代汽车不得不追加10亿美元投资以维持运营，并于2024年5月进行了40%的大规模裁员。Motional目前正在从传统的机器人技术和基于规则的方法转向基于AI基础模型的开发。他们已向员工提供带有安全员的Robotaxi服务，计划在今年晚些时候向公众推出，并在年底前实现完全无人驾驶。

  • 判断/建议： Motional的转型反映了自动驾驶行业对AI基础模型日益增长的共识，以及对实现可扩展和通用化解决方案的需求。其过往的挫折也凸显了部署无人驾驶服务的固有难度。这一进展表明，尽管竞争激烈且挑战重重，Robotaxi领域仍在加速发展，对特斯拉而言，这意味着需要持续创新以保持其领先地位。

充电与能源

1. 加拿大最大的特斯拉超级充电站即将开放

特斯拉在加拿大最大的超级充电站即将投入运营。经过数月的等待，位于安大略省Ajax的44个V3充电桩超级充电站定于2026年1月23日正式开放，这将极大地提升大多伦多地区的特斯拉充电基础设施能力。该站点于2025年5月破土动工，历经近八个月的建设。建成后，它将超越不列颠哥伦比亚省里士满的40个充电桩站点，成为加拿大规模最大的超级充电站。Ajax超级充电站地理位置优越，位于Durham Centre，邻近Kingston路和Harwood大道的东北角，距离401号高速公路的Westney路和Salem路出入口仅五分钟车程，方便过往车辆。该充电站周围拥有丰富的零售和餐饮设施，如星巴克、Five Guys Burgers等，为充电等待的司机提供了便利。

  • 判断/建议： 这一大型充电站的开放是特斯拉在加拿大关键市场的重要基础设施升级，能够有效缓解高峰期的充电拥堵，提升用户体验。其战略性选址和V3技术将进一步支持电动车普及，降低用户的里程焦虑。

2. 特斯拉“企业品牌超级充电站”项目持续扩张

特斯拉正在扩大其去年推出的“企业品牌超级充电站”计划，吸引更多企业利用该平台为电动车主提供充电服务并进行独特的广告宣传。俄克拉荷马州的Francis Energy公司正计划在诺曼地区（俄克拉荷马大学所在地）启动首批四个带有Francis Energy品牌标识的超级充电站，预计明天正式开放。该项目于去年9月初启动，旨在允许企业购买并安装超级充电桩，以自定义费率提供电动车充电服务。这不仅能为企业带来客流量，也为特斯拉扩展充电网络、鼓励更多人购买电动车提供了创新途径。Francis Energy已表示，这并非其计划开设的最后一个超级充电站地点。

  • 判断/建议： “企业品牌超级充电站”项目是一个双赢的创新模式，它不仅为特斯拉快速扩展充电基础设施提供了新的资金和地点来源，也为合作企业提供了吸引EV用户和进行品牌推广的独特机会。此举将进一步加速电动汽车的普及，同时为特斯拉带来多元化的合作收入。

3. 特斯拉推出新型太阳能电池板，效率与外观俱佳

特斯拉终于重新激活其太阳能业务，并已开始交付经过全面重新设计的住宅太阳能电池板。这款新型420瓦电池板在Giga New York生产，模块效率达到20.5%，更重要的是，它优先考虑了美观性和遮荫容忍度。新面板采用全黑饰面和更厚的建筑级框架，呈现统一的哑光黑色外观。此外，新的隐藏式安装系统采用无导轨硬件，使面板仅高出屋顶1.57英寸，比旧系统低3英寸，实现了更平滑的集成效果，弥补了传统太阳能和特斯拉太阳能屋顶之间的美学鸿沟。其最具创新性的特点是拥有18个独立电源区，即使面板一小部分被遮挡，其余区域仍能以最高效率发电，显著提高了实际日常发电量。

  • 判断/建议： 这次升级是对特斯拉住宅太阳能产品线的重大提升，解决了消费者长期以来关注的美观和实际发电效率痛点。通过技术创新和设计优化，特斯拉有望在竞争激烈的住宅太阳能市场中重新获得增长动力，并与Powerwall等储能产品形成更强的生态协同。

市场与交付

1. 中国Model Y获批黑色外观套件和深色轮毂，高性能版上市铺路

特斯拉已在中国正式获得监管批准，为其Model Y车型推出全新的黑色外观套件。这些文件显示，特斯拉现在可以为Model Y配备黑色前后品牌标识，此前已获批黑色侧视镜盖，至此完成了全套工厂认证的黑色外部装饰。与北美市场特斯拉已转向无徽章前脸不同，中国市场的特斯拉车辆仍使用前后标识，因此此次批准意味着中国市场Model Y上的所有可见徽章都可采用黑色涂装。此外，文件还确认批准了全新的深色20英寸Helix 2.0轮毂设计，取代了之前提供的较浅银色版本，与黑色后视镜和黑色徽章搭配时，Model Y将呈现出更具凝聚力的深色外观。此举被认为已为Model Y高性能版在中国市场上市清除了监管障碍，目前中国市场提供后驱、长续航后驱、长续航全驱和Model Y L等版本。车辆仍由上海超级工厂生产，电池主要由宁德时代、亿纬锂能和爱尔集新能源等中国主要制造商提供。

  • 判断/建议： 这一更新对中国市场消费者而言，意味着Model Y将拥有更具运动感和高级感的选择。对于特斯拉来说，在竞争激烈的中国电动汽车市场中，通过设计更新保持产品视觉竞争力至关重要，此举也将有助于进一步提升Model Y的吸引力和潜在市场份额。

2. 特斯拉加速欧洲扩张：进军爱沙尼亚和拉脱维亚

特斯拉正加速其在欧洲的区域扩张步伐，继近期在立陶宛成功启动业务后，最新的报告显示特斯拉已通过注册新子公司的方式，向爱沙尼亚和拉脱维亚市场迈进。根据企业备案信息，特斯拉分别于2025年11月7日在拉脱维亚注册了Tesla Latvia SIA，并于12月16日在爱沙尼亚注册了Tesla Estonia OÜ，两家实体均由Tesla International B.V.所有。值得注意的是，这些实体注册的业务范围主要是“汽车维修和保养”，而非直接的车辆销售，这暗示特斯拉可能会优先在这两国设立服务中心，以支持其在当地的运营。这一策略与特斯拉在立陶宛的扩张模式相似，即先设立实体、继而开设临时门店，并在数月后建立永久性服务中心。预计2026年上半年，爱沙尼亚和拉脱维亚也将迎来特斯拉的服务和零售业务。

  • 判断/建议： 此次扩张是特斯拉深耕欧洲市场的重要一步，尤其是在其2025年欧洲销量有所下滑的背景下。通过先期布局服务网络，特斯拉能够为现有和潜在客户提供更完善的支持，从而为Model 3和Model Y标准版等更具性价比车型的销售铺平道路，预计将有助于提振其在欧洲的整体市场表现。

3. 特斯拉中国2025年销量回顾：全年下降但12月创纪录

2025年，特斯拉在中国市场的本土零售销量达到625,698辆，同比下降4.8%，低于2024年的657,102辆。这导致特斯拉在中国新能源汽车市场的份额从2024年的6.0%（排名第三）下滑至2025年的4.9%（排名第五）。销量下滑的主要原因之一是2025年第一季度Model Y车型换代导致上海超级工厂的生产暂停，影响了年初的车辆供应。此外，上海超级工厂的出口量也同比下降近13%至226,034辆。尽管全年表现有所收缩，特斯拉在2025年12月却实现了创纪录的国内销量，达到93,843辆，同比增长13.2%，环比增长28.3%，创下月度新高。这一年末冲刺部分得益于特斯拉优先保障国内交付，以便购车者享受有利的购置税政策。

  • 判断/建议： 尽管2025年全年销量下滑，但特斯拉中国在年底的强劲表现展示了其市场韧性与调控能力。销量下降主要受Model Y生产线调整的短期影响，随着新版Model Y的稳定生产和更多定制化选项的推出，预计2026年特斯拉在中国的市场份额有望回升，并将在激烈的竞争中继续保持其核心竞争力。

4. 特斯拉在加拿大和欧洲推出Model Y新版本

特斯拉上周在两大洲同步更新了Model Y产品线，继续向更多市场扩展经济实惠的“Standard”版本。在加拿大，特斯拉正式推出Model Y Standard版，起售价仅为49,990加元，成功打破了加拿大电动车定价的关键点，使其比福特Mach E便宜约3000加元，仅比起亚EV6贵1000加元。为规避中国制造电动车可能面临的100%关税，加拿大市场的Model Y Standard将从柏林超级工厂进口，确保其价格竞争力并符合省级激励政策。该版本内饰简化，包括织物座椅、7扬声器音响、手动方向盘调节，并取消了后排屏幕、氛围灯和直接式胎压监测系统，同时仅提供交通感知巡航控制（TACC），不含Autopilot功能。而在欧洲，特斯拉推出了Model Y Standard Long Range版本，将Model Y Premium的更大电池容量与Standard版的轻量化和简化配置相结合，以实现卓越的续航里程，满足欧洲市场对长续航和商业用途的需求。

  • 判断/建议： 特斯拉针对加拿大和欧洲市场推出的Model Y新版本，是其灵活调整产品策略以适应地区性价格敏感度和特定需求的体现。加拿大版的低价策略有望显著提升市场竞争力，而欧洲版的长续航特性则能满足更广泛的用户群体，这将有助于特斯拉在全球范围内扩大Model Y的销量和市场渗透率。

其他值得一提

1. SpaceX赢得7.39亿美元五角大楼卫星发射合同

SpaceX再次获得美国政府的重大合同，获得了美国国防部价值7.39亿美元的新发射合同，将在未来几年内向轨道发射新一代军事卫星。美国太空部队周五宣布，SpaceX赢得了国家安全太空发射第三阶段第一车道任务的所有九项任务订单，未与任何竞争对手分享合同，实现了埃隆·马斯克旗下航天公司的“大满贯”。这些发射任务将支持太空发展局（Space Development Agency）和国家侦察办公室（National Reconnaissance Office）的行动，这两个机构是保护和监测美国国家安全的关键组织。这些任务的重点是建立新一代导弹预警和跟踪卫星网络，采用大量小型低地球轨道卫星，以实现更快速、更精确、更具弹性的威胁跟踪能力。

  • 判断/建议： 这份巨额合同巩固了SpaceX在美国军事发射领域的绝对主导地位，突显了其火箭技术和发射服务的可靠性及成本优势。对于埃隆·马斯克的商业帝国而言，这不仅是一笔可观的收入，更提升了其在国家战略层面的重要性，进一步拓宽了其在技术创新与军事应用领域的边界。

2. 特斯拉保险加速扩张：计划2026年3月进入田纳西州和印第安纳州

特斯拉正准备将其内部汽车保险项目引入田纳西州和印第安纳州。根据监管备案文件，特斯拉财产与意外险公司（Tesla Property & Casualty）已在这两个州提交了新的私人乘用车保险项目，拟定生效日期均为2026年3月1日。如果按时获批，田纳西州将成为特斯拉保险的第14个美国市场，印第安纳州则紧随其后。此次扩张标志着特斯拉保险在经历了三年无新增市场后，继本月初在佛罗里达州推出后，又一次加速发展。该项目在这两个州都将采用其全遥感驱动的保险模式，包括根据客户FSD (Supervised) 使用里程百分比提供折扣，并结合Safety Score系统每月动态调整保费，该系统评估急刹车、急转弯、超速、跟车距离和总里程等驾驶行为。

  • 判断/建议： 特斯拉保险业务的快速扩张，是其利用车辆大数据和技术优势实现垂直整合战略的关键一环。通过提供基于实际驾驶行为的动态保费，特斯拉有望为车主提供更公平、可能更低的保险选择，增强其生态系统吸引力，并创造新的经常性收入流。但其在加州等地的监管限制，也提醒了该模式推广的复杂性。

3. 特朗普呼吁埃隆·马斯克和星链应对伊朗互联网中断

面对伊朗全国范围内的反政府抗议活动导致互联网大面积中断，美国前总统唐纳德·特朗普表示，他计划与SpaceX首席执行官埃隆·马斯克商谈，以恢复伊朗的互联网接入。特朗普在华盛顿向记者表示，马斯克凭借其运营大规模卫星网络的经验，非常适合帮助伊朗恢复连接，并称赞他的公司“非常优秀”。伊朗已连续数日遭受近乎全面的互联网关闭，严重限制了信息流通。此前，星链（Starlink）在伊朗动荡时期曾被用于帮助部分用户绕过政府封锁，接入全球互联网。马斯克和SpaceX尚未就特朗普的言论立即置评，但马斯克在2022年伊朗抗议期间曾公开支持向伊朗人提供星链服务。

  • 判断/建议： 这一事件凸显了星链作为一种突破审查、提供全球连接的战略工具日益增长的地缘政治影响力。特朗普的表态不仅反映了星链技术的重要性，也表明了埃隆·马斯克在国际事务中日益增长的个人影响力。然而，其应用也必然涉及复杂的政治和外交考量，充满不确定性。
