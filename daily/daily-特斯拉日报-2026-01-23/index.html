  • AI超算能源： 特斯拉能源为xAI的Colossus 2超级计算机部署了2.3GWh的Megapack，并在Giga Texas为自家Cortex 2超算部署Megapack。
  • FSD购买方式更新： 特斯拉线上设计工作室已明确列出FSD的订阅、一次性购买（2月14日截止）和稍后添加选项。
  • 竞争对手动态： Waymo在迈阿密推出自动驾驶出租车服务，同时因多次违法超车校车行为面临美国NTSB的调查。

技术进展

  • FSD订阅策略与Autopilot退役： 特斯拉在加拿大和美国市场针对部分购买了增强版自动辅助驾驶（EAP）的用户，将其FSD月度订阅价格从原先的99美元/加元大幅降至49美元/加元。此举旨在为这些早期支持者提供一项实质性的忠诚度折扣，鼓励他们升级到更全面的FSD功能，避免他们感觉为重叠功能支付两次费用。与此同时，特斯拉实施了一项重大的产品线调整：北美市场的新车订单中，基础版Autopilot功能已被正式移除，不再作为标准配置提供。取而代之的是，新车仅标配基础的交通感知巡航控制（TACC），而功能更强大的全自动驾驶（监督版）则成为唯一可供选择的高级驾驶辅助系统。这一策略性转变，旨在全面推动FSD软件的普及和订阅模式的采用，与公司首席执行官埃隆·马斯克此前关于FSD将逐步淘汰一次性购买选项、转向纯订阅模式的声明（一次性购买选项将于2026年2月14日截止）高度一致。虽然此举可能引发部分用户对Autopilot功能缺失的不满，尤其考虑到许多竞品车型已将车道居中等功能作为标配，但特斯拉显然更希望通过集中资源和商业模式创新，加速FSD的迭代和商业化。马斯克也再次强调，随着FSD功能的持续提升，特别是当其能够实现“无监督”驾驶时，订阅价格将会进一步上涨，以体现其巨大的价值跃升。

  • 判断/建议： 特斯拉此次FSD订阅价格调整与Autopilot退役并举，清晰地展示了公司在自动驾驶商业化道路上的坚定决心，即转向更高利润、更稳定的软件订阅收入模式。虽然短期内可能面临部分用户流失和市场质疑的风险，但长期来看，这种策略有望简化产品线、集中研发资源，并为FSD向完全自动驾驶的演进提供更充足的资金支持，有望在未来数年内显著提升特斯拉的软件服务营收。

  • FSD硬件升级至4.5版与3-SoC架构： 根据特斯拉电子零部件目录的最新发现，一个名为“CAR COMPUTER - LEFT HAND DRIVE - PROVISIONED - HARDWARE 4.5”的新FSD电脑部件已经出现，预示着特斯拉可能已开始或即将开始在新车中部署硬件4.5版FSD电脑。该部件的定价与现有FSD电脑类似，表明其很可能是一个替代或修订版本，而非针对后期改装的全新产品。值得注意的是，资深特斯拉固件黑客Green透露，特斯拉的固件中包含了对3-SoC（系统级芯片）设计的引用，这标志着与此前HW3和HW4所采用的双SoC架构的显著不同。如果HW4.5确为3-SoC设计，它将带来远超现有HW4的计算能力，尤其在处理FSD v14及未来版本中指数级增长的推理模型时，将能提供更高的原始吞吐量、更大的内存和更强的计算效率。更具革命性的是，3-SoC系统有望实现“三重模块冗余”（TMR），即当一个芯片的判断出现“幻觉”或异常时，其他两个芯片可以通过多数投票机制进行纠正和验证，从而大幅提升决策的准确性和系统可靠性，显著减少因系统不确定性导致的安全脱离。

  • 判断/建议： FSD硬件4.5版，尤其是其潜在的3-SoC架构，是特斯拉在自动驾驶技术栈中迈出的关键一步，它不仅仅是算力的简单叠加，更是底层架构在安全性和鲁棒性上的重大飞跃。这将为FSD处理更复杂的长尾场景、提升感知和决策能力提供坚实的基础，有望加速“无监督”FSD的商业化进程。此举彰显了特斯拉在自动驾驶领域持续投入和保持技术领先的决心，但其在实际道路上的表现和稳定性仍需广泛验证。

  • FSD“炮弹之路”零干预挑战成功： 一辆2024款特斯拉Model S在最近成功完成了具有里程碑意义的首次零干预FSD“炮弹之路”挑战，该车配备了AI4硬件和FSD v14.2.2.3软件，从洛杉矶红石滩一路行驶至纽约曼哈顿中城，全程长达3081英里（约4958公里）。这次跨越美国东西海岸的壮举，不仅是特斯拉FSD系统首次在无人类干预的情况下完成这一标志性路线，也兑现了长期以来关于自动驾驶能力的一个重要基准。据前汽车记者Alex Roy及其团队报告，整个旅程耗时58小时22分钟，平均时速64英里，其中约10小时用于充电。FSD系统全程负责了所有驾驶任务，包括高速公路巡航、自动变道、导航以及应对极端冬季天气条件，如极寒、大雪、冰冻、泥泞和雨水。Roy的评论强调，FSD系统在旅途中表现惊人，甚至指出人类的任何干预反而可能导致错误或增加行驶时间。此次历史性成功极大地展示了FSD在复杂、长距离、多变环境下所具备的卓越可靠性和鲁棒性，无疑将显著增强市场和公众对FSD未来潜力的信心。

  • 判断/建议： 此次零干预FSD“炮弹之路”挑战的成功，不仅是对特斯拉FSD技术能力的一次强有力验证，更是一个极具说服力的营销案例。它向世界展示了FSD在特定但复杂的长途场景下已具备高度自主性，有助于打消部分消费者对自动驾驶技术实用性和安全性的疑虑，进而推动FSD的普及。然而，尽管这是一项重要成就，但需认识到现实世界的驾驶环境远比预设路线复杂，如何将这种高性能泛化到所有日常驾驶场景仍是特斯拉面临的巨大挑战，且司机在任何情况下仍需保持警惕，随时准备接管。

  • 特斯拉AI超级计算机Cortex 2的进展： 在德克萨斯州超级工厂内，特斯拉正大力推进其用于AI研究和训练的核心基础设施建设，已开始接收Megapack储能系统，以支持其新一代AI超级计算机Cortex 2的运营。Cortex 2集群预计将是一个高达500兆瓦的强大系统，其核心任务是为特斯拉的擎天柱（Optimus）机器人以及下一代FSD的无监督学习提供至关重要的计算能力。Giga Texas观察者Joe Tegtmeyer通过无人机拍摄的画面证实了Megapack的交付工作正在进行，同时Cortex 2的冷却系统（包括第一和第二部分）的建设也取得了快速进展。尤其值得一提的是，第一部分的6个风扇外壳中已有4个、相应的管道系统乃至部分外墙段正在安装，且其整体高度明显高于前代Cortex系统，暗示了其更大的规模和更强的性能需求。这一大规模的能源和计算基础设施投入，旨在为特斯拉在AI领域（特别是机器人和自动驾驶）的深入研发提供无与伦比的强大支持。

  • 判断/建议： Cortex 2的快速建设与Megapack的部署，清晰地表明特斯拉正将其战略重心进一步倾斜至AI核心能力建设上，尤其是在AI模型训练所需的计算资源方面进行巨额投资。这对于加速FSD向完全自主以及擎天柱机器人的商业化落地至关重要，预示着特斯拉在AI硬件和软件的深度集成方面将继续保持领先地位。此举将有效支撑特斯拉AI模型的指数级增长，有望在未来几年内显著提升其在自动驾驶和机器人领域的竞争力。

充电与能源

  • Megapack助力AI超算稳定运行： 特斯拉能源部门近日取得了两项重要的Megapack部署里程碑，充分展示了其大型储能产品在解决尖端科技领域能源稳定性挑战上的独特能力。其中最引人注目的是，特斯拉已为xAI在孟菲斯的“Colossus 2”超级计算机完成了约600个Megapack的安装，形成了总容量高达2.3GWh的巨大储能系统，其价值估计约为5.85亿美元，使其成为全球最大的电池储能项目之一。这些Megapack的部署目的并非传统的电网套利，而是作为“Colossus”和“Colossus 2”运行的关键缓冲，旨在吸收AI训练运行时可能产生的巨大功率尖峰，从而确保当地电网的稳定性，防止在高峰计算负载时出现电力中断或“褐电”。此外，特斯拉也在其德克萨斯超级工厂为其新的Cortex 2超级计算机部署Megapack，该超算将主要用于训练下一代FSD和擎天柱（Optimus）机器人。
  • 判断/建议： Megapack在AI超算领域的成功应用，不仅是特斯拉能源产品商业模式的一次创新性拓展，更凸显了其在为高能耗、对稳定性要求极高的AI基础设施提供能源解决方案方面的核心竞争力。这一策略性部署加强了特斯拉内部AI与能源业务的协同效应，为公司AI战略提供了坚实的能源基础，有望在未来随着全球AI计算需求的爆发式增长，为特斯拉能源业务开辟全新的高价值市场。

市场与交付

  • Cybertruck首次海外交付启动： 特斯拉已首次在中东地区启动了Cybertruck的交付，阿联酋成为首个接收这款全电动皮卡的国际市场。早在2025年9月，特斯拉便在中东地区开放了Cybertruck的订单，并于10月初在阿联酋、卡塔尔和沙特阿拉伯等国推出了配置器，双电机版起售价约为404,900阿联酋迪拉姆（约合110,000美元）。尽管此前的交付时间略有推迟至2026年初，但本月首批正式客户交付已在迪拜的Al Marmoom沙漠区域通过一场灯光和火焰秀盛大进行，约有63辆Cybertruck交付给客户。目前，Cybertruck在中东其他国家如约旦和以色列的特斯拉网站上仍可进行配置。然而，在欧洲等主要电动汽车市场，Cybertruck仍面临诸多监管障碍，特别是其独特的设计（如尖锐边缘和超硬不锈钢外骨骼）与欧盟严格的行人保护安全标准相冲突，可能导致其永远无法在这些市场推出。
  • 判断/建议： Cybertruck在阿联酋的首次海外交付，标志着特斯拉在全球市场扩张的又一步，尤其是在对独特设计接受度较高的新兴富裕市场。尽管此次交付量不大，但具有战略意义，有助于扩大Cybertruck的品牌影响力并探索其在北美以外的潜力。然而，欧洲等关键市场面临的监管挑战预示着Cybertruck的全球化进程将充满变数，特斯拉需谨慎评估未来的国际市场策略。

其他值得一提

  • Waymo迈阿密推出机器人出租车服务： Alphabet旗下的Waymo已在迈阿密正式推出其机器人出租车服务。目前已有近10,000名迈阿密居民在其候补名单上，Waymo从周四开始在一个60平方英里的服务区域内接受公众乘车请求，该区域涵盖了设计区、温伍德、布里克尔和珊瑚山墙等核心地段。Waymo确认计划“很快”将服务区域扩展至迈阿密国际机场。该公司正在美国8个城市进行扩张，包括西雅图、拉斯维加斯和华盛顿特区，部分地区已开始使用Zeekr RT面包车和捷豹I-Pace SUV进行测试。Waymo预计到2026年底，其扩展网络每周将提供100万次乘车服务，展现了其在自动驾驶出租车领域的雄心和快速发展。

  • 判断/建议： Waymo在迈阿密的扩张表明自动驾驶出租车服务正加速商业化落地，其预期的百万次周乘车量显示了行业对未来规模化运营的信心。这既是对特斯拉Robotaxi愿景的一种验证，也意味着市场竞争将日趋激烈，对特斯拉的FSD成熟度和Robotaxi部署速度构成了潜在压力，促使特斯拉加速其Robotaxi的推出。

  • Waymo因非法超车校车行为遭NTSB调查： 美国国家运输安全委员会（NTSB）已对Waymo展开调查，原因是其自动驾驶出租车在至少两个州多次被发现非法超车停靠的校车。NTSB特别关注了发生在德克萨斯州奥斯汀的20多起事件，并已派遣调查人员前往当地收集信息。此前，美国国家公路交通安全管理局（NHTSA）的缺陷调查办公室在去年10月也对Waymo的校车问题启动了类似调查。尽管Waymo去年发布了软件召回以解决此问题，但效果不佳，奥斯汀学区已要求Waymo在接送学生时段暂停运营。Waymo首席安全官Mauricio Peña表示，公司每周安全处理数千次校车遭遇，并相信其在校车周围的安全表现优于人类司机，同时将向NTSB提供透明的见解。

  • 判断/建议： Waymo面临的NTSB调查，凸显了自动驾驶技术在现实复杂交通场景中仍存在的挑战，特别是与公共安全相关的合规性问题。虽然Waymo宣称其系统优于人类驾驶员，但持续的负面事件和监管审查可能会对其品牌声誉和公众信任造成打击，进而影响其扩张速度。这也提醒包括特斯拉在内的所有自动驾驶公司，在追求技术进步的同时，必须高度重视实际应用中的安全性和合规性，确保公众的信任。
