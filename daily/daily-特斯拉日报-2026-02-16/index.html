技术进展

特斯拉FSD政策在北美市场经历重大调整，自情人节起在美国和加拿大正式终止了FSD的单独一次性购买选项，消费者现在只能以每月99美元的价格订阅该功能。这一变化旨在推动FSD向订阅模式全面转型，尽管这可能为实现埃隆·马斯克新薪酬方案中设定的FSD普及率目标带来挑战，因为目前月订阅的采纳率仅约12%。特斯拉仍为购买Model S、Model X或Cybertruck的顶级Cyberbeast版本的用户保留了“豪华套装”作为一次性获取FSD的“漏洞”，该套装包含FSD、免费超级充电、高级连接服务以及四年的高级服务包，但Model S和Model X的价格因此上涨了1万美元。然而，特斯拉也同步更新了条款，明确指出豪华套装中的FSD和免费超级充电权益自2026年2月14日之后购买的车辆将不再随车转移给后续车主，这实质上将其变为了绑定原车主的终身订阅，对车辆的二手市场价值构成显著打击。市场普遍预期FSD订阅价格未来会随着其功能（尤其是接近无监督驾驶能力）的提升而上涨，车主们对此也提出了多种定价建议，包括降价至49-69美元，或针对有人监督和无监督FSD提供不同价格（如监督版50美元/月，无监督版300美元/月），甚至引入按时计费模式，以期在提高普及率和盈利之间找到平衡。

  • 判断/建议： 特斯拉FSD的订阅制转型及其不可转让政策，短期内可能对其旗舰车型二手价值造成冲击，并需通过灵活的定价策略来提升用户采纳率。这是一个巨大的挑战，但也是特斯拉商业模式向软件服务转型的关键一步，其成功将取决于FSD功能的快速迭代和用户体验的持续优化。

特斯拉在全球FSD部署方面正取得区域性突破，特别是在中国市场和欧洲市场的AI集成。针对中国市场，特斯拉正积极推动FSD的重新上线，虽然副总裁陶琳明确表示目前没有具体的官方推出时间表，但特斯拉已为此建立了专门的本地AI训练中心。该中心拥有足够的计算能力，能够在中国境内进行本地化数据训练和处理，有效解决了此前因监管限制导致数据无法出境的问题，从而能够更好地适应中国复杂的驾驶行为和道路布局。同时，特斯拉还在上海超级工厂积极招聘自动驾驶测试工程师，并在临港南汇新城这一指定测试区域获得了公共道路高级自动驾驶测试的许可，这标志着FSD在中国本地化路测已进入验证阶段。在欧洲市场，特斯拉于今日正式向包括英国、爱尔兰、德国在内的九个国家推出xAI的Grok AI助手。这一车载功能通过2026.2.6软件更新实现，支持实时信息查询、免提互动以及与导航系统深度集成，用户可以自然语言发出导航指令，如“找到附近好评的泰国餐厅”或“在咖啡馆步行距离内找一个超级充电站”。Grok还提供多种个性化选择，但需车辆配备AMD信息娱乐处理器和高级连接服务，且已实现本地化语言支持，尽管其在欧洲的推出比北美晚了六个多月，这主要是由于此前存在的监管问题。

  • 判断/建议： 特斯拉在中国建立本地化AI训练中心和开展路测，是其FSD战略在全球扩展的关键一步，有望克服数据主权障碍，为中国庞大的市场提供定制化的智能驾驶体验。Grok在欧洲的本地化推出，则体现了特斯拉在车载AI互动和用户体验方面的持续投入，有望进一步提升车辆的智能化和便捷性，为用户带来更个性化和实用的辅助功能。

埃隆·马斯克再次重申了特斯拉Cybercab的激进生产时间表，强调这款没有踏板和方向盘的自动驾驶出租车将于2026年4月开始生产。这已是马斯克在过去六个月内第三次明确提及这一时间点，显示了他对公司实现这一目标的坚定信心，尽管他以往在其他产品（如Roadster、Semi和无监督FSD）的交付时间上常有延误。去年12月，马斯克曾透露特斯拉正在“测试该车的生产系统”，并表示“真正的生产爬坡将于4月开始”。他同时也为初期生产设定了“S曲线”式的增长预期，暗示初期产量将较为有限。Cybercab的设计理念是完全自动驾驶，取消了传统驾驶控制装置，旨在提供一种全新的出行服务模式。

  • 判断/建议： 马斯克对Cybercab生产时间表的反复确认，表明特斯拉正全力以赴推动这款创新产品的落地，这可能预示着自动驾驶出行服务即将进入量产阶段。然而，考虑到其激进的时间线和“S曲线”生产模式，市场应保持理性预期，关注其初期生产规模和实际部署进展，而非仅仅停留在时间点本身。

特斯拉与苹果公司正在深化合作，以期更好地将Apple CarPlay集成到特斯拉车辆中。此前有报道称特斯拉将支持CarPlay，但后续进展缓慢，现在更多细节浮出水面。延迟的主要原因是苹果地图与特斯拉FSD/原生导航系统之间的技术冲突。FSD依赖车辆的原生导航系统进行路线规划，而CarPlay激活时，苹果地图可能会提供与FSD指令相悖的转向提示，这可能导致危险的“双重导航”场景。为解决这一问题，特斯拉请求苹果公司开发了一个定制修复方案，以确保两个地图系统能够同步。苹果公司已同意并实施了必要的调整，这意味着车主未来或能通过CarPlay设置目的地，并让FSD自动驾驶至该地点。然而，目前该功能普及的瓶颈在于iPhone的iOS更新周期，兼容性修复方案被捆绑在iOS 26的增量更新中（可能为去年12月发布的iOS 26.2或今年2月发布的iOS 26.3），用户更新速度影响了功能的全面推广。

  • 判断/建议： 特斯拉与苹果在CarPlay集成上的合作，特别是解决FSD与导航冲突，展示了特斯拉开放生态的姿态和以用户为中心的改进方向。尽管iOS更新是当前瓶颈，但此举有望显著提升用户体验，吸引更多潜在买家，并缓解部分用户对特斯拉信息娱乐系统兼容性的顾虑，是软件生态融合的积极信号。

工厂与制造

特斯拉德国柏林超级工厂近期卷入了一场劳资纠纷，导致一名IG Metall工会代表受到德国当局的调查。这起事件源于特斯拉管理层上周提交的一份刑事投诉，指控一名工会代表在一次秘密的劳资委员会会议上进行了未经授权的录音。根据德国法律，未经同意录制非公开会议可能构成刑事犯罪。据rbb24报道，警方已于周二下午扣押了该工会成员的笔记本电脑。柏林工厂经理André Thierig在社交媒体X上发文表示，该代表“被当场抓获”，促使公司报警并提出刑事诉讼。IG Metall工会对此指控予以否认，并将其描述为特斯拉在即将于3月2日至4日举行的劳资委员会选举前采取的竞选策略。柏林超级工厂约有11,000名员工有资格参加此次选举，此事件无疑加剧了特斯拉与德国有组织劳工力量之间的紧张关系。

  • 判断/建议： 柏林超级工厂的工会代表被调查事件，凸显了特斯拉在德国运营中面临的劳资关系挑战和文化差异。虽然事件仍在调查中，但它可能进一步加剧特斯拉与德国强大工会之间的对立，并可能影响即将到来的劳资委员会选举，进而对工厂的生产效率和员工士气产生潜在影响，特斯拉需谨慎处理以维护企业形象和稳定的生产环境。

有报告指出，特斯拉Model S和Model X车型的生产预计将在未来几个月内逐渐停止，最快在第二季度结束。这一生产调整对特斯拉的市场策略，特别是针对“豪华套装”的销售产生了直接影响。由于Model S和Model X的生产将告一段落，与这两款旗舰车型深度绑定的“豪华套装”很可能也将随之退出市场，而Cybertruck的Cyberbeast版本中包含该套装的供应也可能受到影响。

  • 判断/建议： Model S和Model X生产的结束预示着特斯拉产品策略的进一步聚焦和转型，可能意味着公司将资源更多地投入到高销量车型如Model 3/Y以及未来的创新产品如Cybercab和机器人出租车。虽然这可能对高端豪华车市场造成短暂的真空，但同时也是特斯拉精简产品线，优化生产效率，并为下一代车型腾出产能空间的重要举措。

充电与能源

特斯拉在加拿大渥太华新增一个超级充电站，位于Campeau Drive的Tanger Outlets Ottawa。这个期待已久的充电站于本周末正式启用，为当地特斯拉车主带来了便利。该充电站于2024年9月首次出现在特斯拉的“查找我们”地图上，并于2025年5月开始施工，同年6月完成物理建设。然而，站点在建成后又等待了数月才完成最终检查并接入电网。新站点配备了12个V4超级充电桩，每个充电桩能够提供高达325 kW的充电速度，确保了高效快速的补能体验。充电费用根据时间段有所不同：特斯拉车主在夜间和清晨的非高峰时段收费为0.29美元/kWh，而在白天高峰时段则高达0.55美元/kWh。值得一提的是，该充电站也向非特斯拉电动汽车开放，其非高峰时段的充电费率为0.41美元/kWh，高峰时段则为0.77美元/kWh。该充电站地理位置优越，靠近Tanger Outlets Ottawa购物中心和417号高速公路，方便车主在充电期间购物、用餐或作为长途旅行的中转站。

  • 判断/建议： 渥太华新超级充电站的开业，特别是其V4桩和对非特斯拉车辆的开放，进一步巩固了特斯拉在北美充电基础设施领域的领先地位。这不仅提升了特斯拉车主的充电体验，也促进了电动汽车的普及，对整个电动汽车行业来说是积极的信号，同时差异化的定价策略也反映了特斯拉对充电网络运营效率和营收的重视。

市场与交付

特斯拉在美国市场推出了两款最畅销车型Model 3和Model Y的低利率融资促销活动，旨在通过降低借贷成本来刺激销量。Model 3全系车型（包括后驱、高级后驱、高级全驱乃至高性能版）现在可享受0.99%的超低融资利率。针对销量最佳的Model Y，特斯拉则提供了更为激进的促销：后驱版和全驱版可享受0%的融资利率，而高级后驱版和高级全驱版则为0.99%，不过Model Y高性能版未包含在此次优惠中。这些优惠均适用于最长六年（72个月）的贷款期限，特斯拉已于周日通过电子邮件通知了客户。在当前利率普遍偏高的市场环境下，特斯拉通过补贴利息成本来维持强劲需求并与传统汽车制造商及新兴电动车品牌竞争，这一策略显得尤为重要。

  • 判断/建议： 特斯拉在美国市场推出极具竞争力的低利率甚至0%融资方案，是应对市场竞争和高利率环境的有效策略，有望显著提升Model 3和Model Y的销量。然而，加拿大等其他市场未能获得类似优惠，这可能导致区域销售表现不均，特斯拉应考虑在全球范围内更均衡地调整市场策略以维持增长势头。

美国德克萨斯州墨菲市警察局近日部署了两辆2026款特斯拉Model Y作为其巡逻警车，这些车辆经过UP.FIT公司的改装，专为警务职责打造。此举的主要目标是显著降低警务部门的运营成本，一项研究显示，警用电动车每年每辆车可节省高达5,000美元的运行费用，主要体现在减少维护需求和燃油开支上。2026款Model Y在设计上具备多项适合警务工作的改进，例如显著提升的座舱隔音效果，这有助于增强巡逻警员的无线电清晰度和态势感知能力。此外，车辆的悬架系统也得到了改进，能够更好地承受额外的警用设备重量。全球范围内已有多个公共安全机构采用特斯拉电动车执行任务，包括墨西哥哈利斯科州警方为2026年FIFA世界杯采购Cybertruck、冰岛警方电动车队累计行驶超过100万公里（多数为Model Y），以及法国芒德利厄-拉纳普勒镇警队在2024年增加了四辆Model 3。

  • 判断/建议： 墨菲市警方部署Model Y警车，再次验证了特斯拉电动车在公共服务领域的可行性和成本效益。随着2026款Model Y在隔音和悬架等方面的改进，其在警务应用中的优势将更加明显，有望推动更多地方政府和机构采纳电动车队，为特斯拉带来新的销售增长点和品牌形象提升。

加拿大联邦政府于今日（2026年2月16日）正式启动了新的电动汽车补贴计划——电动汽车可负担性计划（EVAP），取代了此前的iZEV项目。该计划继续为电池电动车和氢燃料电池车提供最高5,000加元补贴，插电式混合动力车最高2,500加元，但补贴额度将在为期五年的计划中逐步减少。新计划最关键的改变在于，补贴资格不再依据制造商建议零售价（MSRP），而是以“最终交易价格”为准，该价格必须低于50,000加元，但加拿大本土制造的电动车不受此价格上限限制。最终交易价格包含送货费、运费、空调税、经销商费用及配件，但不包括延长保修、冬季轮胎、充电器、融资成本、税费和政府回扣。这意味着，即使车辆MSRP较低，额外配置或经销商费用也可能使其最终交易价格超出5万美元的门槛，从而失去补贴资格。鉴于特斯拉车型通常定价较高且目前并非在加拿大本土生产，大多数特斯拉车型将难以符合此次联邦补贴条件，这对特斯拉在加拿大市场的竞争力构成了挑战。

  • 判断/建议： 加拿大新EVAP补贴计划的价格上限对特斯拉构成显著挑战，可能限制其在加拿大市场的销量增长。特斯拉若想在加拿大市场受益于此类补贴，可能需要考虑推出更多入门级车型或推动本地化生产，否则其销售策略将需更多依赖自身品牌吸引力和技术优势来应对。

中国工业和信息化部（MIIT）发布的草案显示，计划自2027年1月1日起实施新的车辆安全标准，此举将有效禁止新车使用Yoke异形方向盘。这些拟议的修改是自2011年以来未曾大改的中国转向安全法规的更新版本，旨在应对电动汽车快速发展和非常规转向设计引入带来的挑战，以更好地保护驾驶员在碰撞中的安全。新规定要求方向盘必须通过10个特定点的冲击测试，包括“最薄弱区域的中点”和“最短无支撑区域的中点”。由于Yoke方向盘缺乏连续的上部结构，这些必要的测试点无法在其设计上实现，使得其符合性极其困难，甚至不可能。安全考虑是此举的主要驱动因素，碰撞数据显示约46%的驾驶员受伤与转向机构相关；传统的圆形方向盘能提供更大的表面积吸收冲击能量并保护乘员，而Yoke的开放式结构增加了驾驶员头部绕过方向盘撞击转向柱或仪表板的风险。

  • 判断/建议： 中国计划自2027年起禁止Yoke方向盘的举动，将直接影响特斯拉Model S和Model X等提供Yoke选配的车型在中国市场的销售策略和产品设计。特斯拉需要密切关注法规的最终版本，并可能需要为中国市场调整其车型设计，以符合新的安全标准，否则将面临失去该市场竞争力的风险。

埃隆·马斯克旗下的社交媒体平台X于周一上午遭遇了一次大范围的服务中断，全球数万用户报告称无法加载平台，无论是桌面端还是移动端均受到影响。据Downdetector数据显示，中断始于美国东部时间上午8:02左右，并在美国和英国迅速升级，美国一度有超过40,000份事件报告，英国也攀升至6,000多份，菲律宾和哥斯达黎加等其他地区用户也报告了类似问题。用户尝试访问X时，页面显示“出了点问题”，信息流不刷新，帖子不显示。此次中断发生在一周内使用高峰期，加剧了其在全球范围内的可见性。这也是继今年1月中旬以及2025年11月大规模中断之后，X平台再次出现的类似问题，但X公司尚未发布官方解释或确认服务中断的原因。

  • 判断/建议： 社交媒体平台X的频繁中断，尽管与特斯拉的核心业务无直接关系，但作为埃隆·马斯克旗下的重要资产，其稳定性问题可能间接影响投资者信心和公众对其技术能力的认知。持续的服务问题可能损害X的用户体验和品牌声誉，对于马斯克个人品牌形象也有一定负面影响，这提示其需加强基础设施的可靠性建设。

The Boring Company（TBC）近日公布了其连接奥兰多环球影城度假村（Universal Orlando Resort）北园区至环球史诗宇宙（Universal Epic Universe）的隧道项目新细节。Shingle Creek交通与公用事业社区开发区于2月11日投票，将TBC列为该交通项目的首选投标人，并启动合同谈判。新披露的招标文件显示，该项目将采用双隧道结构，每条隧道单向通行，并计划在获得批准后，约一年半内完成许可、设计和施工。TBC表示将部署多台隧道掘进机，并配备8名内部专家和6家分包商来执行项目。运营模式将复制其拉斯维加斯环路（Las Vegas Loop）的成功经验，利用特斯拉车辆提供按需、点对点的快速交通服务，而非固定线路巴士。文件还提及未来可能集成可配置的Robovan用于载客和货运。

  • 判断/建议： The Boring Company的奥兰多环球影城隧道项目，进一步展示了其在城市交通解决方案领域的潜力，并再次强调了特斯拉车辆作为核心交通工具的角色。这一项目若能成功实施，将不仅提升环球影城的游客体验，也为未来城市交通基础设施提供了新的范式，验证了特斯拉在自动驾驶和地下交通方面的技术协同价值，对TBC和特斯拉而言都是重要的里程碑。

瑞典特斯拉公司与特雷勒堡港（Port of Trelleborg）续签租约的决定，在当地引发了一场政治争议，当地领导人就市政拥有的港口是否应在特斯拉与IF Metall工会持续冲突期间继续向其出租空间，分歧日益加剧。此前，由于运输工人工会的封锁行动，特斯拉瑞典公司通过客运渡轮卡车将车辆运往该港口，绕开了工会障碍，从而维持了交付。该港口最初暗示不会与特斯拉签订新协议，但最终仍选择续签现有合同。当地社会民主党反对派议员Lennart Höckert批评港口此举是“背叛了瑞典模式”，认为市政实体不应在劳资冲突中偏袒一方。他提议，未来市政港口的所有租赁协议都应由政治家审查和批准。然而，瑞典民主党（Sweden Democrats）的市政委员会主席Mathias Andersson对此强烈反对，认为政治领导人不应微观管理由其董事会运营的公司，并将社会民主党的方法描述为“金正恩式”。

  • 判断/建议： 瑞典特雷勒堡港与特斯拉的续租争议，凸显了企业在劳资纠纷中与地方政治和价值观体系的复杂互动。特斯拉在此事件中面临着维护供应链稳定与尊重当地“瑞典模式”之间的两难。港口的选择反映了商业利益与社会责任之间的张力，可能对特斯拉在北欧地区的品牌形象和运营环境产生长期影响，特斯拉需寻求更可持续和符合当地社会价值观的解决方案。
