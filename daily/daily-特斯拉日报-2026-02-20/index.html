技术进展

FSD Supervised的实战救援

昨日，一辆特斯拉Cybertruck的车主在高速公路行驶中突发医疗紧急情况，身体失去知觉。当时车辆启用了全自动驾驶（FSD）Supervised系统，系统通过驾驶员监控检测到车主失去意识，随即自动减速、开启双闪警示灯，并安全地将车辆靠边停在路肩上，有效避免了一场潜在的严重交通事故。随后，该车主被FSD系统自主驾驶送往急诊室接受治疗。特斯拉CEO埃隆·马斯克已对此事件进行了回应。

这一事件是FSD Supervised系统在真实危急状况下成功发挥关键作用的有力证明，极大地提升了公众对特斯拉自动驾驶技术在紧急干预方面的信心。它不仅展示了特斯拉在人工智能和车载安全系统方面的领先能力，也为未来自动驾驶汽车处理不可预测的驾驶员健康问题提供了宝贵的案例。FSD的卓越表现有望加速其在消费者心中的接受度，进一步推动自动驾驶技术的普及和商业化进程，尽管其在所有复杂场景下的适用性仍需持续验证。

Optimus机器人工厂的战略布局

特斯拉CEO埃隆·马斯克在2025年第四季度的财报电话会议上确认，Model S和Model X的生产将在2026年第二季度结束。此举并非简单的停产，而是特斯拉更宏大战略的一部分：将这些车辆原有的生产空间，特别是弗里蒙特工厂的产线，改造成为Optimus机器人的专用工厂。这是特斯拉整体战略向自主化未来迈进的关键一步。

Model S和Model X作为特斯拉的早期旗舰车型，曾为公司在豪华电动车市场奠定了基础，它们的停产标志着一个时代的终结。特斯拉将宝贵的工厂空间和生产资源转向Optimus机器人项目，表明公司正将战略重心从传统汽车制造转向其认为更具颠覆性潜力的AI和机器人技术领域。此项战略调整旨在加速Optimus人形机器人的研发、测试和最终量产，以期在未来几年内实现其在劳动力市场和服务行业的广泛应用。虽然这可能在短期内对特斯拉的高端车型产品线造成一定影响，但长期来看，它有望为公司开辟全新的增长曲线，但也面临着巨大的技术、生产和市场转化挑战。

Neuralink引发中国脑机接口竞赛

由埃隆·马斯克创立的脑机接口公司Neuralink，正在中国激发起一场激烈的脑机接口（BCI）技术研发竞赛。中国本土的初创企业，如成立于2021年的NeuroXess，已迅速推进其植入式脑机接口的人体临床试验，并获得了中国政府的强大支持。去年，北京已将BCI技术列为战略性新兴产业，并发布路线图，目标是到2030年培育出2至3家具有全球竞争力的BCI公司。Neuralink目前也在全球范围内开展临床试验，并正积极准备推出其新产品“Blindsight”，旨在帮助视力受损者恢复视力。

Neuralink通过其临床进展和公开演示，成功吸引了全球对侵入式脑机接口技术的广泛关注，并直接刺激了中国在该领域研发和投资的加速。中国政府的战略性推动和大量资本涌入，预示着BCI技术在全球范围内的创新和竞争将进入一个快车道。此领域的快速发展不仅有望在医疗健康领域带来突破，也可能在人机交互、人工智能等前沿技术领域产生深远影响。虽然Neuralink并非特斯拉直接业务，但其在BCI领域的进展体现了马斯克对前沿科技的持续布局，未来可能与特斯拉在AI、自动化方面的技术有潜在的交叉应用，同时也面临着伦理、安全以及大规模商业化等诸多复杂挑战。

充电与能源

特斯拉充电网络开放提升行业满意度

根据2026年JD Power美国电动汽车体验（EVX）所有权研究报告，电动汽车车主的整体满意度已攀升至历史新高，而公共充电体验的显著改善是主要驱动因素之一。报告指出，大众市场电动车主的充电满意度得分同比飙升115点至511分，高端电动车主满意度也达到了652分。这一重大提升主要归功于特斯拉超级充电网络向其他品牌电动汽车的开放，极大地缓解了所有电动车车主寻找可靠且高效充电桩的焦虑。

特斯拉的NACS（北美充电标准）及其超级充电网络的开放战略，不仅为更广泛的电动汽车用户提供了便利，也进一步巩固了特斯拉作为电动汽车基础设施领域领导者的地位。更高的充电满意度对于电动汽车市场的长期增长至关重要，它有助于打消潜在消费者对续航和充电便利性的顾虑，从而加速电动汽车的普及。特斯拉在此领域的战略先发优势有望为其带来长期的生态系统收益，但随着更多品牌加入超级充电网络，如何有效管理和维护日益增长的充电需求，确保服务质量，将是特斯拉面临的挑战。

瑞典超级充电站遭破坏事件

近日，位于瑞典Vansbro的一处特斯拉超级充电站遭到破坏。当地媒体公布的照片显示，充电线缆被人为浇水导致冻结，现场还悬挂了一幅带有埃隆·马斯克肖像的横幅，上面写着“埃隆回家”。这起事件发生在特斯拉与瑞典工会IF Metall持续两年多的劳资纠纷背景下。该工会一直在为争取与特斯拉签订集体谈判协议而进行罢工。尽管特斯拉安装了发电机以应对其他工会因同情罢工而切断部分充电站电源的情况，但事发当天发电机据称并未正常工作。

这起破坏事件不仅直接影响了当地特斯拉车主和其他品牌电动车（因特斯拉超级充电站在瑞典也向其他电动车开放）的充电需求，尤其是在冬季旅行高峰期造成了不便，也反映出特斯拉在国际劳资关系中面临的复杂挑战。瑞典工会传统强大，特斯拉拒绝签署集体协议的立场引发了广泛争议和多方工会的声援罢工。此事件可能加剧特斯拉与工会之间的紧张关系，并可能对其在瑞典乃至更广泛的欧洲市场的品牌形象和运营带来负面影响。特斯拉需要更有效地处理其国际劳资纠纷，以避免运营中断和品牌声誉受损，同时寻求与当地工会建立更为建设性的对话机制。

市场与交付

Model S/X停产与“月光银”漆面售罄

特斯拉的旗舰轿车Model S和SUV车型Model X的“月光银”（Lunar Silver）漆面选项已正式售罄，这标志着该独特高端颜色配置的终结。虽然部分现有库存仍可能找到带有此颜色的车型，但特斯拉在线配置器已不再提供定制选择。更具里程碑意义的是，特斯拉CEO埃隆·马斯克在2025年第四季度财报电话会议上确认，Model S和Model X的生产将在2026年第二季度正式结束。

Model S和Model X是特斯拉早期发展的基石，它们凭借出色的性能和豪华配置，帮助特斯拉奠定了在全球电动汽车市场的地位，改变了公众对电动车的认知。这两款车型的停产，象征着特斯拉一个重要时代的落幕，公司正将这些宝贵的生产空间改造为Optimus机器人的工厂，以实现向AI和机器人领域的战略转型。此举虽可能引发部分消费者的怀旧情绪，并暂时在高端电动车市场造成产品空缺，但从长远看，它将使特斯拉能够集中资源投入到更具未来潜力的新技术和新产品线，为公司的持续创新和增长提供动力，但也需要面对在高端市场维持竞争力的挑战。

Cybertruck新AWD版发布与“10天”限时销售

特斯拉正式推出全新Cybertruck AWD双电机全轮驱动版本，起售价定为极具竞争力的59,990美元。该车型提供了约325英里的续航里程、电动货箱盖、集成了两个120V和一个240V插座的货箱电源以及Powershare功能。此外，它还配备了带自适应减震的螺旋弹簧悬架、线控转向和四轮转向。相较于去年已停产且市场反响平平的后驱版Cybertruck（因功能削减而性价比不高），这款新AWD版在价格更低的同时提供了显著更实用的功能。然而，就在发布后不到24小时，特斯拉CEO埃隆·马斯克在社交媒体上突然宣布，该59,990美元的定价“仅限未来10天”。

Cybertruck自上市以来，由于较高的价格，其销量一直未达预期（2024年约39,000辆，2025年降至约20,000辆，远低于每年25万辆的产能）。此次新AWD版的推出，旨在通过更亲民的价格和保留核心实用功能，有效刺激市场需求，尤其吸引对工作性能有需求的用户群体。然而，马斯克的“10天”限时销售策略给市场带来了巨大的不确定性，引发了关于这是否是促销、价格上调前奏或市场测试的广泛猜测。这种策略可能在短期内制造紧迫感，促使部分观望买家迅速下单，但也可能因未来价格和供应的不明确性，导致更多潜在买家犹豫不决，从而扭曲真实的DMD，特斯拉需要尽快明确长期销售策略，以稳定消费者预期。

Cyberbeast降价与“Luxe”豪华套装移除

特斯拉已将其高性能Cybertruck车型Cyberbeast的价格下调15,000美元，使其起售价降至99,990美元以下。然而，这次价格调整并非简单的降价，而是通过移除此前包含在114,990美元售价中的“Luxe”豪华套装来实现的。该豪华套装此前捆绑了全自动驾驶（FSD）Supervised功能、终身免费超级充电、四年免费服务以及终身高级车载娱乐服务。尽管Luxe套装在Cyberbeast上被移除，但仍适用于Model S和Model X车型（不过这两款车将在2026年第二季度停产）。

此举是特斯拉应对Cyberbeast销量不佳（2025年销量估测下降近50%）的策略之一，旨在通过更低的入门价格，提升其在高端高性能电动皮卡市场的竞争力。通过将FSD等核心增值服务从捆绑销售中分离，特斯拉可能正探索新的订阅或选配盈利模式，使得车辆基础售价更具吸引力，同时允许客户根据自身需求灵活选择增值服务。目前，与其他竞争对手如Rivian R1T Quad、GMC Hummer EV等相比，Cyberbeast在价格上更具优势，且FSD Supervised仍是其独特卖点。特斯拉需要平衡降低成本与维持品牌高端形象之间的关系，并清晰传达FSD的价值主张，以确保此次调整能够有效提振销量并优化营收结构。

Model 3与Model Y荣登EV满意度榜首

根据JD Power 2026年美国电动汽车体验（EVX）所有权研究报告，特斯拉旗下的Model 3和Model Y车型在电动汽车消费者满意度方面表现卓越，双双占据前两名。Model 3以804分（满分1000）荣登榜首，而Model Y则以797分紧随其后。研究还显示，尽管近期电动汽车的整体销量增长面临挑战（部分原因是2025年末联邦税收抵免政策的结束），但现有电池电动汽车（BEV）车主的满意度达到了历史最高水平，高达96%的新车主表示会考虑下一辆车继续购买电动汽车。Model 3近期还连续第二年荣获Edmunds最佳电动车奖项，新推出的标准版车型以更亲民的价格带来了同样的高端技术和可靠性。Model Y则被Consumer Reports评为2026年最佳电动汽车。

这些研究结果有力地证明了特斯拉产品在质量、性能和用户体验方面的强大竞争力，尤其是在当前市场竞争日益激烈和宏观环境变化的情况下。高客户满意度是特斯拉持续增长和维护品牌忠诚度的重要基石，这表明特斯拉的产品策略，包括推出更具性价比的入门级车型，正在有效满足市场需求。尽管电动汽车市场整体增速有所放缓，但特斯拉凭借其强大的产品力和用户口碑，有望在长期保持领先地位，并为行业树立了用户体验的标杆。

其他值得一提

特斯拉2025年美国联邦税收状况解析

根据特斯拉2025年度财务报告披露，尽管公司在美国本土实现了57亿美元的利润，但其联邦企业所得税率为0%。这一现象引发了广泛讨论，但实际上，这并非所谓的“避税漏洞”，而是美国税法体系设计旨在鼓励国内投资和创新的结果。特斯拉在2025年全球范围内实际支付了超过12亿美元的现金税款，在美国也缴纳了数亿美元的州税、地方房产税和员工薪资税。

特斯拉之所以能够在美国实现联邦企业所得税为零，主要得益于多项合法且标准的税收机制。其中包括：首先，加速折旧，美国政府鼓励企业在美国境内进行实体建设，允许公司将大规模资本资产（如制造设备和工厂建设）的成本在税收上更快地摊销。特斯拉近年来投入数十亿美元扩建德州超级工厂、内华达Semi工厂、新建LFP电池工厂以及超级充电网络，这些巨额投资为公司带来了显著的折旧抵免。其次，研发税收抵免，鼓励企业进行创新投入。最后，税收亏损结转，允许企业利用过去的经营亏损来抵销未来的利润。这些机制共同作用，使得特斯拉的联邦税负降至零。这一情况表明，特斯拉的财务策略高效地利用了美国税法的激励政策，促进了其在美国本土的持续投资和就业创造。然而，这也可能在公共舆论中引发对企业税收公平性的持续讨论，投资者应关注其税收结构背后符合政策导向的逻辑。
