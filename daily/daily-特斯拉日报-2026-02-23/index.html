技术进展

  • FSD语音指令集成 埃隆·马斯克近日证实，特斯拉全自动驾驶（FSD）系统即将支持语音指令，这将是FSD可用性方面最重要的升级之一。通过这一功能，驾驶员将能够实时向车辆发出自然语言指令，例如“在下一个街区右转”或“在门口附近找一个停车位”，从而无需手动干预即可调整驾驶行为。这项改进有望大幅提升用户体验，解决FSD此前无法响应具体情境偏好的“最大缺陷”。马斯克在回复X用户的提问时，仅以“Coming”（即将到来）一词确认了这一重要更新，显示出其即将到来的确定性。目前，FSD主要基于导航目的地进行路线计算和执行，但在驾驶过程中，系统无法根据驾驶员的特定偏好进行调整，这常常引起用户的不满。语音指令将允许驾驶员对FSD的行驶路径和停车操作进行精细化指导，例如指定“倒车入库”或“车头朝前停在车道上”。预计这项功能将建立在特斯拉与xAI的Grok助手集成之上，Grok自2025年在北美、2026年在欧洲推出以来，已支持通过对话式输入设定目的地和添加停靠点。这一功能的加入有望弥合自主驾驶与人类偏好之间的差距，特别是在目前“智能召唤”功能相对有限的情况下。

  • 判断/建议： 这项功能是FSD向更自然、更直观人机交互迈出的关键一步，有望显著提高用户满意度和系统的实用性。它为特斯拉在L3/L4自动驾驶体验方面提供了差异化优势，但其实际效果和普及速度将取决于语音识别的准确性以及系统处理复杂指令的能力。

  • FSD手势识别与安全里程碑 埃隆·马斯克近期强调，特斯拉FSD Supervised系统现已能识别手势信号，这一先进能力显著增强了其在复杂真实世界环境中的运行效能。特斯拉欧洲发布的一段视频直观展示了FSD车辆在荷兰狭窄车道中，能够准确识别并响应人工交通指挥手势，顺利通过障碍。在日常驾驶中，行人、施工人员、停车管理员以及其他驾驶员经常通过手势来指挥交通、示意先行或指示安全通行，因此，对于在混合环境中运行的自动驾驶系统而言，理解这些非语言线索至关重要。手势识别能力的加入，极大地提升了FSD系统与人类环境互动的能力，使其能够更好地融入非结构化的交通场景。此外，特斯拉FSD Supervised的累计行驶里程已突破令人瞩目的80亿英里大关，这一里程碑是其技术成熟度和用户普及度的有力证明。FSD Supervised的年度行驶里程呈现爆发式增长，从2021年的约600万英里迅速跃升至2025年的42.5亿英里，并在2026年前50天内又新增10亿英里。按照目前的增长速度，预计FSD Supervised在2026年全年的累计行驶里程有望达到约100亿英里，彰显其在全球范围内的快速部署和广泛应用。特斯拉最新的北美安全数据显示，搭载FSD Supervised的车辆平均每行驶5,300,676英里才发生一次重大碰撞，而同期美国全国的平均水平为每660,164英里发生一次重大碰撞。这一数据表明FSD Supervised在安全性方面已远超人类驾驶平均水平，为推广和监管批准提供了强有力的安全保障。

  • 判断/建议： 手势识别能力的加入显著增强了FSD在复杂交通场景中的感知能力和安全性，是迈向更高级别自动驾驶的重要一环。累计行驶里程的快速增长和卓越的安全数据进一步巩固了FSD的技术领先地位和市场信任度，为未来监管批准和全球推广提供了坚实支撑。

  • 欧洲FSD订阅模式暗示 特斯拉荷兰官网的源代码近期被发现包含一个关于“订阅价格挂钩”的注释，这强烈暗示欧洲市场即将推出FSD（全自动驾驶）的月度订阅服务。源代码中提及的99欧元月费，很可能是一个占位符，但与北美市场99美元的月费标准保持一致，表明特斯拉正在全球范围内统一其FSD的商业模式。尽管欧洲的特斯拉车主对FSD的全面功能等待已久，但由于严格的监管规定，FSD (Supervised)在欧洲的推出一直面临挑战。特斯拉此前曾制定雄心勃勃的计划，旨在通过与荷兰车辆管理局（RDW）的合作，在2026年2月正式在欧洲推出该系统，视RDW为更广泛欧洲批准的门户。然而，目前2月已进入最后一周，FSD尚未获得荷兰乃至其他欧盟国家的官方批准，这表明监管障碍仍是其全面部署的关键瓶颈。为了在欧洲市场制造声势并展示系统安全性，特斯拉去年曾在汉堡、柏林和阿姆斯特丹等城市推出了备受好评的FSD试乘体验计划，让欧洲消费者亲身感受其能力。埃隆·马斯克在最近几周也曾暗示，欧洲市场的首批正式批准可能在本月内到来，但截至目前，尚未有官方消息。值得注意的是，特斯拉在北美市场已于本月初正式取消了FSD的一次性购买选项（8,000美元），转而只提供月度订阅服务。相比之下，欧洲市场目前仍然保留了FSD的一次性购买选项，但源代码的发现预示着这一模式可能很快也会在欧洲市场发生转变。

  • 判断/建议： 欧洲FSD订阅模式的推出将使其对更多用户更具吸引力，降低入门门槛，有助于市场普及，尤其符合特斯拉在软件服务上的战略转型。然而，监管批准仍是关键不确定因素，特斯拉需要继续与欧洲各国监管机构紧密合作，以确保FSD功能的安全性和合规性，这将直接影响其在欧洲市场的商业模式落地。

充电与能源

  • 特斯拉Semi Megacharger网络进军欧洲 特斯拉正积极为Semi电动卡车在欧洲部署Megacharger充电网络奠定基础，这标志着公司在重型电动货运领域的全球扩张迈出了关键一步。公司近期在LinkedIn上发布招聘信息，为中央欧洲（慕尼黑）寻找一名商业充电销售负责人，其核心职责将是促成包括Supercharger和“重型充电”（Megacharging）在内的商业交易。该职位将专注于向充电站运营商、大型房地产所有者和零售公司等主要合作伙伴销售特斯拉的高功率充电产品，这明确指向了Megacharger的部署。Megacharger是专为Tesla Semi设计和建造的超高功率充电桩，可提供高达1.2兆瓦的充电功率，远超传统乘用车Supercharger的最高500千瓦（V4）或325/250千瓦（V3.5/V3）功率。此前，Megacharger仅在美国部署，主要服务于像百事公司这样的早期Semi客户，而Semi卡车本身也仅在美国道路上运营。埃隆·马斯克已确认Tesla Semi将于2026年进入高产量生产阶段，内华达超级工厂附近的Semi工厂也已接近竣工，为全球扩张奠定了生产基础。欧洲作为全球最大的货运市场之一，且拥有严格的排放法规，正加速推动车队电气化，因此，特斯拉将Semi及其配套充电基础设施引入该地区具有重要的战略意义。Semi官方网站已更新了产品线，包括标准版（续航325英里，能耗1.7千瓦时/英里）和长续航版（续航500英里），两者均支持快速充电，可在30分钟内恢复60%的续航。在欧洲市场部署Megacharger网络是实现Semi国际扩张的必然且逻辑性一步，旨在解决电动重卡长途运输的里程焦虑和充电效率问题。
  • 判断/建议： 进军欧洲Megacharger市场是特斯拉Semi实现全球化部署的必然一步，为特斯拉在电动重卡领域的长期竞争力打下坚实基础。此举有望加速欧洲货运业的电气化进程，但也面临当地电网基础设施适应性、标准统一以及与现有充电解决方案竞争的挑战，成功与否将取决于特斯拉的执行力和本地化策略。

市场与交付

  • Model Y L六座版获澳大利亚批准上市 特斯拉最新款Model Y L六座版已获得澳大利亚政府ROVER门户网站的批准，标志着这款车型距离在当地市场正式推出又近一步。该车型在ROVER网站上以“YL5NDB”的变体代码进行备案，确认已通过所有监管障碍，可供澳大利亚消费者选择。Model Y L在标准五座版基础上，通过加长轴距150毫米（达到3040毫米）和车身总长177毫米（达到4969毫米），巧妙地实现了更宽敞的2+2+2六座布局。这种布局包括第二排的两个船长椅和第三排的长凳，旨在提供比传统七座版更实用的乘坐体验，同时提升了第二排的腿部空间。该车型首次于去年在中国市场推出，并迅速受到欢迎，虽然埃隆·马斯克曾表示北美市场可能要到2026年底才能推出，甚至“取决于FSD的发展”，但澳大利亚市场的快速审批显示其全球推广进程正在加速。根据监管文件，Model Y L长4969毫米、宽1920毫米、高1668毫米，制动拖曳能力为1588公斤，非制动拖曳能力为750公斤，与现有Model Y规格基本一致。澳大利亚版本预计将采用双电机全轮驱动配置，电池容量约84kWh，输出功率378kW，并将配备带加热、通风和电动调节的第二排船长椅、加热第三排座椅、18扬声器音响系统、全新前排座椅以及连续可变阻尼减震器。此外，Model Y L已于2025年12月获得欧盟型式批准，历史经验表明，特斯拉在欧洲和澳大利亚的发布往往同步进行。这款车型被定位为Model X的更经济替代品，尤其是在Model X计划于今年晚些时候停产的背景下，它将成为大型家庭的“金发姑娘”解决方案，填补了特斯拉产品线中的空白。

  • 判断/建议： Model Y L的全球扩张（特别是右舵版本在澳大利亚的推出）填补了特斯拉在大型家用SUV市场的空白，尤其是在Model X即将停产的背景下，它将成为大型家庭的更实惠选择。这有助于提升Model Y的整体销量，并可能刺激其他市场对该车型的需求，但供应链和生产能力将是其全面铺开的关键制约因素。

  • Cybertruck低配版内饰曝光 特斯拉首席Cybertruck工程师Wes Morrill近日首次公布了售价59,990美元的双电机全轮驱动版Cybertruck的真实内饰照片，揭示了其成本优化后的细节。这款低配版本与之前的高级（Premium）车型相比，价格大幅下降了20,000美元，整体设计更倾向于实用且耐用的“工作卡车”风格。内饰最显著的变化体现在用料上：座椅、仪表板和门板全部采用“战术灰”纺织面料，取代了高配版本中的高级纯素皮革。成本削减还包括功能调整：前排座椅保留了加热功能，但取消了通风（冷却）功能。后排乘客的配置也进行了简化，9.4英寸的后排娱乐屏幕被完全移除，第二排座椅也不再提供加热功能。音响系统从高端的15个扬声器系统降级为更基础的7个扬声器配置，前中央扶手也经过简化设计。尽管进行了成本削减，但这款双电机全轮驱动版Cybertruck仍保留了核心实用功能，包括电动货厢盖、1.8米×1.2米的复合材料货厢以及PowerShare能力。后者提供了120V和240V的货厢插座，使其仍能为工地上的重型工具供电，确保了作为工具车的实用性。性能方面，它依然保持了与更昂贵车型相近的4.1秒0-60英里/小时加速时间，以及325英里的续航里程，但昂贵的空气悬架被替换为带自适应阻尼的螺旋弹簧。

  • 判断/建议： 推出更具性价比的Cybertruck版本是特斯拉扩大市场份额的战略举措，有助于吸引更广泛的消费者群体，特别是那些注重实用性的“工作卡车”用户。然而，内饰的大幅简化可能会影响一部分追求豪华体验的潜在买家，特斯拉需要在平衡成本和用户期望之间找到最佳点，以确保其市场接受度。

  • Model Y荣获2026年澳大利亚“年度车型”大奖 特斯拉Model Y被澳大利亚知名汽车媒体Drive评选为2026年度总冠军，获得“年度车型”大奖，这一荣誉旨在表彰“为澳大利亚新车买家带来最大进步”的车型。这一奖项是对Model Y在澳大利亚市场卓越表现的肯定，该车型在2025年已成为澳大利亚最畅销的电动车，并且在所有车型销量中位列第十。Drive的评委们特别指出，Model Y的“Juniper”更新进一步增强了其竞争力，带来了新的车主福利和扩展的软件功能。获得年度车型奖的关键因素还包括其提供的五年质保，以及每月149澳元的FSD (Supervised)订阅服务，这凸显了特斯拉在软件即服务方面的创新模式。售价从58,900澳元起（未含上路成本），Model Y被认为在性价比方面远超同尺寸的燃油和混合动力竞争对手，为消费者提供了巨大的价值。此外，Model Y车主能够方便地使用特斯拉遍布澳大利亚的超级充电网络，这一优势大大降低了消费者转向电动汽车的摩擦和焦虑。Drive杂志称赞Model Y是实用性、效率和技术在可接受价格点上完美结合的基准车型，使其成为“毋庸置疑的首选”。尽管FSD仍需要驾驶员监督，但其先进的驾驶辅助功能体现了特斯拉“软件优先”的策略，为用户提供了更智能的驾驶体验。Model Y还符合澳大利亚联邦边缘福利税豁免政策，通过租赁合同进一步提升了其对众多买家的价值主张。

  • 判断/建议： 获得权威“年度车型”奖项极大地提升了Model Y在澳大利亚市场的品牌形象和消费者信心，这将进一步巩固其在该国电动汽车市场的领导地位。奖项肯定了特斯拉在产品、技术、充电生态和软件服务方面的综合优势，有望带动Model Y在当地的销量持续增长。

  • SpaceX星舰发射获FAA年度批准 SpaceX已获得美国联邦航空管理局（FAA）的环境批准，允许其每年在佛罗里达州肯尼迪航天中心（KSC）的39A发射复合体进行多达44次星舰-超重型（Starship-Super Heavy）火箭发射。这项具有里程碑意义的批准涵盖了每年44次发射活动，以及同等数量的超重型助推器和星舰上级着陆，标志着星舰项目迈向高频次、大规模运行的关键一步。FAA的环评结论遵循了公众意见征询期，并概述了与噪音、排放、野生动物保护和空域管理相关的必要缓解措施。肯尼迪航天中心39A发射复合体的星舰基础设施建设已接近完成，该场地曾用于阿波罗和航天飞机任务，现正转型以支持星舰的运营。若能在肯尼迪航天中心及附近的卡纳维拉尔角太空部队站全面部署，太空海岸的星舰活动量每年可能超过120次，不包括测试发射。此外，美国空军已授权将太空发射复合体37号用于潜在的额外星舰活动，但尚待FAA进一步的空域分析。此次批准是SpaceX长期战略的关键一环，旨在部署一个庞大的卫星星座，为基于太空的人工智能数据基础设施提供动力，星舰的扩充运载能力是实现这一目标的核心。FAA的审查确认了高频次发射可能带来的噪音增加、氮氧化物排放以及临时空域关闭等影响，商业航班在发射窗口期间可能会经历周期性延误。然而，FAA认为这些影响将是间歇性且可控的，可通过调度、公众通知和工人安全协议进行管理。

  • 判断/建议： FAA的批准是星舰项目迈向高频次、大规模发射的重要里程碑，极大地加速了SpaceX的卫星部署和深空探索计划。这不仅对SpaceX自身的发展至关重要，也可能对全球太空产业，尤其是空间互联网和太空AI基础设施领域产生深远影响，但高频发射带来的环境和空域管理挑战仍需持续关注和解决。

  • 得克萨斯州城镇寻求Boring Company建造Loop系统 得克萨斯州伍德兰兹镇委员会近日一致批准了一项申请，正式参与埃隆·马斯克旗下The Boring Company发起的“隧道愿景挑战赛”。这项挑战赛为选定社区提供长达一英里的免费隧道建设，旨在鼓励地方政府提出创新的交通解决方案。伍德兰兹镇提出的提案名为“The Current”，计划在市中心走廊（靠近“水路”区）下方建造两条平行的12英尺直径隧道。在这些隧道中，特斯拉车辆将穿梭于水路广场、辛西娅·伍兹·米切尔表演中心、城镇绿地公园及附近的酒店之间，为乘客提供快速便捷的运输服务。城镇官员将这一隧道项目视为解决当地交通拥堵问题的有效方案，尤其是在辛西娅·伍兹·米切尔表演中心每年举办60多场大型演出期间，该区域通常会迎来高达16,500名观众，导致周边道路交通严重受阻。 “The Current”方案的设计理念与The Boring Company在拉斯维加斯会议中心下方运行的Loop系统相似，后者已成功通过地下隧道连接各个场馆和度假村，大幅提升了交通效率。The Boring Company于今年1月中旬发布了征求建议书（RFP），邀请各地城市和区域提交利用其隧道技术的本地化应用方案，伍德兰兹镇已于2月23日提交了申请。伍德兰兹镇首席运营官Chris Nunes强调，该项目目前仍处于初步阶段，但董事会已授权提交提案，以期利用这项技术应对社区挑战。这一项目不仅旨在解决交通问题，也体现了地方政府对创新基础设施建设的开放态度，以及对特斯拉车辆在新型公共交通领域应用潜力的认可。

  • 判断/建议： 伍德兰兹镇的提案如果成功，将进一步验证The Boring Company的Loop系统在城市交通解决方案中的可行性，并为特斯拉车辆拓展新的应用场景，展示未来城市交通的创新模式。这为解决城市拥堵提供了创新思路，但也面临初期建设成本、公众接受度以及长期运营维护等挑战，其推广潜力值得期待。
