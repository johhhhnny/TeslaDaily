技术进展

  • FSD (Supervised) 在瑞典的扩展测试 特斯拉已向瑞典容克平市提交申请，寻求在该市进行FSD (Supervised) 本地测试的批准。此举是公司在欧洲验证其高级辅助驾驶软件努力的一部分，以确保FSD在不同地理和交通环境下均能安全、高效运行。特斯拉此前已获得在瑞典多个城市及国家路网进行测试的许可，并由其北欧公共政策负责人Sofia Bennerstål证实对目前的测试结果感到满意。计划中的测试将使用特斯拉自有车辆，并由经过培训的安全驾驶员在必要时进行干预。这些城市测试对于收集复杂城市环境（如环岛、复杂十字路口和混合交通条件）的数据至关重要，有助于技术进步并促进未来交通系统与现实路况的融合，同时瑞典的监管协调也为试点项目提供了良好环境。

  • 判断/建议： FSD在更多区域的落地测试是其全球推广和技术完善的关键环节，有助于收集多样化数据，加速软件迭代。机会在于进一步提升FSD的鲁棒性和市场竞争力。风险在于测试过程中可能面临的监管挑战或公众安全疑虑。

  • Grok AI 助理全球部署 特斯拉已开始在澳大利亚和新西兰的兼容车辆中推出Grok AI助理，通过无线更新将其直接嵌入车载系统，此前该系统已在美国和欧洲部署。该功能适用于配备AMD处理器且软件版本为2025.26或更高版本的Model S、Model 3、Model X和Model Y车辆。Grok由埃隆·马斯克的xAI公司开发，旨在提供超越传统命令式控制的对话式语音助手，驾驶员可通过方向盘控制激活。它能够实时回答几乎任何问题，调整导航目的地，定位附近兴趣点，解释仪表盘警告，提供驾驶指导，甚至查阅用户手册。特斯拉强调，Grok的交互由xAI处理，与特定驾驶员或车辆匿名关联，且在美国地区还提供多种人格模式选择，如助手、语言导师、治疗师和故事讲述者等。

  • 判断/建议： Grok的普及显著提升了特斯拉车辆的智能化水平和用户体验，为其在车载AI助手领域树立了新的标杆。这是增强产品吸引力和市场差异化的重要机会。然而，如何持续优化AI表现、确保多语言和文化适应性，以及打消用户对数据隐私的潜在疑虑，将是特斯拉需要关注的挑战。

  • Cybertruck 主动降噪 (ANC) 功能即将启用 特斯拉已在其官网的Cybertruck配置对比工具中，悄然将主动降噪（ANC）功能列为高端全轮驱动版（Premium AWD）和赛博野兽版（Cyberbeast）的标配功能，预示着该功能即将通过软件更新启用。尽管目前所有已交付的Cybertruck均未激活此功能，但早前的拆解分析已证实其硬件配置与Model S和Model X相似，只是Cybertruck将使用四个麦克风而非六个。功能迟迟未启用，很可能与Cybertruck独特的声学环境带来的调校挑战有关，包括其巨大的玻璃车顶、铝铸件的共鸣效应以及重型全地形轮胎产生的路噪。一旦启用，ANC系统将利用车内麦克风和加速计实时监测低频噪音，并通过15扬声器系统生成反向声波，有效消除背景嗡嗡声，营造更宁静的驾乘环境。

  • 判断/建议： 启用ANC将显著提升Cybertruck的驾乘舒适性和豪华感，有助于弥补其独特设计带来的潜在噪音问题。这再次展示了特斯拉通过软件更新持续优化车辆性能的强大能力。机会在于进一步提升高端车型的用户满意度，风险在于确保ANC功能在各种复杂声学条件下的实际降噪效果达到预期。

  • 特斯拉App更新引入FSD统计数据和“FSD受影响”提示 特斯拉App的最新4.54.0版本更新预示将引入新的“自动驾驶统计数据”板块，允许用户在App内查看FSD (Supervised) 的使用情况和表现数据。目前，这些数据已可在车辆内部的“控制 > Autopilot”菜单下查看，但未来App版本将允许用户更便捷地访问并分享这些统计数据至社交媒体。此次更新还包含了一个名为“FSD受影响”的新字符串，可能与FSD运行过程中遇到的摄像头可见性问题或需要驾驶员介入的情况（俗称“strike”）有关，旨在向用户提供更清晰的FSD运行状态反馈和潜在影响因素。虽然这些功能尚未全面向所有用户开放，但特斯拉可以随时通过远程配置更新来启用它们。

  • 判断/建议： 将FSD统计数据在App中可视化，增强了用户对FSD性能和自身驾驶习惯的了解，有助于提升用户参与度和安全意识。这代表着特斯拉在FSD透明度方面的进步。机会在于通过数据反馈促进用户更安全地使用FSD，并优化驾驶行为。不确定性在于“FSD受影响”的具体触发机制及其对FSD评分或未来功能使用的影响。

  • SpaceX 星链Direct-to-Cell服务将大幅提升特斯拉高级连接功能 SpaceX已宣布其下一代Direct-to-Cell星链服务目标峰值下载速度将达到150Mbps/用户。这一显著的提升将使该服务从最初仅提供基本的紧急通信（如SOS短信和慢速消息）转变为能够直接向未改装的蜂窝调制解调器提供高速5G连接，完全绕过地面基站。SpaceX卫星政策负责人Udrivolf Pica在国际电信联盟的Space Connect会议上公布了这一雄心勃勃的目标，相比目前约4Mbps/用户的蜂窝星链服务，150Mbps的传输速率足以支持高清视频流、语音通话和数据服务等宽带应用。为实现这一容量飞跃，SpaceX正利用新获得的EchoStar无线电频谱，并计划升级现有的Direct-to-Cell卫星以增加带宽。

  • 判断/建议： 这对特斯拉车辆的高级连接（Premium Connectivity）功能具有革命性意义。未来整合升级后的星链服务，将能为特斯拉车辆提供几乎无死角的高速宽带连接，即便在传统蜂窝网络盲区也能保持流畅的在线体验。这代表着特斯拉在提升车载连接服务方面拥有巨大机会，将极大地提升用户体验和行车安全。

工厂与制造

  • 好莱坞超级充电站餐厅采用Cybertruck回收不锈钢建造 特斯拉已确认，其去年夏天在好莱坞开业的“复古未来主义”餐厅，其两层楼结构的外立面完全由Cybertruck生产过程中回收的不锈钢打造。这家位于洛杉矶圣莫尼卡大道7001号的地标性建筑，不仅是一个全天候的充电中心，拥有80个V4超级充电桩，使其成为世界上最大的城市充电站之一，更结合了创新的汽车影院功能。餐厅使用Cybertruck的“超硬不锈钢”（HFS）合金作为外墙材料，不仅赋予其独特的美学外观，更体现了特斯拉在可持续发展方面的承诺，通过循环利用生产废料来减少环境足迹，这与特斯拉广泛使用回收铝材的实践一脉相承。此举通过创新方式展示了Cybertruck的材料特性，并将其生产链中的“废料”转化为具有品牌价值的建筑元素。

  • 判断/建议： 此举是特斯拉在可持续制造和品牌营销上的双赢策略，既展现了环保理念，又强化了Cybertruck的坚固形象。机会在于提升品牌美誉度和吸引力，同时为未来产品的材料循环利用提供创新范例。

  • Model S和Model X定制选项减少，为Optimus生产让路 随着Model S和Model X车型生产线接近停产，特斯拉在线设计工作室的定制选项已开始缩减，其中“月光银”配色已显示为“售罄”，该颜色是这两款车型独有的。此举是特斯拉计划的一部分，旨在逐步淘汰这两款产量较低的“情感化”车型，并将其位于弗里蒙特工厂的部分产能重新配置，以支持Optimus人形机器人项目的大规模制造。首席执行官埃隆·马斯克曾在今年1月的第四季度财报电话会议上确认，Model S和Model X项目将“光荣退役”，以配合公司向自动驾驶未来的全面转型，并将工厂资源转向更具战略意义的Optimus制造。Model S和Model X在特斯拉年交付量中占比仅为数个百分点，减少定制选项将简化生产流程，便于工厂更顺畅地过渡到Optimus的生产。

  • 判断/建议： 这是特斯拉优化其产品组合和制造策略的明确信号，将资源集中于未来高增长项目，尤其是Optimus机器人，以实现长远战略目标。机会在于通过集中资源加速Optimus的商业化进程，提升工厂整体效率。风险在于可能流失部分对豪华轿车/SUV有需求的细分市场客户。

充电与能源

  • 特斯拉与LG Energy Solution达成LFP电池供应协议，加强北美ESS电池供应 据最新报道，LG Energy Solution (LGES) 将在其位于美国密歇根州兰辛的工厂为特斯拉生产磷酸铁锂 (LFP) 储能系统 (ESS) 电池。该兰辛工厂前身为与通用汽车的合资企业Ultium Cells 3，在LGES于2025年5月收购通用汽车的股权后，现已完全归LGES所有，并拥有每年50 GWh的强大产能。LGES正在将部分工厂改造为LFP电池生产线，预计将于明年下半年（2027年）开始大规模生产。此举被视为特斯拉努力加强其北美能源存储业务供应链的关键一步，此前特斯拉的Megapack系统主要使用宁德时代的棱柱形电池。LGES在去年7月曾披露一笔5.94万亿韩元的电池供应协议（2027年8月至2030年7月），业内消息普遍认为买家即为特斯拉。
  • 判断/建议： 这笔供应协议对特斯拉的能源存储业务具有重要战略意义，不仅实现了供应链的多元化，降低了对单一供应商的依赖，也进一步强化了北美地区的本地化生产能力。机会在于确保Megapack等储能产品的稳定、大规模交付，并可能通过本土化生产降低成本。不确定性在于新生产线的爬坡速度和实际的成本效益是否能达到预期。

市场与交付

  • Cybertruck Dual Motor AWD版从推荐计划中移除，订单需求旺盛导致交付推迟 特斯拉已将其售价59,990美元的Cybertruck Dual Motor AWD版从推荐计划中移除，这意味着新买家不再能享受1,000美元的推荐折扣，目前该政策仅适用于Premium AWD和Cyberbeast版本。此调整正值该子6万美元配置车型推出后需求激增，新订单在美国的预计交付时间已从2026年6月推迟至2026年9月至10月，表明该车型实际上已售罄至该时间段。此外，特斯拉还发出通知，该车的价格将在2月28日之后上涨，埃隆·马斯克也曾强调其介绍性价格仅限时提供。移除推荐奖励和延长的交付周期都表明特斯拉正在积极管理订单量，而非刺激需求，以保护利润，这反映出市场对这款新车型的持续强劲兴趣。

  • 判断/建议： Cybertruck Dual Motor AWD的需求异常旺盛，是市场对这款创新车型高度认可的体现，为特斯拉带来了优化定价和利润的机会。机会在于通过提价和控制销售节奏最大化每辆车的收入。风险在于长时间的等待和潜在的价格上涨可能会影响部分潜在买家的购买意愿，特斯拉需在产能和需求之间寻找平衡点。

  • 特斯拉欧洲市场销售持续下滑，比亚迪市场份额显著增长 2026年1月，特斯拉在欧洲的汽车注册量为8,075辆，同比下降17%，这是其在该地区连续第13个月的同比销量下滑。特斯拉的市场份额也从一年前的1.0%降至0.8%，远低于2025年12月的3.0%。尽管同期欧洲电动汽车（BEV）市场整体呈现近14%的增长，但特斯拉未能从中受益。相比之下，中国汽车制造商比亚迪在1月份注册了18,242辆，同比增长165%，市场份额达到1.9%，首次在欧洲销量上大幅超越特斯拉。分析指出，特斯拉目前仅销售纯电动车型，而包括比亚迪在内的竞争对手提供BEV和插电式混合动力（PHEV）车型组合，且特斯拉在欧洲的产品线主要集中在Model 3和Model Y，面临着更多低成本竞争者的冲击。

  • 判断/建议： 特斯拉在欧洲市场面临严峻挑战，其单一的纯电动车型策略和有限的车型选择使其在面对多元化产品线及更具价格优势的竞争对手时处于劣势。这是一个需要高度警惕的风险信号。特斯拉亟需重新审视其欧洲市场策略，考虑引入更经济的车型、加快车型更新迭代或提升Model 3/Y的竞争力以应对市场变化。

  • 加拿大租赁政策悄然更新，部分客户或可购买租赁期满车辆 特斯拉在加拿大悄然修改了其租赁期末购买政策，可能为部分客户提供在租赁期结束后购买车辆的机会，这在此前的大多数车型上是受限的。特斯拉加拿大支持网站上的措辞已更新，不再有之前针对Model 3、Model Y以及2022年4月15日之后交付车辆的明确限制。旧政策严格禁止Model 3和Model Y的租赁购买，且不允许第三方经销商或个人购买租赁车辆。新的条款建议客户在租赁期结束时联系特斯拉，以了解可用的选择。虽然特斯拉尚未正式宣布，但这一变化意味着公司可能正从一刀切的禁止购买政策转向更灵活的个案处理，此举有望提升客户满意度并增加车辆保有量，一些车主报告称已开始以个案形式进行购买。

  • 判断/建议： 这一政策调整是积极的，为特斯拉在加拿大的客户提供了更多灵活性和选择权，有助于提升租赁服务的吸引力并可能增加租赁车辆的生命周期价值。机会在于提升客户满意度和忠诚度，并可能为公司带来新的营收来源。不确定性在于新政策的全面实施细则、适用范围以及对新车销售可能产生的影响。

  • Rivian R2将直接挑战特斯拉Model Y在中型电动SUV市场的领先地位 随着特斯拉Model Y在去年进行了改款，而Rivian正积极准备其2026年R2车型的量产，中型电动SUV市场的竞争将进一步加剧。Rivian R2旨在将R1的坚固探险基因缩小为更小、更实惠的量产车型，直接瞄准Model Y的主导地位。尽管特斯拉Model Y凭借优化的制造流程和规模经济，具有极具竞争力的起售价（标准后驱版39,990美元），但Rivian R2的单电机后驱版预计起售价约为45,000美元，长续航双电机全驱版约为55,000美元，三电机性能版将超过60,000美元。两款车型均为美国本土生产，符合美国的州级激励政策，但在加拿大，Model Y需进口，两者均不符合新的联邦电动车补贴标准，但可能符合省级补贴。R2在设计理念上与Model Y截然不同，它是一款专注于内部存储空间的传统方正SUV。

  • 判断/建议： Model Y的市场领导地位将面临来自Rivian R2等新竞争者的直接挑战。虽然Model Y在价格上仍有优势，但R2独特的硬派SUV设计理念将吸引不同偏好的消费者。特斯拉需要持续创新并保持成本竞争力，以巩固其市场份额。

其他值得一提

  • 特斯拉向美国专利商标局挑战“Cybercab”商标主张 特斯拉已向美国专利商标局（USPTO）商标审判和上诉委员会提交正式异议，挑战法国饮料公司UNIBEV对“Cybercab”商标的注册主张。UNIBEV在2024年10月28日提交的申请早于特斯拉在11月的申请，导致特斯拉的申请被暂停。特斯拉指控UNIBEV存在欺诈、恶意提交以及试图利用特斯拉“Cyber”品牌系列产品知名度的行为。特斯拉在2024年10月的“We, Robot”活动中已公开展示“Cybercab”，并认为UNIBEV在申请时谎称没有其他公司使用类似品牌。特斯拉还质疑UNIBEV是否有生产车辆或交通服务的真实意图，暗示这可能是一种商标囤积策略，旨在高价出售。此次商标争议并非两家公司的首次冲突，UNIBEV此前已控制其他与“Cyber”相关的商标。
  • 判断/建议： 这场商标争议对特斯拉未来的自动驾驶出租车（robotaxi）服务品牌至关重要，是保护其知识产权和市场策略的关键一步。机会在于成功捍卫品牌权，为未来Cybercab的推出扫清障碍。风险在于，如果未能胜诉，可能需要重新命名或支付巨额费用，从而影响未来产品线的规划和市场推广。
