技术进展

1. Cybertruck事故数据揭示自动驾驶系统在碰撞前已脱离

特斯拉首席执行官埃隆·马斯克近日亲自澄清了2025年8月发生的一起Cybertruck碰撞事故，驳斥了主流媒体关于Autopilot系统导致事故的说法。马斯克在X上明确指出，车辆内部日志数据显示，驾驶员在碰撞发生前4秒就已经解除了Autopilot（或FSD，因为Cybertruck并未搭载Autopilot）。这表明在事故关键时刻，车辆处于完全手动控制之下，而非自动驾驶系统故障所致。

这一信息直接挑战了原告提出的100万美元索赔诉讼的核心主张，即特斯拉的驾驶辅助系统失灵导致了事故。尽管视频片段显示Cybertruck曾一度遵循高架桥的曲线行驶，随后突然直行甚至加速撞向护栏，这可能暗示驾驶员存在判断失误或反应迟滞。

判断： 特斯拉通过公开内部数据维护了其自动驾驶系统的声誉，有效驳斥了不实指控，有助于提升公众对FSD/Autopilot透明度的信任。然而，此类事件仍可能引发关于驾驶员责任与ADAS系统界限的讨论，特斯拉需在技术沟通上持续发力。

2. Cybercab生产单元升级：新增物理充电口与无障碍座椅设计

特斯拉正在紧锣密鼓地为Cybercab的发布做准备，最新的生产单元显示出重要的改进。新曝光的自动驾驶两座车模型展示了经过显著升级的物理充电接口，并且在设计中充分考虑了无障碍需求，有望成为城市出行领域的变革者。特斯拉计划于下月（4月）在得克萨斯超级工厂启动Cybercab的批量生产，这些调整表明车辆正从实验性概念转向实际的可靠性考量。

最大的硬件惊喜来自充电系统，尽管特斯拉此前曾暗示Cybercab将完全依赖无线感应充电，但最近的生产单元被发现配备了一个更加“成熟”的物理充电口。该新接口采用更简洁的门设计，带有完整的密封垫和灵活的外壳，不再需要防风雨塞，这与之前的原型机有显著不同，显得更为精致。非电动翻盖设计可能旨在优化制造成本和更换成本。鉴于量产在即，这一物理NACS接口的出现预示着Cybercab将首先采用传统插电式充电，无线充电功能可能作为后续升级选项。

此外，特斯拉Cybercab工程负责人Eric E.证实，该车型的座椅高度与标准轮椅座椅高度保持一致，旨在确保行动不便乘客也能便捷使用。

判断： Cybercab在推出前夕转向更务实的物理NACS充电接口，并融入无障碍设计，显示了特斯拉致力于确保其Robotaxi服务的实用性和广泛可及性。这些改进是为未来大规模商业部署打下坚实基础的关键步骤，有助于最大化市场潜力。

3. 软件更新2026.8推出“查看驾驶员”功能，提升车辆管理透明度

特斯拉已开始推出其最新软件更新版本2026.8，除了为焕新Model Y带来“舒适制动”等新功能外，还发现了一项实用且未公开的改动——首次允许车主通过Tesla App直接查看车辆当前激活的驾驶员配置文件。这项简单但重要的功能为多驾驶员家庭带来了新的透明度层级，让车主能够一目了然地知道谁正在驾驶车辆。

此功能在车辆行驶时，应用会实时显示正在使用的驾驶员配置文件的名称；当车辆停泊并处于休眠状态时，则显示最后一位使用车辆的驾驶员配置文件。这对于家庭或企业共享车辆的场景尤为有用，尽管任何人在未设置PIN码保护的情况下都可以切换配置文件，但这项新功能通常能准确反映车辆的使用者。

判断： 这项软件更新通过在应用中显示当前驾驶员配置，显著提升了多车家庭的用户体验和车辆管理透明度。它进一步强化了特斯拉的云端互联生态系统，并为车辆共享场景提供了实用价值。

4. Robotaxi应用更新预示安卓版将至，并优化目的地设置

特斯拉的Robotaxi应用已更新至26.2版本，其中包含的代码强烈暗示安卓版本的发布已近在咫尺。新的代码短语涵盖了安卓原生“预计到达时间”、“到达目的地”等提示信息。这意味着特斯拉正积极为将服务扩展到更广泛的智能手机用户群体做准备。

此外，此次更新还改进了地址管理功能，包括添加“家庭”和“工作”地址，并增加了地址验证功能。这些家庭和工作地址很可能会自动从用户的特斯拉账户中获取，与车辆中已有的地址同步，得益于特斯拉的云端配置文件系统。

判断： 特斯拉Robotaxi应用更新预示着安卓版本的即将发布，这将显著扩大其潜在用户群体。同时，地址管理功能的优化将提升用户体验，这些都是为未来Robotaxi大规模部署所做的关键准备。

5. Uber创始人暗示特斯拉Roadster将带来“魔法般”功能，吊足胃口

在经历了多年的等待之后，特斯拉Roadster计划于4月底正式亮相。Uber创始人特拉维斯·卡兰尼克最近根据其从特斯拉内部人士那里听到的消息，暗示了Roadster潜在的“魔法般”功能，这或许会让漫长的等待变得值得。此前，埃隆·马斯克曾多次表示Roadster将是前所未有的产品，可能实现约1秒的0-60英里/小时加速，甚至可能具备悬浮和SpaceX冷气推进器技术。

卡兰尼克在X上表示：“当我遇到那些知情人士时，我询问情况，他们什么也没说，但他们的眉毛扬起，眼睛睁大，这只能意味着某种巫术和魔法即将来临……”马斯克也曾指出，这款车并非以安全为首要目标，并警告“如果安全是你的头号目标，不要购买Roadster。”

判断： Roadster的持续延期伴随着惊人的性能预期，尽管其“魔法”特性令人期待，但也提醒了特斯拉在兑现承诺方面的挑战。若最终产品能满足或超越这些传闻，将极大提升特斯拉的品牌形象和技术实力认知。

工厂与制造

1. 特斯拉通过“爆炸视图”展示Model Y制造工艺，突出一体化压铸优势

特斯拉正通过其创新制造工艺的透明化展示，进一步拉开行业帷幕。近日，有X用户分享了在中国展出的Model Y“爆炸视图”解构模型，这种独特的展示方式让参观者能够清晰地看到这款全球最畅销电动车从裸金属框架到复杂内部布线是如何组装在一起的。这种展示方式也在欧洲的特斯拉交付中心出现，旨在凸显特斯拉在汽车制造领域的领先专业技术。

在解构视图中，最令人印象深刻的部分是特斯拉革命性的“一体化压铸”（Gigacasting）工艺。传统上，汽车车架由数十个小型冲压金属部件焊接而成，而特斯拉则利用大型压铸机（即Gigapress）生产出车辆前后部的大型单件铝结构。这项技术颠覆了传统制造模式，显著简化了组装过程，降低了制造成本，并大幅减轻了车身重量。

判断： 特斯拉通过展示解构Model Y，直观地揭示了其一体化压铸（Gigacasting）等创新制造工艺的优势，证明了其在简化生产、降低成本和提高车辆性能方面的领先地位。这种透明化展示有助于巩固品牌形象，并促进行业对先进制造技术的借鉴与发展。

2. 特斯拉指控前供应商窃取4680电池技术，并已采取法律行动

一场围绕特斯拉严密保护的“干电极（DBE）”技术（4680电池核心技术）的高风险法律战已演变成公开的口水仗。在2026年2月13日的一项临时仲裁裁决之后，前供应商Matthews International发布新闻稿声称取得了对特斯拉的法律胜利，但特斯拉副总裁Bonne Eggleston立即在X上回击，向汽车行业发出严厉警告，并称Matthews的主张是无稽之谈。

Eggleston直接反驳了Matthews对禁令的解读，透露特斯拉实际上“抓到该供应商正在公然复制我们的技术——包括专有软件和敏感机械设计——并将其用于为其他客户生产产品”。他进一步指控Matthews在三年内谎报盗窃行为，同时继续将特斯拉的技术交付给竞争对手。

判断： 特斯拉与供应商Matthews International之间的4680电池技术纠纷凸显了其核心制造技术的巨大商业价值。若特斯拉的指控属实，这将有效保护其在电池技术领域的竞争优势，但也提醒了供应链安全和知识产权保护的重要性。

市场与交付

1. Model Y蝉联全球最畅销车型三年，全球销量突破400万辆

特斯拉Model Y已连续第三年（2023、2024和2025年）巩固其在全球汽车市场的领先地位，不仅在电动汽车领域，而且在所有乘用车中都占据主导地位。这一里程碑由特斯拉中国公司通过微博确认，并引用了JATO Dynamics（2023）、Statista（2024）和Focus2Move（2025）等公司的数据。与此同时，这款纯电动SUV的全球累计交付量已突破400万辆，对于一款自2021年才开始销售的车型来说，这是一项罕见的成就。

Model Y于2023年首次登顶全球销量榜首，成为首款销量超越丰田卡罗拉和RAV4等传统燃油车型的纯电动汽车。尽管市场竞争日益激烈，市场动态不断变化，以及特斯拉今年早些时候在全球工厂协调推出了新款车型，Model Y仍在2024年和2025年保持了领先地位。

判断： Model Y持续的全球领导地位是特斯拉在电动汽车市场取得的巨大成功，证明了其产品的吸引力和市场接受度。这一成就巩固了特斯拉在全球汽车行业中的颠覆者形象，并为未来新车型设定了高标准。

2. 2026年2月特斯拉中国销量强劲反弹，Model Y领跑市场份额

最新数据显示，特斯拉在中国这一关键市场正重新获得增长势头。2026年2月，特斯拉在中国的零售销量同比增长43%至38,206辆，尽管整个汽车市场显示出放缓迹象。其中，Model Y是推动这一增长的主要动力，其销量较去年同期猛增216%至25,286辆，比1月份增长了50%以上。

这一强劲反弹推动特斯拉在中国纯电动汽车（BEV）市场的份额达到13.74%，创下近两年来的新高。尽管Model Y在全球取得了巨大成功，但它正面临日益激烈的竞争，尤其是在中国市场。本土汽车制造商不断扩大其产品线，1月份小米SU7 SUV甚至超越Model Y成为当月中国最畅销的电动汽车。

判断： 特斯拉2月在中国市场的销量大幅反弹，特别是Model Y的强劲表现，表明其在关键区域市场的策略正取得成效。然而，中国本土品牌（如小米）的崛起预示着竞争将持续白热化，特斯拉需不断创新并优化产品，以应对日益复杂的市场格局。

其他值得一提

1. Cybertruck获得“防开门碰撞保护”功能，提升行人与骑行者安全

特斯拉宣布通过2026.8软件更新，为Cybertruck推出了期待已久的创新“防开门碰撞保护”功能。这项安全增强功能旨在提升行人、骑行者以及其他车辆的安全。该系统利用车辆现有摄像头探测盲区内接近的骑行者、行人或车辆。当驾驶员尝试开门时，如果检测到危险，系统会立即启动：盲点指示灯闪烁、发出声音警报，并且初次按压车门按钮时门不会打开。驾驶员需要短暂等待并再次按下按钮才能强制开门，从而提供宝贵的几秒钟来避免事故发生。

这项功能，也称为“停车时盲点警告”，已成为所有新款Model 3和Model Y的标准配置，现在也扩展到了Cybertruck。该技术利用特斯拉基于视觉的系统，无需新的硬件，是一种经济高效的软件解决方案，并且在2018年就有人提出过类似建议。

判断： 为Cybertruck引入“防开门碰撞保护”功能，体现了特斯拉在利用软件提升车辆安全方面的持续努力。这项功能通过智能预警有效降低“开门杀”事故风险，进一步巩固了特斯拉在安全技术方面的创新形象。

2. 加拿大皇家骑警（RCMP）在电动警车测试中高度赞扬特斯拉Model Y

加拿大皇家骑警（RCMP）正在持续扩大其电动汽车（EV）车队，本拿比成为最新一个测试电动巡逻车的区域，这是联邦试点项目的一部分，旨在评估电动汽车是否能满足前线警务需求。西岸皇家骑警已经测试了多款电动汽车，包括特斯拉Model Y、福特Mustang Mach-E和F-150 Lightning。在这些车型中，Model Y脱颖而出，备受警官喜爱，他们赞扬其卓越的性能、瞬时扭矩和便捷的充电方式。

事实上，此前对电动汽车在警务场景中电池续航限制的担忧，在很大程度上被证明是没有根据的。警官们报告称，续航里程足以满足日常使用，充电也能够无缝融入轮班工作。

判断： 特斯拉Model Y在加拿大皇家骑警的实际测试中获得高度认可，其出色的性能和实用性得到了验证。这一来自官方机构的积极反馈，不仅提升了Model Y的公共形象，也可能为其在政府和企业车队市场带来新的机遇。

3. 宝马发布2027款全新i3电动轿车，以卓越续航与快充能力挑战市场

宝马揭示了全新的2027款i3，标志着这一铭牌的重大转变，它将以一款纯电动运动轿车的身份回归。与最初的紧凑型掀背车不同，这款新i3被定位为3系车型的电动版，预示着宝马将其核心产品线带入电动汽车时代的新一步。首发车型i3 50 xDrive基于宝马全新的Neue Klasse平台打造，配备双电机、全轮驱动，提供463马力和476磅-英尺的扭矩。

续航里程是另一个亮点——宝马表示，根据初步的EPA测试结果，新款i3的续航里程可达708公里（440英里），而由于其800伏架构，快充峰值功率高达400千瓦。该公司还称，在理想条件下，该车可在短短10分钟内增加约400公里（250英里）的续航里程。

判断： 宝马全新i3的发布标志着传统豪华品牌在高性能电动轿车领域的强劲反击，其卓越的续航里程和超快充电能力将对特斯拉构成直接竞争。这预示着电动汽车市场的竞争将更加激烈，促使特斯拉继续创新以保持优势。
