技术进展

Robotaxi服务大规模扩张至德克萨斯州，无人监管模式加速落地。 特斯拉今日宣布，其Robotaxi服务已正式在德克萨斯州的达拉斯和休斯顿上线，并且令人意外的是，这两座城市的服务一开始便采用了无人监管模式。此举使得特斯拉在德克萨斯州的运营足迹扩大至奥斯汀、达拉斯和休斯顿三个主要城市，显著提升了其在该州的覆盖范围。在服务启动初期，休斯顿的地理围栏区域覆盖了约12至15平方英里（主要在泽西村和柳溪区），而达拉斯的服务区域则更大，约30至35平方英里，涵盖了城市核心区和公园城。这一模式与特斯拉在奥斯汀的经验有所不同，奥斯汀最初是小范围有监督试点，随后才迅速扩展了其地理围栏，从最初的20平方英里飙升至约245平方英里。 特斯拉此次在德州两大城市直接采用无人监管模式，表明其对FSD（全自动驾驶）技术的信心显著增强，并可能反映了其在奥斯汀及旧金山湾区积累的宝贵经验。德克萨斯州有利的法规环境、旺盛的出行需求以及相对简单的城郊驾驶模式，为特斯拉的自动驾驶服务提供了理想的早期规模化应用场景。此举不仅有助于特斯拉更快地收集真实世界数据、优化算法，也为其在2025年第四季度财报中提及的2026年上半年在美国七个城市（包括菲尼克斯、迈阿密、奥兰多、坦帕和拉斯维加斯）推出Robotaxi服务的计划奠定了坚实基础。 短期来看，市场对特斯拉Robotaxi的商业化前景将抱有更高期待，这无疑是FSD技术商业化进程中的一个重要里程碑。然而，直接采用无人监管模式也意味着潜在的公共安全和法律风险更高，特斯拉需要确保其系统的稳定性和可靠性达到极致。这既是特斯拉抢占未来出行市场的巨大机遇，也对其技术成熟度提出了严峻考验。

特斯拉春季更新推送Robotaxi后排互动导航功能，预示未来自动驾驶体验。 随着2026年春季更新（版本2026.14+）的推出，特斯拉已开始向现有车主车辆推送一项此前仅限于Robotaxi车队的创新功能：后排乘客显示屏上的交互式导航地图。这一更新让Model S、Model X、Model 3、Model Y和Cybertruck的后排屏幕从简单的媒体和气候控制界面，升级为具备实时、可操作导航能力的乘客中心。此前，特斯拉的后排显示屏功能相对有限，而现在则能够提供与驾驶员屏幕类似的导航体验。 这项功能的推出，被视为特斯拉为即将发布的Cybercab（Robotaxi专车）进行软件测试和用户习惯培养的重要一步。在完全自动驾驶的Robotaxi中，车内不再有驾驶员，因此每位乘客都需要直观、实时的地图访问权限，以便了解行程信息和目的地。通过提前在现有数千辆车主车辆上部署这一界面，特斯拉正在实际条件下对软件进行压力测试，并让忠实客户提前体验未来自动驾驶世界的冰山一角。 这一策略完美契合了埃隆·马斯克（Elon Musk）长期以来强调的“先推出配套基础设施，再发布新产品”的理念。尽管目前更新范围尚小，但预计将在未来几周内迅速扩大，甚至将于5月开始交付的Signature Edition Model S和X Plaid也将搭载此项技术。此举不仅提升了现有车型的用户体验，更为特斯拉未来的出行服务生态系统构筑了坚实的用户界面基础，展现出特斯拉在自动驾驶领域的前瞻性布局。

充电与能源

特斯拉提供多样化的家庭充电解决方案，满足不同用户需求。 对于电动车车主而言，从传统加油站模式转向家庭充电是最大的生活方式转变之一。特斯拉为此提供了两款主要的家庭充电设备：Wall Connector（壁挂式连接器）和Mobile Connector（移动连接器），以适应不同的充电需求和安装条件。Wall Connector零售价约为450美元，专为希望获得最快住宅充电速度的独栋住宅用户设计。它通过专用60安培电路可提供高达48安培的连续功率，以Model Y为例，每小时可增加约44英里的续航里程。Wall Connector还具备Wi-Fi连接功能，允许用户通过特斯拉App限制充电车辆、设定充电时间，并获得详细的充电数据分析。 然而，Wall Connector的安装成本相对较高，通常需要专业电工进行硬线连接，安装费用介于500美元至2,000美元以上，具体取决于安装距离和是否需要升级家庭配电盘。对于寻求更经济或更灵活方案的用户，Mobile Connector是一个出色的选择，零售价约为300美元。这是一款便携式设备，可以通过更换适配器插头来匹配各种电源插座，提供了更高的灵活性。 特斯拉提供这两种充电方案，旨在解决电动车普及过程中用户最核心的“充电焦虑”问题。Wall Connector代表了高性能和智能化的固定充电解决方案，适合高强度使用需求的用户；而Mobile Connector则强调了便携性和经济性，满足了日常通勤或租房用户的基本需求。这两种方案共同构成了特斯拉完善的充电生态系统，降低了电动车的使用门槛，是推动电动车普及的重要一环。

市场与交付

特斯拉推出限量版Signature Model S/X，并施加严苛转售限制以打击投机行为。 特斯拉日前为Signature Model S和Model X Plaid推出了限量生产版本，每款车型仅制造250辆，定价高达159,420美元。这些独占车型配备了定制功能和完整的Luxe Package（豪华套件），但购买者在交付前必须签署一份具有约束力的合同，规定车辆在交付后一年内不得转售。若违反此条款，特斯拉将追讨50,000美元或转售所得全额（以较高者为准）的违约金，并保留拒绝未来向违约者销售车辆的权利。此外，即使在一年禁售期结束后，Luxe Package的关键元素也不随车辆转让。 此举旨在确保这些最终的旗舰车型能真正落入热爱特斯拉的收藏家手中，而非被投机者利用短期转售牟取暴利。随着Model S和Model X的生产逐渐减少，特斯拉正将重心转向擎天柱（Optimus）机器人等下一代项目。这一策略反映了特斯拉对品牌形象和客户体验的重视，尤其是在其产品生命周期末端推出的限量版车型，更需维护其独特性和价值。 短期内，这一严格的转售协议可能会筛选掉部分纯粹出于投资目的的买家，从而维持限量版车型的市场稀缺性和价值。然而，过度限制也可能引起部分高净值买家的不满。长期来看，这有助于巩固特斯拉作为创新者和品牌维护者的形象，但对于那些希望在未来获得更灵活的转售价值的客户来说，这无疑增加了不确定性。

彭博社报告揭示Cybertruck销量受内部采购提振，定价问题成销售瓶颈。 据彭博社报道，特斯拉Cybertruck在2025年第四季度的销售数据，很大程度上得益于埃隆·马斯克（Elon Musk）旗下公司（尤其是SpaceX）的内部采购。报告指出，在该季度美国注册的7,071辆Cybertruck中，SpaceX贡献了1,279辆，占比超过18%。马斯克旗下的其他公司，包括xAI、Boring Company和Neuralink，同期也采购了60辆。这些内部采购的总价值超过1亿美元，并且这一趋势在2026年仍在继续。如果没有这些内部销售的支撑，Cybertruck在该季度的销量将骤降51%。 这款曾被誉为“特斯拉有史以来最好产品”的电动皮卡，因其高于预期的价格而未能达到最初的市场预期。Cybertruck在2019年首次亮相时，曾公布39,990美元、49,990美元和69,990美元的配置价格。然而，直到2023年才开始交付，实际售价显著上涨，导致许多最初预订平价配置的买家因价格上涨而被拒之门外。行业分析师Sam Fiorani表示，特斯拉可能正面临Cybertruck买家枯竭的困境，并非没有买家，而是许多潜在客户无法承受当前的价格。 内部采购虽然在短期内提振了账面销量，但长期来看，Cybertruck的定价策略及其有限的可用性仍是其扩大市场份额的巨大挑战。这表明特斯拉在高端小众市场表现强劲，但在大众市场吸引力受阻。未来Cybertruck的销售表现将高度依赖于产能提升、成本优化以及是否能推出更具竞争力的定价，以吸引更广泛的消费者群体。

特斯拉起诉北达科他州，挑战直销禁令以扩展市场足迹。 特斯拉已正式对北达科他州提起诉讼，旨在挑战该州长期以来要求汽车制造商通过独立的第三方特许经销商销售产品的法律，以争取在该州的俾斯麦（Bismarck）和法戈（Fargo）开设其首批两家展厅和服务中心。北达科他州的法律目前将“制造商”定义为组装或进口车辆并将其出售给州内经销商进行转售的实体。特斯拉辩称，由于其直接向消费者销售产品，根本不使用第三方经销商，因此在法律定义上不属于该“制造商”范畴。目前，北达科他州超过800名特斯拉车主不得不驱车前往明尼苏达州或其他州才能提车或享受特斯拉官方服务。 特斯拉的律师Ari Holtzblatt指出，特斯拉只是希望能够直接在该州销售车辆，避免客户为购车或服务而被迫离州。然而，该州助理总检察长Michael Pitcher则认为，特斯拉可以通过任命经销商并签订特许经营协议来在该州运营，与其他制造商别无二致。这场诉讼的核心在于挑战传统的经销商特许经营模式，特斯拉此前已在美国多个州成功推翻或争取到直销例外，为Rivian和Lucid等其他电动车初创公司也铺平了道路。 这场法律战是特斯拉在全球市场扩张中常见的壁垒，胜诉将为特斯拉在北达科他州打开直销和服务的通道，提升当地客户体验，并可能影响其他仍在坚持类似禁令的州。这将巩固特斯拉的直销模式优势，但法律进程本身充满不确定性，需要投入大量资源和时间。
