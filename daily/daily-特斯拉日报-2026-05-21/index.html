技术进展

1. 自动驾驶竞争格局演变：Wayve与Stellantis合作

自动驾驶领域竞争持续升温，英国自动驾驶初创公司Wayve宣布与汽车巨头Stellantis达成合作，计划自2028年起为Stellantis在北美市场的多款车型提供L2+级别的自动驾驶技术。这项合作是在Wayve近期成功完成12亿美元D轮融资后宣布的，该轮融资吸引了包括日产、Stellantis、微软和英伟达在内的重量级投资者。Wayve的技术核心在于其端到端神经网络驱动的软件，该方案不依赖特定传感器、芯片或高精度地图，这对于寻求降低成本并快速部署自动驾驶功能的传统汽车制造商具有显著吸引力。Stellantis计划到2030年在北美推出11款新车型，其中7款售价低于4万美元，这为Wayve的技术提供了广阔的潜在市场。

此次合作标志着传统车企在自动驾驶技术路径上的多元化探索，也为特斯拉的FSD系统带来了新的竞争维度。Wayve与特斯拉在端到端AI和视觉为主的感知方案上有相似之处，但其硬件无关性的策略可能使其在与不同制造商合作时更具灵活性。对于特斯拉而言，这意味着除了Waymo、Cruise等L4级竞争者外，还需要应对在L2+级别辅助驾驶市场中出现的、技术路线相似但商业模式不同的对手。

判断与建议： 行业竞争加剧是必然趋势，特斯拉需持续巩固其FSD的技术领先性，特别是在泛化能力和成本控制上。同时，也应关注不同技术路线的融合与创新，以便在未来的自动驾驶市场中保持核心竞争力。

2. 自动驾驶挑战凸显：Waymo遭遇恶劣天气困境

作为自动驾驶行业的先驱之一，Waymo近日再次遭遇挫折，因其自动驾驶出租车在亚特兰大遭遇洪水后受困，公司被迫暂停在该市的服务。此前，Waymo也曾因类似问题暂停在圣安东尼奥的服务，并于上周针对软件缺陷发布召回，承诺更新车辆以避免洪水区域。然而，周三在亚特兰大，一辆Waymo车辆在遭遇突如其来的强降雨后，仍驶入被淹路段并被困长达一小时，这表明其“最终解决方案”尚未奏效。Waymo坦承，即使采取了预防措施，面对极端天气时的实时判断能力仍是巨大挑战。此外，Waymo此前还因车辆非法绕过校车问题，正在接受美国国家公路交通安全管理局（NHTSA）和国家运输安全委员会（NTSB）的调查。

Waymo在应对复杂天气和特殊路况时暴露出的问题，凸显了L4级自动驾驶技术在实际部署中的巨大挑战和局限性。这些事件不仅可能拖慢Waymo的商业化进程，也对公众对自动驾驶技术的信任度造成负面影响。对于特斯拉而言，尽管其FSD主要面向L2/L3级辅助驾驶，但Waymo的经历也提供了重要教训：自动驾驶系统在非理想环境下的鲁棒性和安全性是决定其成功与否的关键。

判断与建议： 自动驾驶技术距离完全成熟仍有漫长的路要走，尤其是在应对极端环境方面。特斯拉的FSD应持续致力于提升在各种复杂场景下的表现，包括恶劣天气和非常规路况，并以透明、负责任的态度处理安全问题，从而赢得用户信任，避免重蹈竞争对手的覆辙。

3. SpaceX AI计算巨额协议及其行业启示

SpaceX近日披露了与人工智能公司Anthropic之间的一项里程碑式计算资源协议的财务细节，揭示了AI领域对高性能计算能力的巨大需求。根据协议，Anthropic将每月支付12.5亿美元，总计近450亿美元，以独家使用SpaceX的Colossus AI集群。该集群包括Colossus I和Colossus II，共计拥有超过20万块NVIDIA GPU，并提供数百兆瓦的电力支持，是目前人工智能领域最大的计算资源交易之一。这项为期三年的协议将持续到2029年5月，旨在为Anthropic提供训练和运行其前沿AI模型所需的强大算力。值得注意的是，SpaceX在公告中提到，公司正“追随特斯拉的脚步”进入人工智能领域。

这项交易不仅为SpaceX带来了可观的经常性收入，也使其在市场认知中从一家太空探索公司扩展至人工智能基础设施提供商，彰显了其在快速部署大规模、高性能计算基础设施方面的能力。对于特斯拉而言，尽管这是SpaceX的商业活动，但它深刻反映了埃隆·马斯克旗下公司对AI算力战略性投入的共识。特斯拉自身也在通过开发Dojo超级计算机来构建专有的AI训练硬件，此协议的签署，侧面印证了自建或掌握大规模AI算力对于维持人工智能技术领先地位的关键重要性，同时也凸显了NVIDIA GPU在当前AI算力市场中的核心主导地位。

判断与建议： AI算力已成为人工智能发展的核心瓶颈。特斯拉应加速Dojo超级计算机的部署和优化，以确保FSD训练能够持续获得充足且高效的计算资源，从而避免对外部供应商的过度依赖，并在未来为Dojo的商业化探索提供更多可能性。

市场与交付

1. Model S/X Signature Edition交付，告别传奇车型

2026年5月20日，特斯拉在弗里蒙特工厂举行了一场情感复杂的Model S和Model X Signature Edition独家交付活动，标志着这两款传奇旗舰车型正式结束生产。此次活动共交付了最后350辆特别定制版车辆，其中包括250辆Model S和100辆Model X。每辆车的售价高达159,420美元，均为顶级的Plaid性能版本，并采用了专属的石榴石红漆面，搭配碳陶瓷刹车和金色装饰，内饰也进行了高级定制，同时配备了特斯拉的Luxe套装，确保车主获得最顶级的配置体验。在活动中，埃隆·马斯克及其他高管深情回顾了Model S和Model X过去十多年的辉煌历程，强调这两款车型如何将电动汽车从“缓慢、无聊的高尔夫球车”的刻板印象，彻底转变为高性能、零妥协的“路上最佳汽车”。

Model S曾创下多项行业第一，包括首款续航里程达到400英里的电动汽车、首款0-60英里/小时加速时间低于2秒的量产车以及首款在高速公路安全管理局（NHTSA）测试中屋顶强度突破测试机器上限的车型。Model X也曾是加速最快的量产SUV，并首次在监管测试中实现零翻滚。这两款车型不仅自身取得了巨大成功，更对整个汽车行业产生了深远影响，激发了其他汽车制造商对电动汽车的信心和投入，推动全球电动汽车年销量从2011年的5万辆飙升至如今的2100万辆。目前生产的Model S和Model X与最初版本相比，零部件数量减少了40%，仅有3%的零部件与2012年和2015年的原版共享，充分展现了特斯拉在制造工艺和技术迭代上的持续进步。

判断与建议： Model S和Model X的停产，象征着特斯拉一个时代的终结，也预示着公司将战略重心转移至下一代产品和更具市场潜力的领域。此举虽然具有历史意义，但也提醒投资者关注特斯拉未来的产品路线图和新的增长引擎，例如即将推出的Robotaxi或更经济型车型。公司应在告别传奇车型的同时，继续秉持其创新精神和高性能标准，以维系品牌魅力。

其他值得一提

1. SpaceX Starship V3首次集成飞行测试

2026年5月21日，SpaceX再次刷新太空探索的里程碑，成功进行了其Starship V3（星舰V3）的首次集成飞行测试（IFT-12）。此次发射是升级版Starship V3配置的官方首次亮相，新版本在尺寸上更大，结构进行了显著改进，燃料容量也得以增加，并搭载了下一代更强大的Raptor 3引擎。更值得关注的是，本次发射是首次从位于德克萨斯州博卡奇卡星际基地新建的二号发射台进行，标志着SpaceX在发射基础设施建设方面取得了重要进展。在这次亚轨道飞行中，SpaceX的主要测试目标包括部署20颗模拟Starlink卫星的载荷模拟器，以验证星舰作为卫星部署平台的潜力。尽管V3是重大升级，但此次测试中，助推器将安全地在墨西哥湾进行消耗性降落，不会进行回收，以优先收集飞行数据。发射窗口于美国中部时间下午5:30（东部时间下午6:30）开启，全程通过SpaceX官方平台进行直播。

此次星舰V3的首飞，不仅是SpaceX在实现火星殖民和大规模太空运输愿景上的关键一步，也展示了马斯克旗下公司在尖端工程和快速迭代方面的卓越能力。虽然这是SpaceX的事件，但作为特斯拉的姐妹公司，两者在技术理念、工程文化和创新精神上存在共通之处。星舰项目的成功，无疑会增强公众和投资者对马斯克及其“不可能”愿景的信心，进而对特斯拉的品牌形象和市场预期产生积极的间接影响。

判断与建议： SpaceX的工程壮举持续巩固了马斯克作为科技创新领袖的地位。对于特斯拉而言，这意味着其领导者在多个前沿领域同时推进，但也可能引发对马斯克精力分配的持续关注。建议特斯拉专注于自身核心业务的创新和交付，以应对市场和投资者的期望，同时可探索与SpaceX在材料科学、AI等领域的潜在协同效应。

2. SpaceX巨额IPO，揭示财务挑战与AI野心

SpaceX于2026年5月20日公开提交了S-1注册声明，正式启动了可能成为史上最大规模的首次公开募股（IPO）程序。这份备受期待的文件首次向公众披露了公司的财务细节，显示SpaceX在2025年实现了187亿美元的合并营收，其中Starlink卫星互联网业务贡献了114亿美元，同比增长近50%。然而，尽管营收强劲增长，SpaceX在2025年仍录得约49亿美元的净亏损，自公司成立以来累计亏损已超过370亿美元。值得注意的是，2025年约60%的资本支出，即高达200亿美元，投入了最近合并到SpaceX旗下的xAI部门，但该部门的营收仅增长了约22%，显示出AI领域的巨大投入与当前回报之间的差距。SpaceX计划在纳斯达克上市，股票代码为SPCX，由高盛、摩根士丹利和美国银行牵头，目标通过IPO募资约750亿美元，估值高达1.75万亿美元。路演预计于6月5日开始，马斯克通过双层股权结构确保了对公司的控制权。

SpaceX的IPO无疑是资本市场的一大盛事，其高达1.75万亿美元的估值将使其成为全球市值最高的公司之一，彰显了市场对其太空探索和互联网业务巨大潜力的认可。然而，财务报告中显示的巨额亏损，特别是对xAI部门的巨额投入但回报相对较低的状况，可能引发市场对AI投资效率的担忧。对于特斯拉而言，SpaceX的IPO及其披露的财务状况，尤其是xAI的“烧钱”特性，可能会让投资者重新审视马斯克在AI领域的总体战略和投资回报率。两家公司在AI领域的一系列动作，也凸显了马斯克生态系统对未来AI技术的巨大野心和投入。

判断与建议： SpaceX的IPO将为其雄心勃勃的项目提供充足资金，但同时也暴露了前沿AI研发的巨大成本。投资者应密切关注特斯拉自身在FSD和Dojo等AI项目上的投入产出比，确保其AI战略与财务表现能够匹配市场预期，并警惕重蹈xAI初期高投入低回报的覆辙。同时，特斯拉也可以从SpaceX大规模工程管理和融资能力中汲取经验。
