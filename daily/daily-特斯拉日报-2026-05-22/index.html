  • 储能项目大单：Meta宣布与Enbridge合作在怀俄明州建设大型可再生能源项目，特斯拉将为此提供价值约2亿美元的Megapack电池储能系统。
  • Model S/X旗舰车型落幕：Model S和Model X Signature Edition在弗里蒙特工厂举行交付仪式，标志着这两款传奇旗舰车型时代的终结。

技术进展

Cybercab树立电动汽车效率新标杆 特斯拉在近日的Model S和Model X Signature Edition交付活动上透露，其专为自动驾驶设计的Cybercab已被官方认证为有史以来能效最高的电动汽车。该车型实现了惊人的165瓦时/英里（Wh/mi）的超低能耗，这意味着它的效率比标准Model 3高出约40%。特斯拉车辆工程副总裁Lars Moravy强调，这一工程壮举为电动汽车的实际能耗设定了新的基准。更值得关注的是，Cybercab工程主管Eric E.表示，165 Wh/mi仅仅是一个起点，开发团队将继续不懈地推动Cybercab平台效率的极限。

这种对极致效率的追求对于特斯拉即将推出的商业化机器人出租车（robotaxi）网络至关重要。作为需要持续运行的商业车队，每一瓦的节省都直接转化为更高的利润率，并能显著减少充电停机时间。车辆停机时间越少，其运营时间就越长，从而能接载更多乘客并产生更多收入。这种物理效率水平是特斯拉自动驾驶平台从现有测试区域扩展到构建统一（并最终全球化）自动驾驶交通服务骨干的关键。Cybercab的卓越效率不仅展示了特斯拉在电动汽车技术上的领先地位，也为自动驾驶大规模商业化铺平了道路。

充电与能源

特斯拉Megapack助力Meta打造AI数据中心清洁能源基地 科技巨头Meta与加拿大能源基础设施公司Enbridge合作，在怀俄明州启动了一项大规模可再生能源项目，并选择特斯拉作为其电池技术供应商。该项目包括一个365兆瓦（MW）的太阳能农场，并配套一个200 MW/1,600兆瓦时（MWh）的电池储能系统（BESS），特斯拉将提供价值约2亿美元的Megapack电池。这是Enbridge和Meta的“牛仔项目”第一阶段，旨在通过Wyoming’s Large Power Contract Service tariff，为Meta在当地不断扩展的AI数据中心提供稳定且低碳的电力供应。

此次合作进一步巩固了特斯拉在大型储能解决方案市场的领导地位，并凸显了其Megapack产品在满足大型企业对可再生能源需求方面的强大能力。该电池系统将通过长期租赁协议运作，在电网需求高峰期提供可调度容量，从而增强电网可靠性。这对于AI数据中心日益增长的电力需求而言至关重要，也解决了将大规模可再生能源并入电网的挑战。此举不仅为特斯拉带来了可观的营收，更使其成为未来AI基础设施清洁能源化的关键推动者，也验证了其能源业务在助力大型科技公司实现碳中和目标上的核心价值。

市场与交付

Model Y在挪威注册量突破十万，成首款达此里程碑的电动车 特斯拉Model Y在世界领先的电动汽车市场挪威实现了历史性的里程碑，其累计注册量已突破10万辆大关。根据挪威道路交通信息委员会（OFV）的最新数据，截至2026年5月20日，共有100,224辆Model Y新车在挪威注册，成为该国首款达到这一销量的单一电动汽车车型。自2021年8月首次交付以来，Model Y仅用了不到五年时间便达成此成就，目前挪威道路上每约29辆乘用车中就有一辆是Model Y。OFV首席执行官Geir Inge Stokke表示，在如此短的时间内，单一车型能达到六位数的注册量是前所未有的，这充分显示了Model Y如何全面重塑了挪威消费者的出行习惯。数据显示，Model Y的吸引力已超越科技前沿的城市中心，普及至全国各地，其中近九成（87.6%）的车辆注册给私人用户，使其真正成为一款“国民车”。

Model Y在挪威市场的快速普及，从2021年的8,267辆注册量，到2025年峰值的27,621辆，清晰展示了其强劲的增长势头和市场韧性。这一成就不仅巩固了特斯拉在挪威电动汽车市场的绝对主导地位，也为Model Y在全球其他高度电动化市场的产品策略提供了宝贵经验。未来，Model Y持续的销量增长将面临来自新兴竞争者和市场饱和度的挑战，但其作为“国民车”的地位和深厚的用户基础将为其保持领先提供强大支撑。

Model S/X Signature Edition交付，标志旗舰车型时代落幕 特斯拉于5月20日在弗里蒙特工厂举行了历史性的Model S和Model X Signature Edition交付活动，正式为这两款奠定现代电动汽车运动基础的传奇车型画上句号。此次交付仪式虽然比原定日期推迟并略有延时，但仍为Model S和Model X长达十余年的辉煌历史画上了充满怀旧色彩的感叹号。特斯拉为最终的350辆Signature Edition车型（Model S 250辆，Model X 100辆）精心设计了专属配置。

这些限量版车型拥有独特的“石榴红”深邃漆面、豪华的白色Alcantara内饰，以及一系列专属的金色Plaid徽章、车身同色门把手、金色制动卡钳和定制的内饰细节。每辆车均标配高性能Plaid版本，售价为159,420美元，并附赠尊享套装（Luxe Package），包含免费的全自动驾驶（FSD）功能和终身超级充电服务等特权。这些六位数收藏级车辆通过仅限邀请的方式发售，每辆车都拥有独特的VIN编号，彰显其特殊身份。Model S和Model X Signature Edition的交付不仅是对特斯拉早期创新精神的致敬，也可能预示着特斯拉未来的产品线将更侧重于Cybercab等高效率、规模化的车型，以适应市场和公司战略的演变。

其他值得一提

Waymo机器人出租车因恶劣天气暂停多城服务，凸显自动驾驶挑战 特斯拉的自动驾驶竞争对手Waymo因其机器人出租车在暴雨和洪水中屡次受困，已扩大服务暂停范围至四个城市。继上周因类似问题发布召回后，Waymo于近日暂停了在亚特兰大、圣安东尼奥、达拉斯和休斯顿的L4级自动驾驶服务。据当地新闻报道，一辆Waymo机器人出租车在亚特兰大遭遇积水街道并被困约一小时，尽管此前公司已发布软件更新，以限制车辆在存在洪水风险的区域行驶，但显然这些预防措施仍不足以应对突发的极端天气。美国国家公路交通安全管理局（NHTSA）已对此次事件知情并正与Waymo沟通。

Waymo在恶劣天气条件下的运营挑战，暴露了当前自动驾驶技术在应对复杂、不可预测环境时的局限性。虽然Waymo表示安全是其首要任务，但频繁的服务中断和召回无疑会影响消费者对其技术的信任度，并对其商业化扩张构成阻碍。这与特斯拉Cybercab追求极致效率和在复杂环境中稳定运行的目标形成了鲜明对比，也为特斯拉在全自动驾驶领域的发展提供了潜在的竞争优势。自动驾驶技术要实现大规模普及，必须首先解决在各种天气和路况下的鲁棒性和安全性问题。

SpaceX星舰v3首次试飞因技术故障推迟 埃隆·马斯克旗下的太空探索技术公司SpaceX的星舰v3原定于今日进行首次试飞，但在发射前几分钟因技术问题而推迟。SpaceX CEO埃隆·马斯克在社交媒体X上解释称，发射塔“筷子”臂上的一个液压销未能正确缩回，导致发射中止。SpaceX团队已立即着手解决该液压系统故障，并计划在明日（5月22日）傍晚进行另一次发射尝试。此次星舰v3的试飞将是其首次亮相，该版本相较于早期型号进行了多项重要升级，包括更大的推进剂容量、更强大的猛禽3发动机、更大的格栅翼、增强的隔热罩和改进的燃料传输系统。

星舰v3的这些改进旨在提高有效载荷性能、支持更高的飞行频率，并推进其用于Starlink部署、NASA Artemis月球着陆任务以及未来的载人火星飞行等操作任务。尽管发射推迟，但这在复杂的火箭发射测试中并不少见，SpaceX快速响应并安排再次尝试的能力，体现了其在航天工程领域的实力。虽然这不是特斯拉的直接新闻，但作为埃隆·马斯克旗下公司的重大进展，它反映了马斯克所倡导的技术创新和工程突破精神，这些精神也深刻影响着特斯拉在电动汽车和AI领域的愿景与实践。
