2026-05-25 特斯拉日报

  • 特斯拉确认其旗舰跑车Roadster 2.0将在德克萨斯州超级工厂生产，目前原型车正处于测试阶段。
  • 特斯拉工程副总裁暗示正考虑开发三电机版Model 3 Plaid，但当前工程重心仍放在下一代Roadster上。
  • 特斯拉计划在德克萨斯州欧文市建设一个专用的Robotaxi维护与调度中心，为未来的自动驾驶叫车服务奠定基础。

技术进展

  • Robotaxi网络基础设施建设加速 特斯拉正在德克萨斯州欧文市积极筹建其首个专用的Robotaxi维护与调度中心，这标志着公司在自动驾驶叫车服务商业化道路上迈出了关键一步。该中心位于达拉斯-沃斯堡大都会区内，将是一个占地35,000平方英尺的改造仓库，其设计理念是为高容量、无人驾驶的Robotaxi车队提供一体化的支持，而非依赖现有消费者服务中心。该设施将专门用于自动驾驶车辆的存储、服务、维修、清洁和调度，确保车队的高效运作和车辆的良好状态。外部场地规划显示，该中心将提供212个停车位以及16个V4超级充电桩，预示着特斯拉在该区域部署大规模自动驾驶车队的意图。这一战略布局将为特斯拉未来Robotaxi和Cybercab服务的落地提供坚实的基础设施保障，有望重塑城市出行方式。然而，该模式的监管挑战和市场接受度，以及大规模运营的复杂性仍是短期内需要关注的风险点。

  • Roadster 2.0原型车进入测试阶段 特斯拉首席设计师Franz von Holzhausen和工程副总裁Lars Moravy在一期播客节目中确认，备受期待的Roadster 2.0目前已进入原型车测试阶段。Lars Moravy透露，团队正在测试“alpha prototypes”，并且Model S Plaid Plus项目的取消使得特斯拉的全部性能工程资源都集中到了Roadster的开发上。Moravy还强调，Roadster将是特斯拉首次以“纯粹性能”的理念来设计电机，暗示其将搭载突破性的硬件技术。这一进展表明，在经历了多次延期之后，Roadster的开发进度正显著加快，有望成为特斯拉展示其极限电动性能和前沿技术实力的全新旗舰。市场对Roadster的期待已久，测试阶段的确认无疑提升了信心，但特斯拉需尽快公布更具体的量产时间表和最终性能参数以满足市场预期。

  • 三电机版Model 3 Plaid的可能性浮现 特斯拉工程副总裁Lars Moravy在近期播客中透露，他一直在思考将Model S Plaid上革命性的碳套筒电机技术应用于Model 3平台，以打造一款三电机版Model 3 Plaid。尽管Model 3 Performance已提供卓越性能，但Moravy承认，在Model 3的后副车架中集成第三个电机将面临巨大的工程挑战和空间限制。他将其形容为一项“付出就有回报”的工作，但明确指出当前工程团队的纯性能研发重心全部放在下一代Roadster上。Moravy表示，一旦Roadster达到生产阶段，其高性能电机技术未来有可能“下放”到其他车型。这一设想展示了特斯拉对产品性能的极致追求和技术下放的潜力，为Model 3的未来性能升级留下了巨大的想象空间。虽然短期内不会实现，但这一概念的提出，无疑会激发市场对特斯拉未来高性能产品的期待，同时也提醒我们当前资源集中在Roadster，三电机Model 3 Plaid仍是远期展望。

工厂与制造

  • Roadster 2.0确认在德克萨斯超级工厂生产 特斯拉首席设计师Franz von Holzhausen在一次播客中明确证实，下一代Roadster 2.0将在德克萨斯州超级工厂（Gigafactory Texas）进行生产。他指出，德州工厂庞大的占地面积为容纳新的Roadster生产线提供了充足的空间，并且工程团队已经开始规划这款车辆的布局和生产流程。这一决定不仅明确了Roadster的最终制造地点，也凸显了德克萨斯超级工厂在特斯拉全球制造网络中的战略重要性，使其成为高性能旗舰车型的主要生产基地。将Roadster的生产集中在德州，有望通过协同效应优化制造流程和供应链管理，加快量产速度。此举为投资者和潜在买家提供了关于Roadster量产计划的更多具体信息，降低了市场的不确定性，但市场仍将密切关注从规划到实际大规模生产的进展和时间表。

充电与能源

  • Robotaxi专用V4超级充电网络初具规模 特斯拉在德克萨斯州欧文市规划的Robotaxi维护与调度中心，将配备16个最新的V4超级充电桩，专为未来的自动驾驶叫车车队服务。这些V4超充桩将确保Cybercab和Robotaxi车辆能够快速高效地进行能量补给，从而最大化其运营时间和效率。这套专门为自动驾驶车队设计的充电基础设施，体现了特斯拉为支持其新型出行服务模式而进行的全面布局。通过在专用中心集成充电功能，特斯拉能够更好地管理车队能源需求，减少非营运时间。这一举措不仅验证了V4超充桩在大规模商业车队应用中的可行性，也为特斯拉未来Robotaxi网络的能源保障提供了有力支撑。此项投资是特斯拉自动驾驶商业化战略的关键组成部分，但也意味着公司在基础设施建设上需投入大量前期成本，并面临车队管理和电力负荷优化的挑战。

其他值得一提

  • 特斯拉加速构建自动驾驶出行服务生态 特斯拉近期在德克萨斯州欧文市规划的Robotaxi专用维护与调度中心，是公司全面推进自动驾驶叫车服务（Cybercab和Robotaxi）商业化的关键一步。这个35,000平方英尺的设施将不仅是车辆的停放点，更是集维护、维修、清洁和智能调度于一体的运营枢纽，旨在支持高容量的无人驾驶车队。通过建设这种专门的基础设施，特斯拉正在构建一个独立且高效的自动驾驶服务生态系统，而非仅仅将现有服务中心挪用。这表明特斯拉对其自动驾驶技术的成熟和商业潜力抱有巨大信心，并正从物理层面为大规模的无人驾驶出行服务做好准备。此举预示着未来城市交通可能会因特斯拉Robotaxi网络的普及而发生颠覆性变革，为公司带来全新的营收增长点。然而，该业务模式的成功将高度依赖于自动驾驶技术的完全成熟、监管政策的放开以及消费者接受度的提升，其不确定性依然存在。
