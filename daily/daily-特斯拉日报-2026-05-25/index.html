2026-05-25 特斯拉日报

  • 特斯拉4680电池干法正极技术取得重大突破，有望显著降低电池成本。
  • 特斯拉确认下一代Roadster 2.0原型车正在测试中，未来将在德克萨斯州超级工厂生产。
  • 特斯拉正在德克萨斯州欧文市建设首个Robotaxi专用维护与调度中心。
  • 特斯拉工程副总裁 Lars Moravy 探讨了推出三电机版 Model 3 Plaid 的可能性。

技术进展

特斯拉正积极为自动驾驶服务部署专用基础设施，规划在德克萨斯州欧文市建设一个35,000平方英尺的Robotaxi维护与调度中心。该中心将改造现有商业仓库，功能涵盖Robotaxi车队的存储、服务、维修和清洁等环节，以确保车辆随时处于最佳运营状态。该设施规划配备212个停车位和16个V4超级充电桩，其规模和功能首次揭示了特斯拉未来大规模自动驾驶叫车服务所需的运营足迹。这标志着特斯拉不仅在软件和AI层面推动自动驾驶技术，也在硬件和物理基础设施上进行同步建设，为Cybercab和Robotaxi的全面商业化运营奠定基础，旨在最大化车队效率并提升用户体验。这是一个明确的信号，表明特斯拉正从纯粹的技术研发向“自动驾驶即服务”的商业模式迈进，未来几年有望改变城市交通格局，但初期高昂的运营投入和复杂的城市管理协调仍是其面临的挑战。

工厂与制造

特斯拉在4680电池生产技术上取得了关键性的突破，通过一项最新公布的USPTO专利（US 2025/0364562），成功解决了干法正极的量产难题。这项“蜘蛛网专利”揭示了特斯拉如何利用PTFE与PVDF的复合粘合剂系统，在高剪切喷射研磨过程中形成微观的“蜘蛛网”结构，从而在无需有毒液体溶剂的情况下，将电极活性颗粒机械地锁定在一起，形成柔韧且自支撑的薄膜。此项创新使得此前需要多达十次高压辊压才能形成的薄膜，现在只需三次即可完成，效率大幅提升，解决了4680电池此前在制造速度上的瓶颈，生产吞吐量预计将提升三倍。这一技术突破对于降低4680电池的生产成本、简化制造流程以及提升电池整体性能具有深远意义，有望加速特斯拉在电动汽车领域内的成本优势。这项干法正极技术是特斯拉电池自产战略的里程碑，不仅对特斯拉的未来盈利能力和市场竞争力构成核心支撑，也可能促使整个电池制造行业向更环保、高效的干法工艺转型，其长期影响值得密切关注。

此外，特斯拉首席设计师Franz von Holzhausen确认，备受期待的下一代Roadster 2.0车型将在德克萨斯州超级工厂（Gigafactory Texas）进行生产。他指出，德州工厂拥有足够的空间来容纳新的装配线，且团队已着手规划车辆布局和生产流程。此举意味着德州超级工厂将不仅仅是Model Y和Cybertruck的主要生产基地，更将成为特斯拉高性能旗舰车型的制造中心。将Roadster这类高端车型引入德州生产，有助于优化特斯拉的全球生产布局，并通过集中资源提升制造效率和技术协同。这一决策强化了德州超级工厂在全球制造版图中的战略地位，表明特斯拉对该工厂的制造能力和未来发展寄予厚望，但同时也需确保生产工艺能满足超跑级别的高标准要求。

充电与能源

在特斯拉德克萨斯州欧文市规划的Robotaxi维护与调度中心，将建设16个V4超级充电桩，以支持其自动驾驶车队。这一专用充电设施的配置，反映了特斯拉对未来Robotaxi车队高效率运营的深思熟虑。V4超级充电桩作为特斯拉最新的充电技术，其更快的充电速度和更高的可靠性，能够确保自动驾驶车辆在最短时间内完成补能，从而最大化其在线运营时间并减少停运损失。这种集成在维护中心的专属充电解决方案，对于保障Robotaxi服务的连续性、提升用户体验以及降低车队运营成本至关重要。这表明特斯拉在构建其自动驾驶生态系统时，充电基础设施是与车辆技术同样重要的组成部分，其策略性部署将为Robotaxi的大规模推广提供关键支撑，但初期在各个运营区域的充电网络覆盖率仍需加速建设。

市场与交付

特斯拉工程副总裁Lars Moravy透露，备受瞩目的下一代Roadster 2.0的Alpha原型车目前正处于测试阶段。他强调，在取消了Model S Plaid Plus项目后，特斯拉所有的性能工程重点都已完全转向这款跑车，预示着Roadster将搭载特斯拉最前沿的电机技术，实现革命性的性能突破。Roadster 2.0的积极进展对于特斯拉的品牌形象至关重要，它不仅仅是一款产品，更是特斯拉在电动汽车性能极限探索上的技术标杆，将重新定义电动超跑的性能标准，并吸引全球高性能汽车爱好者的目光。虽然Roadster的销量对特斯拉整体交付量的贡献相对较小，但其作为技术展示平台，将为公司带来巨大的品牌溢价和技术下放潜力。该项目的持续推进表明特斯拉正信守其对极致性能的承诺，但具体的发布时间和量产细节仍有待官方进一步公布。

此外，特斯拉工程副总裁Lars Moravy在一次播客中，暗示了未来推出三电机版Model 3 Plaid的可能性。他坦言这是一个他“一直思考”的工程挑战，并特别提到考虑将Model S Plaid上革命性的碳纤维套筒电机适配到Model 3平台。鉴于Model S和Model X Plaid的退市，特斯拉目前缺乏一款旗舰级的“Plaid”性能车型。尽管新版Model 3 Performance表现卓越，但在0-60英里/小时加速时间上仍不及Model S Plaid。Moravy指出，尽管在Model 3的后副车架中集成第三个电机存在巨大的工程难度，且当前公司的性能工程重心在即将推出的Roadster上，但一旦Roadster达到生产阶段，高性能电机技术下放至其他车型的可能性将再次打开。这一讨论为市场注入了兴奋剂，表明特斯拉持续探索其主力车型的性能极限，未来三电机Model 3 Plaid的出现将进一步巩固Model 3在高性能电动轿车市场的地位，吸引追求极致驾驶体验的消费者。
