技术进展

网页版行车记录仪查看器与加密功能 特斯拉已正式推出其全新的网页版行车记录仪查看工具（dashcam.tesla.com），此功能随软件更新2026.20一同上线。该更新的核心在于引入了行车记录仪视频的自动加密功能，默认情况下，所有录像都将通过与车主特斯拉账户绑定的唯一加密密钥进行保护，有效阻止未经授权的播放，大大提升了隐私安全性。新的在线查看器允许用户登录后，在本地电脑上实时解密并流畅播放这些加密视频，整个过程数据不上传云端，确保了隐私的端到端保护。此外，该工具还支持标准的未加密文件，并提供直观的多摄像头网格布局和拖放操作，极大地简化了用户对视频片段的管理与查看。

  • 影响： 这一创新显著提升了特斯拉用户在处理行车记录仪视频时的便捷性、安全性和隐私性，尤其在应对车辆被盗或存储设备丢失时的隐私风险。对于特斯拉而言，它进一步完善了车辆安防功能生态，并加强了用户对其数据安全能力的信任。
  • 判断/建议： 该功能是特斯拉在用户体验和隐私保护方面的重要进步，有助于巩固其在智能汽车领域的领先地位。然而，新功能的普及依赖于2026.20软件更新的推送进度，目前仅有小部分车辆完成了更新，因此短期内其覆盖范围有限。

行车记录仪录制时长扩展与新增遥测叠加 随着2026年春季软件更新（版本2026.14）的全球部署，特斯拉大幅提升了行车记录仪的循环录制时长，从之前的1小时扩展至惊人的24小时。这一扩展功能适用于Model S、Model X、Model 3、Model Y和Cybertruck等车型，但要求车辆配备HW3或更高硬件、AMD Ryzen信息娱乐系统以及1TB或更大容量的USB驱动器或SSD。此外，特斯拉近期还为行车记录仪视频增加了遥测数据叠加功能，能够在视频中实时显示车速、转向角以及自动驾驶状态等关键车辆数据，为用户提供了更丰富的上下文信息。

  • 影响： 24小时录制缓冲区为车主提供了更广泛的事件追溯能力，即使事故发生后未能及时保存片段，也能在更长时间内找到证据。遥测数据的加入则极大地增强了视频的分析价值，特别是在事故责任认定或评估FSD表现时。然而，更长的录制时长也意味着存储设备被盗时可能泄露更多行踪信息，这也正是2026.20更新中加密功能的重要性所在。
  • 判断/建议： 这些改进显著提升了特斯拉车辆的安防和智能监控能力，为用户提供了更全面的保障，并有助于在突发事件中提供有力证据。用户应确保其车辆硬件和软件满足要求，以充分利用这些功能，并配合加密设置以保障个人隐私。

FSD (Supervised) v14.3.3长途测试表现 在近期进行的一次长达150英里的宾夕法尼亚收费公路压力测试中，特斯拉Full Self-Driving (Supervised) v14.3.3版本展现出令人印象深刻的性能。测试者报告称，在大部分路程中，系统能够良好地处理驾驶任务，仅在少数情况下需要人工介入，且这些介入主要是为了应对其他车辆的不可预测行为。特别值得一提的是，FSD系统能够准确识别路面上的车道结束指示箭头，并提前做出规划。测试者总结道，FSD的辅助使得长途驾驶体验显著变得更加轻松愉快，大大减轻了驾驶员的疲劳感，改变了以往长途跋涉后的身心状态。

  • 影响： 此次长距离测试的积极结果，进一步验证了FSD (Supervised)在相对复杂的公路驾驶环境中的成熟度和可靠性。系统的持续优化是特斯拉实现未来Robotaxi服务愿景的关键一步，有助于增强市场和消费者对特斯拉自动驾驶技术的信心。
  • 判断/建议： FSD技术的稳步进步是特斯拉核心竞争力之一，预示着其在自动驾驶领域的领先地位。但需承认，目前仍是“监督”模式，完全实现无人驾驶仍有挑战，特斯拉需继续在复杂路况和极端条件下的表现，以应对日益严格的法规和用户期待。

FSD在华推出准备工作 特斯拉正在积极为FSD (Supervised)软件在中国的正式推出进行各项准备工作。近期，公司已更新了其中文版车主手册和官方网站，其中包含了对FSD v14专属功能以及“特斯拉辅助驾驶”的提及，后者很可能将作为FSD在中国的本地化名称。同时，特斯拉也在中国市场加大了相关职位的招聘力度，包括软件开发、测试和本地化运营等，这表明FSD在华的广泛部署已进入实质性操作阶段。

  • 影响： FSD进入中国市场对特斯拉具有里程碑意义，中国作为全球最大的新能源汽车市场和智能驾驶技术前沿阵地，FSD的落地将极大地提升特斯拉在华产品的差异化竞争优势，并为其带来新的软件服务收入增长点。此举也将促进中国智能驾驶技术的整体发展和市场成熟。
  • 判断/建议： FSD在华落地无疑是一个巨大的市场机会，但特斯拉将面临中国独特的监管环境、高精地图合规性以及本土智能驾驶解决方案提供商的激烈竞争。初期可能需要应对本地化适应性挑战，但长期来看，其技术优势有望在中国市场获得可观回报。

市场与交付

特斯拉中国5月销量创2026年新高 特斯拉中国在2026年5月取得了显著的市场表现，其批发销量达到了85,982辆，创下本年度以来的单月最高记录。这一数字较去年同期实现了39.44%的强劲增长，并较4月份的79,478辆环比增长了8.18%。值得注意的是，该批发销量包含了在中国本土的零售交付以及从上海超级工厂出口到其他国际市场的车辆。截至2026年前五个月，特斯拉中国的累计批发销量已达378,858辆，同比增长29.36%，显示出其在中国市场持续的增长势头和生产效率。

  • 影响： 中国市场的强劲复苏对特斯拉的全球交付目标至关重要，尤其是在全球经济面临不确定性的背景下。上海超级工厂的高效运作，不仅满足了中国本土需求，也作为重要的出口基地，支撑了欧洲等市场的增长。
  • 判断/建议： 5月销量数据表明特斯拉在中国市场成功扭转了此前4月份短暂的销量下滑趋势，展现出强大的市场韧性。结合FSD在中国的潜在推出和“轻松贷”等激励措施，预计特斯拉在华销量有望继续保持增长，但仍需密切关注本土品牌的激烈竞争和消费者偏好变化。

欧洲市场销量表现强劲及中国市场策略 2026年5月，特斯拉不仅在中国市场取得了优异成绩，在多个欧洲关键市场也录得了显著增长，这进一步巩固了其全球销售回升的势头。例如，特斯拉在法国的销量同比飙升了655%，并在丹麦、西班牙和瑞典等国也实现了健康的增长。与此同时，为持续刺激中国市场需求，特斯拉推出了一项名为“轻松贷”的全新车辆融资结构，旨在大幅降低购车门槛。以售价为235,500元人民币（约合35,000美元）的后轮驱动版Model 3为例，通过此方案，最低首付可降至55,900元人民币（约合8,200美元），并提供五年期分期付款。

  • 影响： 欧洲市场的爆发式增长结合中国市场的灵活策略，共同构成了特斯拉全球销售业绩向好的关键支撑。通过多元化的融资方案和市场激励，特斯拉能够有效吸引更广泛的消费者群体，尤其是在对价格敏感度较高的市场中。
  • 判断/建议： 欧洲和中国市场的双重增长预示着特斯拉在全球范围内的销售势头正在重新加速，短期内将对其股价形成支撑。然而，欧洲市场的持续高速增长可能面临供应链和产能的潜在压力，而中国市场的融资策略效果也需长期观察，以评估其对盈利能力的影响。

其他值得一提

SpaceX与特斯拉潜在合并传闻引发市场关注 SpaceX修订后的S-1文件披露了一项关键条款，指出该公司“可能发行大量股权以进行未来交易”，这一表述立即在市场上引发了对SpaceX与特斯拉潜在合并的强烈猜测，并导致特斯拉股价当日下跌5%。尽管一些分析师认为这可能只是S-1文件中的标准条款，但考虑到两家公司与埃隆·马斯克的紧密联系，以及马斯克本人曾与亲近同事讨论合并可能性的传闻，投资者将其解读为一个重要信号。机构投资者普遍对此表示担忧，例如The Future Fund董事总经理Gary Black就指出，此类合并可能导致特斯拉股东股权稀释高达28%，并认为多元化企业集团往往估值较低，机构投资者更偏好专注于核心业务的公司。

  • 背景与影响： 然而，也有市场观察者（如特斯拉影响力人士AleXandra Merz）提出了不同的“看涨”观点，认为如果按照“对等合并”模式进行，通过相对公允市场价值谈判，特斯拉的股票有望被重估。她计算称，若以SpaceX 2.5万亿美元、特斯拉1.6万亿美元的估值合并为4.1万亿美元实体，特斯拉股东所持部分将价值2.05万亿美元，相较当前市值增长约4500亿美元。
  • 判断/建议： 尽管合并仍停留在市场猜测层面，但其对特斯拉股价和投资者情绪的影响不容忽视。短期内，这种不确定性可能继续对特斯拉股价构成压力，投资者需密切关注后续任何官方声明。长期来看，任何形式的合并都将是科技和金融界的一大事件，对两家公司的业务协同、资本结构以及未来战略方向产生深远影响，机遇与风险并存。
