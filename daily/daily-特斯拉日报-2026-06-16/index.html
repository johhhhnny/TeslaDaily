技术进展

特斯拉FSD (Supervised) v14.3.4的近期更新中，导航功能依然是其显著的薄弱环节，这与数十年来已成熟的传统导航技术形成了鲜明对比。尽管FSD在流畅加速、理想条件下的自信变道以及对可见障碍物的响应处理等方面表现出色，但车主反馈其在准确遵循路线方面屡次出错，包括错误转弯、错过高速公路出口、选择低效的本地道路而非高速、出现虚假限速提示，甚至将车辆引导至建筑物后门。特斯拉已通过内部调查承认此问题，并开始向车主发送专门的调查问卷以收集详细反馈。导航的缺陷并非孤立存在，它会引发一系列更广泛的系统性问题，例如混淆AI的决策过程，导致车辆表现犹豫、不必要的自动驾驶脱离，甚至尝试不安全的掉头或忽略明确的匝道。这不仅损害了用户体验，也对FSD的整体可靠性和“完全自动驾驶”的愿景构成了挑战。

  • 判断/建议： 导航功能是任何自动驾驶系统的核心基础，FSD在此方面的持续缺陷是其走向成熟的“阿喀琉斯之踵”。特斯拉急需投入更多资源解决这一关键问题，因为导航的准确性直接影响用户信任和系统的安全边界。若能有效解决，将大幅提升FSD的短期可用性和市场接受度，从而巩固其在自动驾驶领域的领先地位；反之，则可能面临用户流失和监管机构更严格的审查风险。

在新泽西州，特斯拉正积极动员当地车主，反对州议会正在审议的S.1677和A.3968两项法案，认为这些法案将对Robotaxi的部署构成严重障碍。这些立法草案旨在建立一个为期三年的自动驾驶试点项目，但附带的严苛要求——如强制配备人工安全驾驶员、高达500万美元的巨额保险金，以及在获批无人驾驶前需积累10万英里的安全自动驾驶里程——被特斯拉批评为武断且不切实际的壁垒。公司指出，这些规定忽视了FSD系统真实的性能数据，并可能阻碍创新技术的发展，反而有利于现有竞争者。特斯拉在给车主的邮件中强调，Robotaxi能够消除疲劳、分心驾驶等人类错误导致的交通事故，鉴于2025年新泽西州因交通事故导致582人死亡，Robotaxi有望为社会带来更安全、独立的出行方式，惠及家庭、老年人和残障人士。

  • 判断/建议： 监管环境是Robotaxi实现大规模商业化运营的关键不确定性因素，新泽西州的情况是特斯拉在全球推广其无人驾驶服务时面临的典型挑战。特斯拉需要持续与政策制定者沟通，用详尽的数据和案例证明Robotaxi的安全性与社会效益，以争取更有利的技术发展和部署环境。成功应对此类立法挑战将为Robotaxi在其他地区铺平道路，开启巨大的市场机会；但若遭遇阻碍，则可能导致部署延迟，增加运营成本和区域碎片化风险。

美国国会参议员埃德·马基和理查德·布卢门撒尔已致信美国国家公路交通安全管理局（NHTSA），敦促该机构对特斯拉Full Self-Driving (Supervised)系统的安全声明进行审查。此举是在路透社此前对特斯拉公开引用的FSD安全数据方法论提出质疑之后发生的。特斯拉宣称其FSD系统比人类驾驶安全7到10倍，平均每行驶550万英里才发生一次重大碰撞，而美国人类驾驶的平均水平是66万英里。参议员们在信中明确表示，误导性的安全统计数据可能鼓励驾驶员过度依赖FSD，掩盖技术中潜在的安全缺陷，并削弱NHTSA有效评估已在公共道路上运行车辆风险的能力。他们要求NHTSA在7月7日前回答一系列关键问题，包括是否独立评估了特斯拉数据的统计有效性，是否已要求特斯拉提供生成这些数据的底层数据、假设、碰撞定义和方法论，以及NHTSA如何评估特斯拉在FSD安全计算中采用的5秒脱离窗口（与SGO的30秒报告窗口不同）和自动遥测系统可能遗漏连接性不佳或车辆通信系统受损情况下发生的事故。

  • 判断/建议： 针对FSD安全数据的持续审查和质疑，对特斯拉构成了显著的监管和声誉风险。如果特斯拉无法透明且充分地证明其数据方法论的严谨性和有效性，或者NHTSA发现其数据存在重大缺陷，可能会导致FSD的推广和部署受到限制，并损害公众对该技术的信任。特斯拉当前面临的机会在于，通过与监管机构的全面合作和数据透明化，进一步验证FSD的安全性，并为自动驾驶行业树立更高的安全数据报告标准。然而，不确定性在于NHTSA的最终裁决以及其对FSD未来发展和市场准入可能产生的影响。

工厂与制造

有最新报道称，带有Costco品牌标识的特斯拉Semi卡车在亚利桑那州的一个仓库被发现，这强烈暗示了全球最大的零售商之一Costco可能已开始或即将把特斯拉Semi用于其日常的物流配送网络中。在商业卡车领域，当车辆印有公司品牌并带有DOT编号和内部车辆ID时，通常意味着该车辆已被整合到实际运营中，而不仅仅是进行测试。Costco采用的枢纽辐射式分销模型，即商品从大型中心配送中心运往区域零售点，非常适合特斯拉Semi的运营特性，因为这些路线通常具有可预测性，并处于Semi的续航里程范围内，便于在仓库或配送中心进行计划性充电。虽然此次发现的Semi是早期生产版本，缺乏前置灯条，但考虑到特斯拉Semi已进入规模化生产，预计Costco未来扩充车队时将采用最新的量产版本，该版本通过各种改进实现了减重和更高的效率。

  • 判断/建议： 大型零售商如Costco的采纳，是特斯拉Semi卡车商业化进程中的一个重要里程碑，它验证了Semi在实际物流场景中的商业价值和环境效益。这为特斯拉在重型卡车市场带来了巨大的拓展机会，并有助于加速整个物流行业向电动化转型。然而，目前发现的是早期版本Semi，其大规模部署的节奏和新版本Semi的产能爬坡能力，仍是影响其市场渗透率和成本效益的关键因素，这既是机遇也是挑战。

其他值得一提

埃隆·马斯克的航天巨头SpaceX在上市后采取了其首次重大行动，以高达600亿美元的全股票交易正式收购了AI编码初创公司Cursor。此次收购是在SpaceXAI与Cursor进行了数月的联合模型训练和合作之后进行的，其核心目标是构建全球最有用的AI模型，并已发布了Cursor移动测试版。Cursor作为一家AI原生代码编辑器和编码代理，专注于通过自然语言指令将想法转化为可执行代码，其年度经常性收入已超过30亿美元，并已被半数财富500强企业采用，拥有约300名工程师的专业团队。更值得关注的是，SpaceX首席运营官格温·肖特韦尔在近期接受采访时曾暗示，“SpaceX和特斯拉之间的合并可能会让埃隆（马斯克）的生活更轻松一些”，这为特斯拉与SpaceX之间未来潜在的战略整合留下了想象空间。SpaceX在上市后股价飙升，市值已高达2.8万亿美元，超越亚马逊，正逼近微软的2.9万亿美元市值，成为全球第五大最有价值的公司。

  • 判断/建议： SpaceX对Cursor的巨额收购及其在AI领域的激进扩张，反映了马斯克在其商业生态系统内构建强大AI能力的宏大愿景，这可能通过技术协同、人才共享或未来潜在的战略整合（如肖特韦尔所暗示的合并）间接利好特斯拉。对于特斯拉而言，虽然收购并非直接由其执行，但马斯克在AI领域共享的资源和方向，可能加速特斯拉在FSD和机器人等AI核心技术领域的发展，从而带来长期的战略机会。然而，这种跨公司资源的调配和潜在的整合，也可能带来管理上的复杂性和不确定性。

一辆特斯拉Cybertruck在英国大曼彻斯特地区被当地警方扣押，原因是该车型不符合英国的道路安全法规，无法获得在该国运营所需的型式认证。警方援引“对其他道路使用者或行人的安全存在合理担忧”作为扣押理由，指出Cybertruck独特且棱角分明的造型以及其不锈钢外骨骼的尖锐边缘，不符合英国及欧盟地区严格的行人保护规定。被扣押的车辆在国外进行了注册和投保，但驾驶员为英国居民，其行为已被记录。特斯拉此前曾探讨过开发一款符合欧洲标准、被称为“国际版本”的Cybertruck，但迄今为止，公司尚未在该方面展现出实质性进展，其主要精力仍集中在Robotaxi的全球推广和部署上。

  • 判断/建议： Cybertruck在英国的合法性问题凸显了其激进设计在国际市场所面临的合规挑战，这直接限制了其在关键海外市场的商业化潜力，并可能影响特斯拉的全球交付战略。特斯拉需要认真权衡为欧洲等市场进行设计调整的成本与潜在的市场回报。短期内，这构成了Cybertruck市场扩张的风险，但若能成功推出符合当地标准的国际版本，则将解锁新的巨大市场机会。

有最新报告指出，苹果公司正在开发一项名为“路径共享”（Route Sharing）的全新CarPlay技术，该功能已于今年3月随iOS 26.4版本发布，这有望成为特斯拉车辆未来集成CarPlay的关键缺失环节。尽管许多特斯拉车主对其内置的、无缝且高效的用户界面感到满意，但仍有不少用户渴望CarPlay提供的优势，例如更熟悉的导航体验和更丰富的第三方应用集成，尤其是iMessage等功能。此前，特斯拉并未将CarPlay的集成视为优先事项，主要原因在于其专注于全自动驾驶技术的开发、应用兼容性问题以及iOS 26版本较低的采用率。然而，随着“路径共享”功能的出现，该报告预测，CarPlay有望通过2026年夏季或秋季的特斯拉软件更新，最终进入特斯拉车辆。

  • 判断/建议： CarPlay的引入对特斯拉而言是一把双刃剑。一方面，它能够满足部分车主对苹果生态系统的需求，有望提升用户满意度和品牌吸引力，尤其是在弥补特斯拉自身导航功能不足方面具有潜在优势，从而可能吸引更广泛的潜在买家。另一方面，这也可能在一定程度上削弱特斯拉对其车内用户体验的完全控制。如果能够顺利整合，并在此过程中保持特斯拉自身系统优势，这将是一个重要的市场机会。

特斯拉正式宣布，此前仅作为“创始版Cyberbeast”独家附件提供的Cybertruck越野灯条，现已在北美地区的在线商店单独销售。这款高性能的车顶照明套件定价为1950美元（加拿大地区为2700加元），让所有Cybertruck车型（无论是否为创始版）的车主都能选购。该灯条充分利用了Cybertruck的48V电气架构，并能通过车辆的触摸屏直接控制灯光角度、强度及其他设置，实现了高度集成化的用户体验。购买价格中包含了从特斯拉发货至当地服务中心以及完整的安装服务。特斯拉表示，未来计划将这款越野灯条的销售范围逐步扩展到国际Cybertruck市场，以满足全球车主的定制化需求。

  • 判断/建议： 单独销售Cybertruck越野灯条是特斯拉在配件策略上的一次积极调整，它不仅满足了更多Cybertruck车主的个性化需求，增加了潜在的配件收入，也可能是在为Cybertruck更广泛的市场推广做准备。此举显示了特斯拉对车主社区需求的响应能力和在产品线上的灵活性，有助于提升Cybertruck的吸引力和用户体验，是一个积极的市场机会。
