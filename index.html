2025-12-18 特斯拉日报

新闻速览

  • 特斯拉保险业务在佛罗里达州正式推出，是三年来的首次扩张，现已覆盖美国13个州。
  • Waymo付费自动驾驶出租车服务累计乘车次数突破2000万，七个月内实现翻倍增长。
  • 星链（Starlink）宣布与Airtel Africa合作，计划于2026年在非洲14个市场推出“直连手机”卫星服务。
  • 特斯拉在加利福尼亚Lost Hills的Oasis超级充电站全面开放，拥有164个V4充电桩，成为全球最大且首个主要离网的超级充电站。
  • Rivian为其第二代R1电动车发布“通用免提驾驶”功能，可在美国和加拿大超过350万英里的道路上使用。
  • 特斯拉FSD（完全自动驾驶）系统在韩国获得国会议员李素永的高度评价，称其“已是成熟技术”。

技术进展

  • 特斯拉FSD获得韩国国会议员高度评价： 特斯拉的FSD（完全自动驾驶）系统在韩国市场获得了重要的正面认可。韩国国会议员李素永（担任韩国国会战略与财政委员会成员）在体验了最新版的FSD v14.1.4后，给予了高度赞扬，她形容FSD“开得和大多数人一样好”，并认为“这已经是一项成熟的技术”，这让她对未来的日常生活变化充满期待。FSD于11月下旬在韩国正式上线，使其成为继美国、波多黎各、加拿大、中国、墨西哥、澳大利亚和新西兰之后，全球第七个启用FSD服务的国家。此项来自公众人物的评价对于FSD在韩国的推广和监管审批具有积极意义，有望增强当地公众对自动驾驶技术的信任度和市场接受度。
  • 判断/建议： 知名政治人物的认可为特斯拉FSD在全球扩张提供了强有力的背书，可能加速其在更多市场的普及。这凸显了FSD技术的日益成熟和特斯拉在全球自动驾驶领域的领先地位，但持续的监管沟通和用户教育仍是关键挑战。
  • Waymo自动驾驶出租车突破2000万次乘车： 谷歌母公司Alphabet旗下的自动驾驶公司Waymo宣布，其付费自动驾驶出租车服务累计完成了超过2000万次完全自动驾驶行程。这一里程碑意义重大，尤其值得注意的是，从1000万次到2000万次仅用了短短七个月时间（此前1000万次也只用了约五个月），目前每周提供超过25万次付费行程，显示出其服务采用率的急剧上升和运营区域的快速扩张。Waymo已确认计划在2026年在美国多个主要城市（如达拉斯、丹佛、底特律、休斯顿、拉斯维加斯、迈阿密、圣地亚哥和华盛顿特区）推出服务，并计划于2026年在伦敦进行首次海外启动，同时已在东京进行车辆训练。此外，Waymo正在寻求新一轮融资，目标估值达1000亿美元，拟筹集150亿美元。
  • 判断/建议： Waymo的快速增长及其激进的扩张计划，无疑对特斯拉的FSD和未来Robotaxi愿景构成了强劲的竞争压力。虽然特斯拉FSD强调私家车应用，但Waymo在Robotaxi领域的商业化进展表明市场潜力巨大，特斯拉需加快其Robotaxi战略落地，以避免在该领域失去先发优势。
  • Rivian推出“通用免提驾驶”功能： 电动汽车制造商Rivian为其第二代R1电动车推出了全新的“通用免提驾驶”（Universal Hands-Free）软件功能，该功能已覆盖美国和加拿大超过350万英里的道路，包括高速公路和有清晰车道线的普通道路。尽管该系统允许驾驶员双手脱离方向盘，但仍需驾驶员保持监督，并且目前不支持交通信号灯、停车标志的识别与应对，也无法自主转弯或跟随导航（驾驶员需手动处理转弯）。Rivian计划在2026年实现车辆的“点对点”自动驾驶能力，并正在为2026年发布的R2 SUV开发搭载定制芯片和激光雷达的全新自动驾驶计算机。
  • 判断/建议： Rivian的“通用免提驾驶”功能显著扩展了其驾驶辅助能力，标志着行业内L2+级别自动驾驶技术的普遍进步。虽然与特斯拉FSD的全面城市驾驶能力仍有差距，但其发展速度不容小觑，这提醒特斯拉需在技术领先性、安全性和用户体验上持续投入，以保持竞争优势。

充电与能源

  • 特斯拉Oasis超级充电站全面开放，打造全球最大离网充电枢纽： 特斯拉已完成对其位于加利福尼亚Lost Hills的Oasis超级充电站的压力测试，并正式全面开放。该站点是全球最大的特斯拉充电站，拥有164个V4超级充电桩，其中包含12个专为拖车设计的直通式充电位。最引人注目的是，Oasis是全球首个主要离网超级充电站，由11兆瓦的现场太阳能发电系统和10个特斯拉Megapacks储能系统提供动力，总峰值使用和电池备用容量高达15.8兆瓦。在12月17日进行的为期一小时的压力测试中，该站点成功提供了7.5兆瓦的实际充电负荷，验证了其在极端需求下的处理能力和可靠性。该项目于去年10月动工，仅用8个月左右便分阶段上线，显示了特斯拉强大的基础设施建设能力。
  • 判断/建议： Oasis超级充电站的全面开放，不仅解决了加州繁忙交通走廊的充电需求，更树立了特斯拉在可持续能源和充电基础设施整合方面的行业标杆。其离网设计通过太阳能和储能的结合，显著提升了充电网络的韧性和可靠性，有望成为未来大规模超级充电站部署的典范，进一步巩固特斯拉在电动汽车生态系统中的领先地位。

其他值得一提

  • 特斯拉保险三年后重回扩张轨道，佛罗里达州成为第13个覆盖州： 经过三年多的沉寂，特斯拉的保险业务终于开始重新扩张，正式在佛罗里达州推出，使其成为特斯拉内部保险覆盖的第13个美国州，覆盖约48%的美国人口。此次扩张得益于特斯拉近期开始自主承保保险政策，而非依赖第三方，从而更好地利用其车辆数据。与大多数地区一样，佛罗里达州的保单将根据驾驶员的“安全评分”实时调整保费，良好的驾驶习惯和频繁使用FSD甚至能获得显著保费折扣，甚至足以抵消FSD的月度订阅费用。目前，佛罗里达州的服务主要面向新交付的特斯拉车主。
  • 判断/建议： 特斯拉保险业务的重新扩张表明公司正积极深化其垂直整合战略，利用车辆数据优势提供更具竞争力的产品。这不仅有望为车主节省保费、激励安全驾驶和FSD使用，也有助于特斯拉获取更多利润和增强客户粘性，但需警惕各州复杂的监管环境可能带来的扩张阻力。
  • 星链与Airtel Africa合作，在14个非洲市场推出直连手机服务： SpaceX旗下的星链（Starlink）宣布与Airtel Africa达成战略合作，将在非洲14个市场推出星链的“直连手机”（Direct-to-Cell）卫星连接服务。预计商业服务将于2026年启动，具体取决于各国监管审批。根据协议，Airtel Africa旗下超过1.7亿客户的兼容智能手机将能够直接连接星链卫星，尤其是在传统蜂窝基础设施缺失的偏远地区。初期服务将支持选定应用程序的数据和文本消息，提供关键的生命线，未来将逐步升级至高速宽带连接。Airtel Africa成为非洲大陆首家如此大规模承诺与星链“直连手机”合作的移动网络运营商。
  • 判断/建议： 星链与Airtel Africa的合作是全球连通性领域的一大飞跃，特别是在弥合非洲数字鸿沟方面具有巨大潜力。虽然这并非特斯拉的直接业务，但作为埃隆·马斯克生态系统的一部分，它展示了通过创新技术解决全球重大挑战的能力，有助于提升其旗下所有企业的整体品牌形象和技术实力感知。
