技术进展

FSD Supervised 即将登陆韩国

特斯拉已通过其韩国官方X账号确认，Full Self-Driving (FSD) Supervised 系统即将登陆韩国市场，并发布了一段展示该系统在当地道路上运行的宣传视频。视频中，一辆特斯拉Model S在无需驾驶员干预的情况下，成功完成了车道变换、路口导航甚至自动泊车等复杂操作，显示了其对韩国复杂交通环境的适应能力。此举标志着特斯拉在全球范围内推广FSD服务的重要一步，继加拿大和美国之后，韩国加入到欧洲、中国和日本等计划于明年推出FSD Supervised的市场行列。然而，分析师也指出，FSD在韩国的本地化引入可能面临法律和监管挑战，特别是考虑到韩国销售的特斯拉车辆中超过80%是中国制造，它们需要符合当地的安全标准。因此，首批搭载FSD的车辆很可能优先选择根据韩美自由贸易协定制造的美国产车型，以简化合规流程。这无疑将提升特斯拉车辆在韩国市场的吸引力，但监管审批的进度将是其能否顺利扩张的关键不确定因素。

FSD 软件版本更新至 V14.1.7 (2025.38.8.7)

特斯拉已向早期测试用户推送了 FSD 软件的最新版本 V14.1.7 (2025.38.8.7)。此次更新将 FSD V14 分支整合到 2025.38 的软件体系中，使得 FSD 用户能够享受到 2025.38 版本中的最新功能和改进。尽管具体的 FSD 发布说明保持不变，但这一整合通常意味着底层架构的优化、性能的提升以及对新硬件或现有传感器数据处理能力的增强。特斯拉通过持续的软件更新来迭代其 FSD 系统，旨在不断提高其自动驾驶能力和安全性。对于早期测试者而言，这意味着他们将能够体验到更先进的驾驶辅助功能，并向特斯拉提供关键的真实世界数据反馈。这种快速迭代的策略是特斯拉在自动驾驶领域保持领先的关键，但每一次更新的稳定性和安全性仍需在实际运行中进一步验证，以确保大规模推广的可靠性。

Cybercab 设计更新与 Robotaxi 市场扩张

特斯拉在2025年度股东大会上公布了 Cybercab 的最新设计细节，并宣布了 Robotaxi 服务激进的扩张计划。作为专为自动驾驶设计的车型，Cybercab 正在从概念逐步走向成熟量产，预计明年将进入大规模生产。新设计中，Cybercab 的蝴蝶门将采用无框车窗，如同特斯拉其他车型，同时门底部尖锐的棱角也进行了柔化处理，车身侧面线条更加流畅，旨在提升实用性和乘客体验。在 Cybercab 部署之前，特斯拉正积极利用现有 Model Y 车型进行 Robotaxi 服务的先行扩张，除了已有的奥斯汀和湾区测试区域，服务范围将进一步扩大到拉斯维加斯、凤凰城、达拉斯、休斯顿和迈阿密这五座美国主要城市。特斯拉还计划在今年年底前在奥斯汀的 Robotaxi 服务中移除所有安全监控员，这标志着其在实现完全无人驾驶商业化运营方面迈出了重要一步。这些实际部署将为 Cybercab 的大规模推广积累宝贵经验和数据，同时也考验着特斯拉在不同城市复杂交通环境下的应对能力。

Optimus 机械手演示为 V2 版本，V3 更为精巧

特斯拉CEO埃隆·马斯克最近透露了一个令人惊讶的事实：在2025年度股东大会上展示的，给与会者留下深刻印象的 Optmius 机械手，实际上仍是 V2 版本。马斯克在社交媒体X上表示，“这仅仅是 Optimus V2 的手。V3 的手将更上一层楼。精巧的工程设计。”这一声明表明，Optimus 的 V3 版本仍处于高度保密状态，其技术水平预计将远超现有展示。马斯克此前多次强调，机器人的手部是整个设计中最困难的部分，因为它需要极其灵巧和精确的动作来执行各种任务，甚至包括外科手术等精细操作。特斯拉致力于为 Optimus 打造高度灵敏和精细的手部，这对于实现其在工厂、家庭乃至未来更广泛应用场景中的功能至关重要。虽然 V2 版本已经展现出令人瞩目的能力，但 V3 版本的潜力预示着特斯拉在人形机器人技术上可能实现更具突破性的进展。行业内普遍认为，特斯拉在人形机器人领域的技术积累和规模化生产能力，使其有潜力在这一新兴领域占据领先地位，但其商业化落地的时间表和成本效益仍是投资者关注的重点。

工厂与制造

上海超级工厂达成500万电池包生产里程碑

特斯拉上海超级工厂本周达成了一项重要的生产里程碑，其第500万个电池包成功下线。这一成就凸显了上海工厂作为特斯拉全球最高产量制造中心和主要车辆出口枢纽的关键作用。上海超级工厂的电池包设计和组装都在中国完成，而电芯则由当地合作伙伴宁德时代和韩国LG新能源提供。特斯拉中国强调，其电池包的安全标准远超行业规范，并设计使其寿命能够超越车辆本身。尽管这一里程碑令人瞩目，但特斯拉中国最近的国内销售数据却不尽如人意。中国乘用车协会数据显示，特斯拉10月零售销量降至26,006辆，同比下降36%，创下近三年来的新低，市场份额也跌至2.03%。分析师将此归因于上海工厂上个月将更多精力放在出口上，以及小米SU7等有竞争力的中国本土品牌崛起。这一里程碑证明了特斯拉强大的制造能力和供应链效率，但如何平衡出口与本土市场需求，应对日益激烈的市场竞争，将是上海工厂未来面临的挑战。

德克萨斯州 Megafactory 启动招聘工作

特斯拉已正式启动其在德克萨斯州布鲁克希尔耗资2亿美元的 Megafactory 的招聘工作。该制造中心预计将专注于生产特斯拉的电网级 Megapack 电池，以进一步扩大公司在能源存储领域的影响力，并计划到2028年雇佣1,500名员工。目前，特斯拉招聘网站上已列出超过30个针对该工厂的职位空缺，涵盖工程师、焊工和项目经理等多个领域，显示出其正在积极构建一支多元化的专业团队。据报道，该布鲁克希尔工厂的年产能预计将达到10,000个 Megapack，相当于40吉瓦时的能源存储容量，与加州的 Lathrop Megafactory 规模相当。特斯拉与沃勒县达成了财产税减免协议，条件是在2026年前雇佣375人，2027年前750人，2028年前达到1,500人，并在随后的10年减免期内维持这一就业水平。该工厂的启动不仅对特斯拉的能源业务增长至关重要，也标志着布鲁克希尔市从传统物流向先进清洁能源制造业转型的关键一步，有望为当地经济带来高薪就业机会和新型投资。

充电与能源

超级充电桩实时可用性功能集成 Google Maps 和 Apple Maps

特斯拉已将其超级充电桩的“实时可用性”功能扩展到第三方导航应用 Google Maps 和 Apple Maps（目前仅限美国地区）。这一重要举措使得所有电动车车主，无论是否驾驶特斯拉，都能够通过这些常用地图应用实时查看附近超级充电站的可用充电桩数量、充电速度和站点详细信息，从而大幅提升了充电体验的便利性。该功能在拥堵时段尤为实用，减少了非特斯拉车主抵达充电站却发现无桩可用的风险。特斯拉自2017年便在自有车辆中引入了这一功能，并逐渐将其纳入开放充电点接口（OCPI）标准。然而，目前 Google Maps 的数据可能存在轻微延迟，且无法显示动态定价信息或清晰区分仅限特斯拉使用的 V2 充电站。尽管如此，特斯拉充电部门负责人 Max de Zegher 表示，这仅仅是第三方平台整合的开始，未来将寻求实现实时等待时间、预测可用性和动态重新规划路线等更高级功能，最终目标是让特斯拉的“出行规划器”扮演电动车充电的“空中交通管制员”角色，以优化整个充电网络的效率。

大众汽车旗下电动车将接入特斯拉超级充电网络

大众汽车宣布，从11月18日起，其ID.4和ID.Buzz电动车车主将能访问北美地区的特斯拉超级充电网络。此举将使大众电动车用户在加拿大和美国获得超过25,000个特斯拉超级充电桩的充电选择，显著扩展了其充电范围，超越了Electrify Canada和其他基于CCS标准的网络。为实现与特斯拉北美充电标准（NACS）的兼容，大众汽车开发了一款直流快速充电适配器，可将特斯拉的NACS插头连接到大众现有电动车使用的CCS端口。该适配器将通过大众经销商或线上平台发售，售价为304加元。大众车主将能够利用特斯拉移动应用定位兼容的超级充电站、发起充电会话并直接完成支付。此外，部分2024和2025款ID.4和ID.Buzz车型可能需要软件更新，以确保在使用特斯拉网络时的最佳充电性能。此举标志着NACS标准在北美地区持续成为主导充电接口，大众汽车的加入进一步巩固了特斯拉超级充电网络的行业地位，同时也为其他品牌电动车主带来了更便捷的充电体验。

市场与交付

中国市场长续航 Model Y+ 发布并引发强劲需求

特斯拉在中国市场推出了全新长续航 Model Y+，该车型在CLTC工况下的续航里程达到了惊人的821公里（510英里），定价为人民币28.85万元（约合4.05万美元）起。这款内部代号“Y+”的新车型，上市首日便获得了足以填补上海超级工厂数周产量的订单，据报道，仅在北京地区单日就售出了约400辆，门店客流量激增，其中近一半访客都是专为了解 Model Y+ 而来。市场对 Model Y+ 的强劲需求已导致其在线配置器的初始交付预估从2-4周延长至4-6周。Model Y+ 搭载了升级的78.4-kWh LG Energy Solution电池组，与今年秋季早些时候发布的 Model 3 长续航+（CLTC续航约830公里）使用相同电池化学。此次发布的时机非常关键，因为特斯拉中国10月份的零售销量跌至26,006辆，同比下降35.8%，创下近三年来的新低，市场份额也首次跌出中国新能源汽车品牌前十名，降至2.03%。Model Y+ 的推出有望扭转特斯拉在中国市场的颓势，通过高性价比的长续航产品重新激发消费者需求，但其能否持续保持销售势头，并应对日益激烈的本土品牌竞争，仍需持续观察。

特斯拉中国推出 Model Y L 和 Performance 专用 V2L 适配器

特斯拉中国发布了一款新型紧凑型 Vehicle-to-Load (V2L) 适配器，专为 Model Y L 和即将推出的 Model Y Performance 设计。这是继 Cybertruck 之后，特斯拉首次为 Model Y 系列引入 V2L Powershare 功能，为用户提供了比现有 Powershare 移动适配器更便捷的第二种选择。这款适配器提供2200W的峰值输出（220V，10A），并集成了中国标准的Type A和Type I插座。特斯拉通过视频展示了该适配器的实用场景，例如同时为一台600W的便携式电饭锅、一台600W的便携式电热水壶和一台1000W的便携式火锅供电，这使得它非常适合露营或作为家庭停电时的备用电源。相较于需要连接移动充电器线的传统适配器，这款新适配器更轻巧、更易用。该适配器预计在未来几周内通过特斯拉中国商店发售，并免费提供给近期购买 Model Y L 的车主。这一举措不仅提升了 Model Y 特定版本的实用性和吸引力，也反映了特斯拉针对不同市场需求的快速响应能力，并预示着未来V2L功能可能在全球更多特斯拉车型上普及。

特斯拉暗示将进入哥伦比亚市场 特斯拉在社交媒体X上发布了一段视频，以模糊而神秘的方式暗示其即将进入新的市场——哥伦比亚。这段视频仅展示了南美洲国家的轮廓，并未提供任何具体细节，但结合特斯拉此前在哥伦比亚发布的多个招聘信息，如销售顾问、服务技术员和销售交付经理等，基本确认了这一市场扩张计划。哥伦比亚将成为继智利之后，特斯拉在南美洲的第二个正式运营国家。目前，特斯拉在整个南美洲仅在智利拥有两个超级充电站，这意味着如果特斯拉要在哥伦比亚以及更广泛的南美市场取得成功，其充电基础设施需要进行大规模扩张。尽管如此，哥伦比亚的进入策略也可能反映了特斯拉对“中间市场”的优先关注，而非一开始就进入如巴西这样更大但基础设施挑战可能更大的市场。此次市场扩张预计将提升特斯拉在全球范围内的品牌影响力，并为其带来新的增长点，但充电网络建设的投入和速度将是其在当地能否快速打开局面的关键。
