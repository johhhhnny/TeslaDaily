Autopilot

特斯拉日报 2026-03-05

柏林工厂工会选举结果：特斯拉柏林超级工厂劳资委员会选举中，非工会派“Giga United”获胜，工会IG Metall得票率显著下降，为工厂未来大规模扩张创造了有利条件。 Robotaxi欧洲生产规划：特斯拉发布招聘信息，暗示柏林超级工厂将为Robotaxi生产奠定基础，未来还将生产Semi、Cybercab和Optimus机器人，并计划到2027年达到8GWh电池产能。 Cybertruck主动降噪激活：Cybertruck通过软件更新2026.2.6.1（或2026.2.9）激活“主动道路降噪”功能，提升驾驶舒适性。 FSD术语更名：特斯拉发布软件更新2026.2.9，将“Navigate on Autopilot”更名为“Navigate on Autosteer”，“FSD Computer”更名为“AI Computer”，以符合加州监管要求。 FSD即将登陆日本：特斯拉有望在2026年底前在日本推出FSD，已开始员工及客户试驾，并计划到2027年在日本将超级充电网络扩展至1000个点。 供应链可持续性领先：特斯拉连续第二年在“Lead the Charge”榜单中荣登电动汽车供应链可持续性排名榜首，总分49%，在电池供应链透明度方面取得显著提升。 Powerwall兼容性提升：特斯拉Powerwall 3将在澳大利亚率先获得与Powerwall 2的兼容性，允许用户灵活组合以增加储能容量。 加拿大充电网络扩张：特斯拉在魁北克省新增开放两个V4超级充电站，共增加28个充电桩。 特斯拉Semi商业部署：Hight Logistics公司在其车队中增加了一辆特斯拉Semi电动卡车，并计划未来增购。 下一代Roadster座椅专利：特斯拉获得一项一体式复合材料座椅设计的专利，采用创新技术，预计将应用于下一代Roadster，并可能推广至其他车型。 Model Y摄像头修复**：特斯拉发布针对Model Y前置摄像头进水问题的服务公告，提供诊断与维修方案。

2026-03-05

特斯拉日报 2026-03-02

技术与太空: SpaceX宣布Starlink V2卫星将从2028年起，与德国电信合作在欧洲10国提供直连手机服务，旨在实现5G级别连接。 SpaceX推出下一代Starship V3 SN1，预计3月首飞，以期实现完全可重复使用性。 市场与交付: 特斯拉已从加拿大官网下架所有Model 3库存，可能为利用新开放的中国产电动车进口配额做准备。 特斯拉2月在挪威销量强劲反弹，以1,210辆重回榜首；在西班牙销量飙升73.7%，显示欧洲市场复苏。 特斯拉在德国柏林超级工厂的制造总监澄清，2025年Model Y实际产量超过20万辆，驳斥了媒体的错误报道。 工厂与制造: 埃隆·马斯克提出Giga Berlin大规模扩张计划，包括在欧洲首次生产电池电芯，以及未来可能引入Semi、Optimus和Cybercab生产线。 其他: 特斯拉通过软件更新2026.2.9，调整了Autopilot相关功能名称，以符合加州DMV的规定。 加拿大充电奖励平台WattsApp在3月推出促销活动，推荐5位朋友可获得家庭充电双倍积分。 * 拉斯维加斯特斯拉碰撞中心纵火案嫌疑人认罪，面临最高70年监禁。

特斯拉日报 2026-02-28

特斯拉发布2026.2.9软件更新，将“Autopilot”更名为“Autosteer”，“FSD计算机”更名为“AI计算机”。 FSD（监督版）转移政策更新：截止日期改为必须在2026年3月31日或之前完成车辆交付。 特斯拉CEO埃隆·马斯克建议投资者持有特斯拉股票，并对公司未来价值表示看好。 特斯拉在《Model Y车主手册》中更新电池保养建议，不建议日常频繁使用超级充电桩。 加拿大市场Model Y获得内饰升级，包括黑色顶棚和16英寸中控屏。 宝马暂停其7系车型的L3级“免视”自动驾驶技术。

特斯拉日报 2026-02-25

- 特斯拉在瑞典延雪平市申请FSD (监督版) 测试许可。 - Cybertruck即将通过软件更新激活主动降噪 (ANC) 功能。 - 特斯拉已将59,990美元的Cybertruck双电机全轮驱动版从推荐计划中移除，因订单激增。 - Cybertruck双电机全轮驱动版价格将于2月28日之后上涨，预计交付时间推迟至2026年9月-10月。 - 特斯拉与LG能源解决方案达成协议，将在美国扩大LFP电池供应，用于储能系统(ESS)。 - 特斯拉在澳大利亚和新西兰推出Grok AI车载助理。 - 特斯拉加拿大更新租赁政策，为部分车型租约期满购买开启可能性。 - 特斯拉Model S和Model X部分定制选项开始减少，预示停产临近。 - 特斯拉在2026年1月欧洲销量同比下降17%，市场份额下滑，比亚迪销量翻番并超越特斯拉。 - 特斯拉在加拿大阿尔伯塔省Penhold开设新的V4超级充电站。 - 特斯拉确认好莱坞Diner餐厅使用Cybertruck生产中的回收不锈钢建造。 - 特斯拉应用4.54.0更新将引入“自动驾驶统计”和潜在的“受FSD影响”功能，并暗示新的忠诚度计划。 - 美国联邦法官命令特斯拉就H-1B签证招聘歧视诉讼出庭应诉。 - 特斯拉向美国专利商标局(USPTO)提出异议，挑战法国公司UNIBEV对“Cybercab”商标的注册申请。 - SpaceX的目标是将星链“直连手机”服务的峰值速度提升至每用户150Mbps，有望改善特斯拉高级互联服务。

特斯拉日报 2026-02-24

特斯拉就Autopilot和FSD广告误导性裁决起诉加州DMV。 Cybertruck双电机全轮驱动版交付时间推迟至2026年9月-10月，并确认将于2月28日涨价。 Giga Berlin工厂管理层在与德国工会IG Metall的冲突中，以“进步、创新、成功”的横幅表达团结立场。 特斯拉在澳大利亚和新西兰推出xAI的Grok AI助手，支持自然语言导航。 特斯拉正升级Matrix头灯，提升对高反光物体的处理能力，引入两阶段像素级调光。 特斯拉德克萨斯州Megapack超级工厂取得进展，两栋总面积超160万平方英尺的租赁建筑已售予机构投资者。 特斯拉Model 3预计将迎来内饰升级，包括黑色Alcantara风格顶棚和16英寸QHD显示屏。 加拿大新斯科舍省将从2026年10月1日起对电动汽车和混合动力车征收新税，两年期分别为500加元和250加元。 * 瑞典特斯拉罢工工人因工会IF Metall的税务处理错误将获得两年所得税退款，但可能影响养老金和福利。
