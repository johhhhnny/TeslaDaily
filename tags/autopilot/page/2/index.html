特斯拉日报 2026-05-07

6座Model Y L在美国德州超级工厂被发现，暗示即将进入北美市场生产。 2026款特斯拉Model Y成为首款通过美国国家公路交通安全管理局(NHTSA)全新ADAS安全测试的车型，涵盖行人自动紧急制动、车道保持辅助等四项新标准。 特斯拉中国上海超级工厂4月Model 3和Model Y出货量达79,478辆，同比增长36%，创该月新高。 特斯拉4月在德国销量同比增长256%，达到3,149辆；在韩国销量13,190辆，创历史新高。 特斯拉在欧洲将终止FSD的一次性购买选项，转向订阅模式，多数地区截止日期为5月21日。 特斯拉Semi首次运载Cybercab单元离开德州超级工厂，预示机器人出租车开始交付。 * 特斯拉通过OTA软件更新召回近21.9万辆美国车辆，修复后视摄像头延迟问题。

特斯拉日报 2026-04-26

财报亮点： 特斯拉公布Q1财报，自由现金流达14亿美元，营收符合或略超预期。 FSD硬件： 埃隆·马斯克承认，数百万辆搭载HW3的特斯拉汽车需硬件升级才能支持未来无需人工监督的FSD。 柏林工厂： 柏林超级工厂Q1 Model Y产量创纪录，突破61,000辆，宣布将提升20%产能，并新增1,000名员工，500名临时工转正。 销售激励： 特斯拉北美地区为Model 3长续航版和高性能版提供一年免费超级充电服务。 充电体验： 特斯拉推出超级充电站虚拟排队系统，以解决排队争议。 SpaceX动态： SpaceX向FCC提交下一代星链网关申请，旨在提供千兆级连接速度；FCC驳回SpaceX关于直接对设备（D2D）卫星通信服务的频谱申请。

特斯拉日报 2026-04-24

市场拓展：特斯拉与Sourcewell签订合同，开放对美国超过5万个政府机构的车辆及能源解决方案直销。 技术进展：Robotaxi应用正式登陆Android平台，并在休斯顿和达拉斯扩展服务范围。 FSD硬件：特斯拉正式承认Hardware 3 (HW3) 无法实现无监督全自动驾驶 (Unsupervised FSD)，并公布了HW4升级计划和车辆置换折扣方案。 FSD软件：FSD v14.3.2版本发布，通过统一AI模型显著改进了召唤功能，并提升了街头驾驶体验。 AI与机器人：特斯拉签署协议，计划以高达20亿美元收购一家神秘AI硬件公司，以加速机器人和AI领域的研发。 关联公司：SpaceX加入美国“金色穹顶”导弹防御系统核心软件开发团队，负责卫星通信集成。
