特斯拉日报 2025-11-28

特斯拉在北美推出FSD v14.2的30天免费试用，面向HW4车辆。 FSD v14.2.1发布，面向AI4车辆（包括Cybertruck），并获得用户广泛好评。 FSD（受监督）在意大利、法国、德国启动公众乘客试乘项目，捷克议员暗示将审查FSD。 Cybertruck首次在北美以外地区交付，首批客户在韩国收到车辆。 特斯拉中国驳斥减少对中国供应商依赖的报告，重申全球采购标准。 特斯拉在印度古尔冈开设首个一体化体验中心，提供销售、服务和充电，并展示Optimus Gen 2机器人。 新款Model 3荣获新西兰2025年度最佳乘用车奖。 Elon Musk展望未来移动设备将演变为AI边缘节点，而非传统智能手机。 瑞典工会不满特斯拉规避其邮政封锁以获取车辆牌照。 星链（Starlink）硬件及配件现已在亚马逊上架。

特斯拉日报 2025-11-27

- 特斯拉FSD获准在瑞典Nacka市进行城市环境测试，但遭遇部分官员因工会冲突提出的反对。 - 埃隆·马斯克宣布下月奥斯汀Robotaxi车队将翻倍至约60辆，远低于此前设定的2025年底500辆无人监督运营目标。 - Model 3和Model Y在挪威被评为各自细分市场的最佳购车选择，Model 3重获转向灯拨杆，Model Y改进显著。 - 加拿大不列颠哥伦比亚省Delta市的Supercharger充电站经过近两年延期后，12个V3充电桩正式启用。 - 特斯拉在加拿大Supercharger地图更新中新增了不列颠哥伦比亚省Sicamous和萨斯喀彻温省Nipawin两个“开发中”站点。 - 柏林超级工厂已转为两班制，持续提升Model Y产量以满足全球需求，并开始向加拿大出口。 - 特斯拉宣布其在新西兰的车辆保有量已达到20,000辆，Model Y成为当地主要销量贡献者。 - 特斯拉在北美地区（美国、加拿大、波多黎各、墨西哥）推出为期30天的FSD (监督版) v14.2免费试用，覆盖所有符合条件的AI4硬件车辆。 - 特斯拉App更新至v4.51.1版本，新增对FSD单月订阅礼品卡功能的支持，该商品即将上线。

特斯拉日报 2025-11-26

技术进展: 特斯拉发布2025.44更新，为Intel Atom MCU2车型带来Dashcam Viewer功能对齐AMD Ryzen。 特斯拉正招聘AI工程师，旨在通过“推理”和“蒸馏”技术增强FSD的复杂场景处理能力。 特斯拉Robotaxi应用更新，推出车内数据共享功能，为移除安全驾驶员做准备。 外部：Uber与WeRide在阿布扎比推出全无人驾驶Robotaxi服务，为美国和中国以外首例。 外部：埃隆·马斯克旗下的xAI提议Grok 5与《英雄联盟》世界冠军队进行人机对战。 充电与能源: 特斯拉在加州Lost Hills完成全球最大Supercharger站点的建设，拥有168个充电桩，并实现完全太阳能供电和离网运行。 外部：Starlink Direct-to-Cell服务在智利正式上线，成为拉美首个提供手机直连卫星服务的国家。 市场与交付: 特斯拉宣布12月将在奥斯汀将其Robotaxi车队规模扩大一倍。 特斯拉FSD（监督版）在韩国正式上线，初期仅限AI4（HW4）的Model S和Model X车型。 瑞穗证券维持特斯拉“跑赢大盘”评级，但下调目标价至475美元，理由是2026年美国和中国电动汽车补贴可能削减。 特斯拉改变传统策略，开始在社交媒体平台X上投放FSD付费广告。 特斯拉在挪威创下年度销量新纪录，超越大众汽车，成为单一年度注册量最高的品牌。 Model Y Standard版上市，其与Premium版的主要差异在于内部储物空间和音响系统。
