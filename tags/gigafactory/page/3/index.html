特斯拉日报 2026-04-30

特斯拉Semi电动卡车在内华达州启动高产量生产线，首批新版Semi卡车下线。 特斯拉公布一项视觉导航专利，旨在解决GPS盲区，为Robotaxi和Optimus机器人提供基础。 特斯拉Model X在2026年第一季度成为美国二手车市场最快售出车型，平均25.6天售出。 NHTSA召回文件显示，Cybertruck后轮驱动版（RWD）仅售出173辆后已停产。 SpaceX宣布与AI编程初创公司Cursor建立战略合作，并拥有600亿美元收购选项。 Halter公司推出由SpaceX Starlink网络支持的直连卫星智能牛项圈。

特斯拉日报 2026-04-26

财报亮点： 特斯拉公布Q1财报，自由现金流达14亿美元，营收符合或略超预期。 FSD硬件： 埃隆·马斯克承认，数百万辆搭载HW3的特斯拉汽车需硬件升级才能支持未来无需人工监督的FSD。 柏林工厂： 柏林超级工厂Q1 Model Y产量创纪录，突破61,000辆，宣布将提升20%产能，并新增1,000名员工，500名临时工转正。 销售激励： 特斯拉北美地区为Model 3长续航版和高性能版提供一年免费超级充电服务。 充电体验： 特斯拉推出超级充电站虚拟排队系统，以解决排队争议。 SpaceX动态： SpaceX向FCC提交下一代星链网关申请，旨在提供千兆级连接速度；FCC驳回SpaceX关于直接对设备（D2D）卫星通信服务的频谱申请。

特斯拉日报 2026-04-24

市场拓展：特斯拉与Sourcewell签订合同，开放对美国超过5万个政府机构的车辆及能源解决方案直销。 技术进展：Robotaxi应用正式登陆Android平台，并在休斯顿和达拉斯扩展服务范围。 FSD硬件：特斯拉正式承认Hardware 3 (HW3) 无法实现无监督全自动驾驶 (Unsupervised FSD)，并公布了HW4升级计划和车辆置换折扣方案。 FSD软件：FSD v14.3.2版本发布，通过统一AI模型显著改进了召唤功能，并提升了街头驾驶体验。 AI与机器人：特斯拉签署协议，计划以高达20亿美元收购一家神秘AI硬件公司，以加速机器人和AI领域的研发。 关联公司：SpaceX加入美国“金色穹顶”导弹防御系统核心软件开发团队，负责卫星通信集成。

特斯拉日报 2026-04-23

Cybercab在德州超级工厂启动批量生产，月内已发现60辆，目标年产200万辆。 特斯拉确认FSD v15将兼容现有的HW4硬件，并计划推出具备双倍内存的AI4+芯片。 FSD v14.3.2已推出，统一了Robotaxi、FSD和智能召唤的模型，并新增了驾驶员干预原因报告功能。 HW3车辆被确认无法支持无监督FSD，但特斯拉将提供V14-lite更新和折扣以旧换新方案。 Model Y L车型在美国首次进行路测，预示其北美市场发布临近。 埃隆·马斯克表示，新一代Roadster跑车有望在一个月左右首次亮相，这将是特斯拉最后一款以手动驾驶为主的车型。 * 特斯拉已取消向埃隆·马斯克授予的290亿美元临时薪酬方案，因特拉华州最高法院已恢复其2018年更大的560亿美元薪酬方案。

特斯拉日报 2026-04-18

Robotaxi服务扩展： Tesla在德克萨斯州的达拉斯和休斯顿推出无人驾驶Robotaxi服务。 Signature Edition Model S/X： 特斯拉对限量版Model S和X Plaid车主施加一年内不得转售的限制，以打击投机行为。 Cybertruck销售： 2025年第四季度Cybertruck的销售数据受到埃隆·马斯克旗下公司（如SpaceX）内部大规模采购的显著提振。 Robotaxi功能推送： Tesla通过2026年春季更新，向现有车主车辆推送了包括后排交互式导航地图在内的Robotaxi相关功能。 法律诉讼：** Tesla起诉北达科他州，挑战其禁止汽车制造商直销的法律。
