特斯拉日报 2026-03-06

北美地区取消Model S和Model X的引荐计划，Cybertruck引荐折扣调整为3个月FSD使用权，并削减Model S、Model X及Cybertruck的忠诚奖励。 特斯拉Model Y L（六座加长版）正式宣布于2026年在澳大利亚和新西兰上市，并获得韩国市场认证。 马斯克的AI公司xAI计划在孟菲斯超算中心进行耗资6.59亿美元的扩建。 特斯拉计划于2026年底在日本推出FSD (Supervised) 系统，同时将韩国FSD转让交付截止日期延长至6月30日。 加拿大Supercharger网络持续扩张，不列颠哥伦比亚省坎贝尔里弗站点已开始施工，多地新站点进入开发阶段。 特斯拉公布了新一代Roadster的一体式座椅系统专利，预示其即将亮相。 * 特斯拉App更新至4.54.5版本，新增“自动驾驶统计”功能、优化家用充电桩详情显示，并加入Powershare功能介绍。

2026-03-06

特斯拉日报 2026-03-05

柏林工厂工会选举结果：特斯拉柏林超级工厂劳资委员会选举中，非工会派“Giga United”获胜，工会IG Metall得票率显著下降，为工厂未来大规模扩张创造了有利条件。 Robotaxi欧洲生产规划：特斯拉发布招聘信息，暗示柏林超级工厂将为Robotaxi生产奠定基础，未来还将生产Semi、Cybercab和Optimus机器人，并计划到2027年达到8GWh电池产能。 Cybertruck主动降噪激活：Cybertruck通过软件更新2026.2.6.1（或2026.2.9）激活“主动道路降噪”功能，提升驾驶舒适性。 FSD术语更名：特斯拉发布软件更新2026.2.9，将“Navigate on Autopilot”更名为“Navigate on Autosteer”，“FSD Computer”更名为“AI Computer”，以符合加州监管要求。 FSD即将登陆日本：特斯拉有望在2026年底前在日本推出FSD，已开始员工及客户试驾，并计划到2027年在日本将超级充电网络扩展至1000个点。 供应链可持续性领先：特斯拉连续第二年在“Lead the Charge”榜单中荣登电动汽车供应链可持续性排名榜首，总分49%，在电池供应链透明度方面取得显著提升。 Powerwall兼容性提升：特斯拉Powerwall 3将在澳大利亚率先获得与Powerwall 2的兼容性，允许用户灵活组合以增加储能容量。 加拿大充电网络扩张：特斯拉在魁北克省新增开放两个V4超级充电站，共增加28个充电桩。 特斯拉Semi商业部署：Hight Logistics公司在其车队中增加了一辆特斯拉Semi电动卡车，并计划未来增购。 下一代Roadster座椅专利：特斯拉获得一项一体式复合材料座椅设计的专利，采用创新技术，预计将应用于下一代Roadster，并可能推广至其他车型。 Model Y摄像头修复**：特斯拉发布针对Model Y前置摄像头进水问题的服务公告，提供诊断与维修方案。

2026-03-05

特斯拉日报 2026-03-04

特斯拉欧洲排放池缩小：丰田和Stellantis退出2026年合作，影响监管信用收入。 安全争议：特斯拉因Model S门把手安全缺陷面临集体诉讼；中国已禁止纯电动门把手。 AGI愿景：埃隆·马斯克预言特斯拉将率先打造具人形通用人工智能（AGI）的机器人。 Optimus生产：Model S/X弗里蒙特生产线将改造用于Optimus试点生产，目标年产100万台。 FSD进展：特斯拉FSD (Supervised) 在韩国推出约100天，累计行驶里程突破800万公里。 AI芯片：特斯拉正与三星谈判，计划将AI6芯片月产量提升至约40,000片晶圆。 澳大利亚市场：特斯拉2月销量显著反弹，Model Y继续主导电动汽车市场。 充电网络：特斯拉在马来西亚向非特斯拉电动车开放部分超级充电站，履行当地承诺。 能源业务：特斯拉发布太阳能电池板投资回收期新指南，强调联邦税收抵免到期后的财务回报。 华尔街评估：美国银行看好特斯拉自动驾驶，将52%估值归于其Robotaxi雄心，FSD累计里程超84亿英里。 * FSD版本：FSD v14.2.2.5用户反馈褒贬不一，被评为“最令人困惑的版本”。

特斯拉日报 2026-03-03

特斯拉加拿大官网清空所有Model 3现车库存，为中国产Model 3进口做准备。 马斯克旗下xAI和X据报正准备全额偿还约175亿美元债务。 BC Hydro宣布自2026年4月1日起上调电动汽车充电费率，新站点将兼容NACS。 特斯拉柏林超级工厂负责人公开反驳德国媒体关于2025年生产数据的错误报道，称实际产量远超报道。 特斯拉针对柏林工厂生产的Model Y Juniper车型发布服务公告，解决前刹车异响问题。 三星得克萨斯州芯片工厂量产计划据报再次推迟至明年初，可能影响特斯拉下一代AI芯片（AI5/AI6）的生产。 特斯拉正在加速Cybercab（Robotaxi）的测试生产，得州超级工厂已观测到25辆测试车。 特斯拉收紧FSD（完全自动驾驶）转移政策，引发社区热议。 SpaceX在3月1日成功执行两次猎鹰9号发射任务，部署54颗星链卫星。 华盛顿州立法机构推进法案，允许Rivian和Lucid直接向客户销售电动汽车，与特斯拉此前获准模式类似。 特斯拉Semi电动卡车被发现由Ralph's超市（Kroger旗下）在南加州投入使用。 特斯拉面临针对Model S电子门把手设计的集体诉讼，原告称紧急情况下存在安全隐患。 SpaceX计划从2027年中期开始，使用星舰（Starship）发射下一代星链V2卫星。 有传闻称苹果可能在CarPlay中添加AirPlay类似功能，允许在停车时观看Apple TV，这将使CarPlay集成对特斯拉更具吸引力。

特斯拉日报 2026-03-02

技术与太空: SpaceX宣布Starlink V2卫星将从2028年起，与德国电信合作在欧洲10国提供直连手机服务，旨在实现5G级别连接。 SpaceX推出下一代Starship V3 SN1，预计3月首飞，以期实现完全可重复使用性。 市场与交付: 特斯拉已从加拿大官网下架所有Model 3库存，可能为利用新开放的中国产电动车进口配额做准备。 特斯拉2月在挪威销量强劲反弹，以1,210辆重回榜首；在西班牙销量飙升73.7%，显示欧洲市场复苏。 特斯拉在德国柏林超级工厂的制造总监澄清，2025年Model Y实际产量超过20万辆，驳斥了媒体的错误报道。 工厂与制造: 埃隆·马斯克提出Giga Berlin大规模扩张计划，包括在欧洲首次生产电池电芯，以及未来可能引入Semi、Optimus和Cybercab生产线。 其他: 特斯拉通过软件更新2026.2.9，调整了Autopilot相关功能名称，以符合加州DMV的规定。 加拿大充电奖励平台WattsApp在3月推出促销活动，推荐5位朋友可获得家庭充电双倍积分。 * 拉斯维加斯特斯拉碰撞中心纵火案嫌疑人认罪，面临最高70年监禁。

特斯拉日报 2026-02-28

特斯拉发布2026.2.9软件更新，将“Autopilot”更名为“Autosteer”，“FSD计算机”更名为“AI计算机”。 FSD（监督版）转移政策更新：截止日期改为必须在2026年3月31日或之前完成车辆交付。 特斯拉CEO埃隆·马斯克建议投资者持有特斯拉股票，并对公司未来价值表示看好。 特斯拉在《Model Y车主手册》中更新电池保养建议，不建议日常频繁使用超级充电桩。 加拿大市场Model Y获得内饰升级，包括黑色顶棚和16英寸中控屏。 宝马暂停其7系车型的L3级“免视”自动驾驶技术。
