特斯拉日报 2025-11-24

FSD国际拓展与监管： FSD (Supervised) v14.1.4已在韩国部署；内华达州批准特斯拉自动驾驶车辆运营；荷兰RDW监管机构确认2026年2月为FSD在欧演示合规目标，但强调非保证批准。 AI芯片进展： 特斯拉AI5芯片设计接近定稿，AI6已启动开发，目标每年推出新芯片设计并量产。 传统车企FSD授权： 马斯克称传统车企对许可特斯拉FSD不感兴趣或提出不可行条件，警告其未来将受损。 Model X制造： Model X通过数百项改进，成功减重近400磅。 能源储能： 澳大利亚Golden Plains风电场将部署168个Megapack 2 XL电池系统。 充电网络体验： 特斯拉迅速回滚Supercharger导航显示调整，并计划在12月进行更完善的UI更新。 挪威市场表现： 特斯拉11月在挪威销量强劲，全年有望打破大众历史纪录；瑞典市场表现挣扎，工会抗议持续。 租车服务： 特斯拉在美国多州扩展租车计划，提供包含FSD、免费超充和无限里程的全包式服务。 法律诉讼： 华盛顿州一家庭就2018年“意外加速”致死事故起诉特斯拉。 Cybertruck应用： 拉斯维加斯警方正式启用10辆改装版Cybertruck作为巡逻车。 第三方充电设施：** 加拿大BC Hydro推出首个移动式EV快充站，采用高架供电方式简化部署。

特斯拉日报 2025-11-18

- 欧洲Supercharger充电站开始支持包括34种主流服务商的第三方电动汽车充电卡，未来数周内将增加40余种。 - 特斯拉Robotaxi服务今日起向美国和加拿大所有iOS用户全面开放，覆盖奥斯汀和旧金山湾区。 - 埃隆·马斯克确认下一代AI5芯片量产将推迟至2027年中，Cybercab将搭载AI4硬件于2026年4月投产。 - 特斯拉与Syrah Resources的石墨供应协议因技术问题再次延期，最终资质认定截止日期为2026年2月9日。 - 特斯拉已开始推送2025.44软件更新，为即将到来的年度假日更新做准备，包含Dashcam和Cabin Overheat Protection改进。 - 加州法院驳回了针对特斯拉弗里蒙特工厂的涉及6,000名黑人员工的种族歧视集体诉讼。 - 亚马逊旗下的Zoox和Alphabet旗下的Waymo在自动驾驶领域均取得新进展，分别在旧金山和迈阿密开放或拓展了服务。 - 有乘客在旧金山湾区搭乘特斯拉Robotaxi时，报告安全驾驶员在驾驶过程中多次睡着。 - 飞迪拜航空宣布将从2026年起在其全部机队上部署SpaceX的Starlink机载Wi-Fi服务。

2025-11-18

特斯拉日报 2025-11-17

市场动态： Stifel将特斯拉目标股价上调至$508，TD Cowen重申$509目标价；野村资管增持特斯拉4.2%，成为其第十大持仓；Peter Thiel大幅减持股份。 销售策略： 特斯拉推出Model Y/Model 3 Standard版；美国市场Model Y租赁计划实现零首付并提供免费升级。 自动驾驶： Robotaxi测试车首次在宾夕法尼亚州被发现；Robotaxi又发生3起碰撞，总数达7起；特斯拉推出FSD (Supervised) 实时安全仪表板，日均行驶约1440万英里。 机器人： 特斯拉设定Optimus机器人量产价格目标$20,000，计划2026年开始Gen 3生产并实现极速产能爬坡。 供应链： 特斯拉正推动供应商削减用于美国汽车的中国制造零部件。 充电网络： 超级充电站“实时定价”策略扩展到美国另外550个站点。 法律诉讼： 特斯拉解决另一起Autopilot碰撞诉讼；起诉北达科他州直销禁令。 其他： 埃隆·马斯克暗示可能撰写自传；2025年假日更新即将推出。

特斯拉日报 2025-11-15

特斯拉更新美国和加拿大推荐计划，首次将FSD试用和购买纳入激励范畴，并新增FSD演示试驾奖励。 在美国市场推出Model Y租赁的零首付促销，同时提供一项免费升级选项，以大幅降低购车门槛。 * 特斯拉加速供应链多元化，计划在未来两年内逐步淘汰美国工厂中使用的中国制造零部件，以应对地缘政治和关税风险。

2025-11-15

特斯拉日报 2025-11-14

FSD相机清洁服务： 特斯拉针对前置摄像头玻璃内侧雾化问题，通过FSD v14.1.7更新（2025.38.8.7版本）推出车辆检测警报，并提供免费的精确清洁服务。 FSD安全报告发布： 特斯拉公布FSD（监管版）详细安全数据，声称其在北美地区发生重大和轻微碰撞的里程数是人类驾驶的7倍以上。 Robotaxi竞争升级： 特斯拉CEO埃隆·马斯克回应Waymo的2500辆Robotaxi车队规模为“新手级别”，并重申特斯拉将在年底前大幅扩张其在奥斯汀和湾区的Robotaxi车队。 FSD推荐计划更新： 特斯拉在美国和加拿大更新了推荐计划，引入了推荐他人完成FSD（监管版）试驾即可获得积分的新奖励。 投资者信心： 亿万富翁投资者罗恩·巴伦重申其对特斯拉和SpaceX的长期持有承诺，将其称为“一生投资”，并透露其个人净资产的40%投资于特斯拉。 第三方屏幕发布： Enhance Auto推出S3XY Dash，一款支持Apple CarPlay、Android Auto并显示深度车辆数据的定制化显示器。 圣诞模式更新预告： 刷新版2026款Model S和Model X车辆暂时缺少“圣诞模式”，但特斯拉预告该功能将“很快推出”，暗示底层可视化引擎升级。 Starlink航空合作： 消息称阿联酋航空有望与SpaceX达成Starlink机上Wi-Fi合作协议，进一步扩大Starlink在商业航空领域的影响力。

2025-11-14

特斯拉日报 2025-11-13

FSD更新与拓展： 特斯拉已向美国和加拿大用户推送FSD V14.1.7版本，新增3D建筑和Tron模式；同时宣布FSD功能即将进入韩国市场。 xAI融资辟谣： 埃隆·马斯克否认其AI初创公司xAI已获得150亿美元融资的报道。 中国EV加速限制： 中国正考虑出台新规，限制电动汽车启动加速至0-100公里/小时不低于5秒。 澳大利亚里程碑： 特斯拉在澳大利亚庆祝累计交付15万辆电动汽车。 CarPlay集成： 据报道，特斯拉正在内部测试Apple CarPlay集成功能。 Powerwall 2召回： 特斯拉Powerwall 2在美国召回约10,500台，原因是电池过热和火灾风险。 充电网络认可： 特斯拉超级充电网络连续第二年被评为英国最佳电动汽车充电网络。 NACS普及： 大众汽车宣布其ID.4和ID. Buzz车主将于11月18日起通过NACS适配器使用特斯拉在北美的超级充电网络；法拉第未来也宣布2026年起其车型将采用特斯拉NACS标准。 Starlink非洲扩张： Vodacom与Starlink合作，将在非洲20多个国家扩大互联网接入，但南非因监管障碍暂时除外。 传统车企反思： 福特CEO吉姆·法利承认，拆解特斯拉和中国电动汽车后，对福特的效率差距感到“谦卑”。 Boring Company安全事故：** 埃隆·马斯克旗下的Boring Company在拉斯维加斯隧道施工现场发生化学烧伤事故。
