特斯拉日报 2025-11-24

FSD国际拓展与监管： FSD (Supervised) v14.1.4已在韩国部署；内华达州批准特斯拉自动驾驶车辆运营；荷兰RDW监管机构确认2026年2月为FSD在欧演示合规目标，但强调非保证批准。 AI芯片进展： 特斯拉AI5芯片设计接近定稿，AI6已启动开发，目标每年推出新芯片设计并量产。 传统车企FSD授权： 马斯克称传统车企对许可特斯拉FSD不感兴趣或提出不可行条件，警告其未来将受损。 Model X制造： Model X通过数百项改进，成功减重近400磅。 能源储能： 澳大利亚Golden Plains风电场将部署168个Megapack 2 XL电池系统。 充电网络体验： 特斯拉迅速回滚Supercharger导航显示调整，并计划在12月进行更完善的UI更新。 挪威市场表现： 特斯拉11月在挪威销量强劲，全年有望打破大众历史纪录；瑞典市场表现挣扎，工会抗议持续。 租车服务： 特斯拉在美国多州扩展租车计划，提供包含FSD、免费超充和无限里程的全包式服务。 法律诉讼： 华盛顿州一家庭就2018年“意外加速”致死事故起诉特斯拉。 Cybertruck应用： 拉斯维加斯警方正式启用10辆改装版Cybertruck作为巡逻车。 第三方充电设施：** 加拿大BC Hydro推出首个移动式EV快充站，采用高架供电方式简化部署。

特斯拉日报 2025-11-21

特斯拉FSD (Supervised) V14.2已开始向首批配备AI4硬件的车辆推送，并有望进行“广泛发布”，新版FSD新增高分辨率视觉编码器、多项驾驶行为改进及“自动驾驶统计”菜单。 加拿大市场重新开放Model Y Performance订单，售价C$74,990起，预计2026年3月交付，新车在设计和配置上均有显著升级。 更新版2026 Model S和Model X已引入中国市场，但受中美贸易关税影响，目前仅限库存销售，无法定制。 2026款Model X通过动力系统、内饰、线束、冷却系统及一体化压铸等多项工程改进，成功实现减重400磅。 特斯拉在加拿大阿尔伯塔省Red Deer启动V4超级充电站建设，已安装12个325kW充电桩，旨在提升当地充电容量。 特斯拉公布了2025年第三季度超级充电站投票获胜地点，全球多个新站点将投入建设，并已启动第四季度投票。 SpaceX新型Starship V3助推器Booster 18在德克萨斯州星际基地进行地面压力测试时遭遇结构性失效，可能导致V3计划延误。 Piper Sandler重申特斯拉500美元的目标价，其分析师认为FSD V14的驾驶表现已堪比甚至优于普通人类司机。 * 特斯拉计划建设名为TeraFab的AI芯片工厂，以垂直整合AI芯片制造，应对AI5芯片的巨大需求，AI5芯片预计2027年量产。
