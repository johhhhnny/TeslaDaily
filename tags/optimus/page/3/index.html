特斯拉日报 2026-05-19

特斯拉将于5月20日（太平洋时间）举行Model S/X Signature Edition交付活动，标志两款旗舰车型时代的终结。 美国众议院提议对电动车征收每年130美元的联邦道路税，对插电混动车征收35美元。 特斯拉发布2026.14春季更新，引入新能耗图、盲点警告、“Hey Grok”及Unreal Engine集成等。 前特斯拉AI总监Andrej Karpathy宣布加入Anthropic，将专注于大型语言模型（LLM）的预训练研究。 埃隆·马斯克预测机器人出租车到今年底将在美国广泛普及，并在未来十年内AI将驾驶90%的里程。 SpaceX宣布其最新星舰v3计划于5月21日（周四）进行首次发射。 * 埃隆·马斯克表示将对OpenAI诉讼案的程序性驳回提起上诉。

特斯拉日报 2026-05-16

特斯拉Model Y在北美市场迎来两年内首次价格上涨，部分高端配置涨价500至1000美元，入门级车型价格保持不变。 FSD v14.3版本即将与2026年春季软件更新功能合并，为用户带来全面升级的座舱体验和更先进的自动驾驶能力。 特斯拉新获得一项专利，揭示了FSD V14实现“拟人化”驾驶风格的秘密，采用“分层节点图”AI架构取代传统暴力计算。 特斯拉向NHTSA披露了两起发生在奥斯汀的Robotaxi低速事故详情，两起事件均涉及遥操作员介入。 * 埃隆·马斯克在X上确认SpaceX正通过调整治理结构和薪酬框架，确保其领导层专注于火星殖民的长期宏伟目标。

特斯拉日报 2026-05-15

App更新： 特斯拉App 4.57发布，新增家长控制功能（可禁用浏览器、游戏、影院），引入动画车辆徽章，并在能源状态显示“Powered by Grok”并支持用户反馈。 Cybercab测试： 一辆Cybercab测试车辆被发现搭载Starlink Mini卫星天线，预计将增强其网络连接可靠性及数据上传能力。 FSD改进： FSD v14.3（或v14.2）更新，当驾驶员分心时，车辆将主动寻找安全地点靠边停车，而非原地制动。 Robotaxi事故： 特斯拉向NHTSA披露两起由远程操作员远程控制Robotaxi时发生的低速碰撞事故。 Cybercab基建： 特斯拉在拉斯维加斯规划建设36,000平方英尺的Cybercab专用洗车维护中心。 Cybertruck新用途： 哈萨克斯坦国家卫队选用Cybertruck作为移动指挥控制车，服务于突厥国家非正式峰会。

特斯拉日报 2026-05-14

- Robotaxi基础设施: 特斯拉向拉斯维加斯提交了一份关于建设专用Cybercab洗车设施的许可申请。 - 技术专利: 特斯拉获得一项电磁悬挂座椅的新专利，有望提升乘坐舒适性。 - 工厂扩产: 柏林超级工厂宣布追加2.5亿美元投资，将4680电池年产能提升至18 GWh，并计划自7月起将Model Y产量提高20%。 - 法律进展: 特斯拉在与Charge Fusion Technologies的超级充电专利纠纷中取得部分胜利，一项涉及气候控制的专利主张被撤销。 - 行业动态: 本田宣布放弃2040年全电动汽车目标，转而侧重混合动力车型。 - SpaceX动态: 埃隆·马斯克解释达美航空拒绝星链车载Wi-Fi的原因是达美坚持使用其自有门户，而非星链的无缝体验。

特斯拉日报 2026-05-13

特斯拉发布新版自动软件更新功能，允许车辆在满足条件时于凌晨2点自动安装更新。 一辆特斯拉Cybercab在公共道路上遭遇首次已知事故，系被追尾所致。 特斯拉与SpaceX合资成立TERAFAB，计划在德克萨斯州建设价值1190亿美元的半导体制造和先进计算设施。 特斯拉推出售价210美元的远程电表，以简化家庭充电安装并实现动态功率管理。 特斯拉在加拿大推出Supercharger 3D站点地图功能，提升充电体验。 特斯拉FSD在德国柏林超级工厂内部累计自动驾驶93,000英里，用于车辆转运。 Rivian旗下工业机器人公司Mind Robotics完成4亿美元新一轮融资，总融资超10亿美元。 埃隆·马斯克证实SpaceX的星链（Starlink）互联网服务已在美国总统专机“空军一号”上投入使用。
