Optimus

特斯拉日报

特斯拉在自动驾驶和人工智能领域的进展持续引领行业，近期宣布FSD（完全自动驾驶）即将迎来重要更新，进一步降低驾驶员的监督要求。随着FSD v14.1.x的陆续推出，埃隆·马斯克在股东大会上表示，根据内部安全统计数据，特斯拉“几乎感到可以允许人们发短信和驾驶”了，并计划在“未来一两个月内”开始放宽监督要求。这一自信源于FSD专用数据（不含Autopilot）显示，过去一年中，FSD使用下的事故率降低了85%，死亡人数减少3.5万，受伤人数减少200万。特斯拉正积极利用这些数据向监管机构证明FSD的卓越安全性，为实现真正意义上的自动驾驶铺平道路。此举无疑是自动驾驶技术发展史上的一个里程碑，有望大幅提升FSD的用户体验和吸引力，进一步巩固特斯拉在该领域的领导地位。然而，能否顺利获得监管机构的批准，以及公众对“脱手”驾驶的接受程度，仍是特斯拉需要面对的挑战和潜在风险，任何安全疑虑都可能对市场产生影响，因此谨慎推进和数据透明度至关重要。
