Optimus

特斯拉日报 2025-11-21

特斯拉FSD (Supervised) V14.2已开始向首批配备AI4硬件的车辆推送，并有望进行“广泛发布”，新版FSD新增高分辨率视觉编码器、多项驾驶行为改进及“自动驾驶统计”菜单。 加拿大市场重新开放Model Y Performance订单，售价C$74,990起，预计2026年3月交付，新车在设计和配置上均有显著升级。 更新版2026 Model S和Model X已引入中国市场，但受中美贸易关税影响，目前仅限库存销售，无法定制。 2026款Model X通过动力系统、内饰、线束、冷却系统及一体化压铸等多项工程改进，成功实现减重400磅。 特斯拉在加拿大阿尔伯塔省Red Deer启动V4超级充电站建设，已安装12个325kW充电桩，旨在提升当地充电容量。 特斯拉公布了2025年第三季度超级充电站投票获胜地点，全球多个新站点将投入建设，并已启动第四季度投票。 SpaceX新型Starship V3助推器Booster 18在德克萨斯州星际基地进行地面压力测试时遭遇结构性失效，可能导致V3计划延误。 Piper Sandler重申特斯拉500美元的目标价，其分析师认为FSD V14的驾驶表现已堪比甚至优于普通人类司机。 * 特斯拉计划建设名为TeraFab的AI芯片工厂，以垂直整合AI芯片制造，应对AI5芯片的巨大需求，AI5芯片预计2027年量产。

特斯拉日报 2025-11-17

市场动态： Stifel将特斯拉目标股价上调至$508，TD Cowen重申$509目标价；野村资管增持特斯拉4.2%，成为其第十大持仓；Peter Thiel大幅减持股份。 销售策略： 特斯拉推出Model Y/Model 3 Standard版；美国市场Model Y租赁计划实现零首付并提供免费升级。 自动驾驶： Robotaxi测试车首次在宾夕法尼亚州被发现；Robotaxi又发生3起碰撞，总数达7起；特斯拉推出FSD (Supervised) 实时安全仪表板，日均行驶约1440万英里。 机器人： 特斯拉设定Optimus机器人量产价格目标$20,000，计划2026年开始Gen 3生产并实现极速产能爬坡。 供应链： 特斯拉正推动供应商削减用于美国汽车的中国制造零部件。 充电网络： 超级充电站“实时定价”策略扩展到美国另外550个站点。 法律诉讼： 特斯拉解决另一起Autopilot碰撞诉讼；起诉北达科他州直销禁令。 其他： 埃隆·马斯克暗示可能撰写自传；2025年假日更新即将推出。

2025-11-17

特斯拉日报 2025-11-14

FSD相机清洁服务： 特斯拉针对前置摄像头玻璃内侧雾化问题，通过FSD v14.1.7更新（2025.38.8.7版本）推出车辆检测警报，并提供免费的精确清洁服务。 FSD安全报告发布： 特斯拉公布FSD（监管版）详细安全数据，声称其在北美地区发生重大和轻微碰撞的里程数是人类驾驶的7倍以上。 Robotaxi竞争升级： 特斯拉CEO埃隆·马斯克回应Waymo的2500辆Robotaxi车队规模为“新手级别”，并重申特斯拉将在年底前大幅扩张其在奥斯汀和湾区的Robotaxi车队。 FSD推荐计划更新： 特斯拉在美国和加拿大更新了推荐计划，引入了推荐他人完成FSD（监管版）试驾即可获得积分的新奖励。 投资者信心： 亿万富翁投资者罗恩·巴伦重申其对特斯拉和SpaceX的长期持有承诺，将其称为“一生投资”，并透露其个人净资产的40%投资于特斯拉。 第三方屏幕发布： Enhance Auto推出S3XY Dash，一款支持Apple CarPlay、Android Auto并显示深度车辆数据的定制化显示器。 圣诞模式更新预告： 刷新版2026款Model S和Model X车辆暂时缺少“圣诞模式”，但特斯拉预告该功能将“很快推出”，暗示底层可视化引擎升级。 Starlink航空合作： 消息称阿联酋航空有望与SpaceX达成Starlink机上Wi-Fi合作协议，进一步扩大Starlink在商业航空领域的影响力。
