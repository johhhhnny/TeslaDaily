特斯拉日报 2025-11-25

- 特斯拉Autopilot系统累计行驶里程突破100亿公里。 - 特斯拉Autosteer将取消“Beta”标签，并推出更智能的驾驶员注意力监控系统。 - 特斯拉诊断软件ToolBox 3解锁FSD电脑升级配置，或预示HW3硬件升级。 - 特斯拉FSD v14.2推出“FSD里程统计”功能，并改进驾驶体验。 - 埃隆·马斯克表示传统汽车制造商对FSD授权仍犹豫不决。 - 特斯拉瑞典工厂在哥德堡面临新的工会喷漆服务封锁。 - 特斯拉在挪威提前一个月打破年度销量记录。 - 特斯拉新增“排除家庭”选项，优化驾驶室过热保护/无空调功能。 - The Boring Company拉斯维加斯机场隧道预计2026年Q1开放，将使用特斯拉车辆。 - Perrone Robotics起诉特斯拉Autopilot系统侵犯专利。

2025-11-25

特斯拉日报 2025-11-24

FSD国际拓展与监管： FSD (Supervised) v14.1.4已在韩国部署；内华达州批准特斯拉自动驾驶车辆运营；荷兰RDW监管机构确认2026年2月为FSD在欧演示合规目标，但强调非保证批准。 AI芯片进展： 特斯拉AI5芯片设计接近定稿，AI6已启动开发，目标每年推出新芯片设计并量产。 传统车企FSD授权： 马斯克称传统车企对许可特斯拉FSD不感兴趣或提出不可行条件，警告其未来将受损。 Model X制造： Model X通过数百项改进，成功减重近400磅。 能源储能： 澳大利亚Golden Plains风电场将部署168个Megapack 2 XL电池系统。 充电网络体验： 特斯拉迅速回滚Supercharger导航显示调整，并计划在12月进行更完善的UI更新。 挪威市场表现： 特斯拉11月在挪威销量强劲，全年有望打破大众历史纪录；瑞典市场表现挣扎，工会抗议持续。 租车服务： 特斯拉在美国多州扩展租车计划，提供包含FSD、免费超充和无限里程的全包式服务。 法律诉讼： 华盛顿州一家庭就2018年“意外加速”致死事故起诉特斯拉。 Cybertruck应用： 拉斯维加斯警方正式启用10辆改装版Cybertruck作为巡逻车。 第三方充电设施：** 加拿大BC Hydro推出首个移动式EV快充站，采用高架供电方式简化部署。

2025-11-24

特斯拉日报 2025-11-21

特斯拉FSD (Supervised) V14.2已开始向首批配备AI4硬件的车辆推送，并有望进行“广泛发布”，新版FSD新增高分辨率视觉编码器、多项驾驶行为改进及“自动驾驶统计”菜单。 加拿大市场重新开放Model Y Performance订单，售价C$74,990起，预计2026年3月交付，新车在设计和配置上均有显著升级。 更新版2026 Model S和Model X已引入中国市场，但受中美贸易关税影响，目前仅限库存销售，无法定制。 2026款Model X通过动力系统、内饰、线束、冷却系统及一体化压铸等多项工程改进，成功实现减重400磅。 特斯拉在加拿大阿尔伯塔省Red Deer启动V4超级充电站建设，已安装12个325kW充电桩，旨在提升当地充电容量。 特斯拉公布了2025年第三季度超级充电站投票获胜地点，全球多个新站点将投入建设，并已启动第四季度投票。 SpaceX新型Starship V3助推器Booster 18在德克萨斯州星际基地进行地面压力测试时遭遇结构性失效，可能导致V3计划延误。 Piper Sandler重申特斯拉500美元的目标价，其分析师认为FSD V14的驾驶表现已堪比甚至优于普通人类司机。 * 特斯拉计划建设名为TeraFab的AI芯片工厂，以垂直整合AI芯片制造，应对AI5芯片的巨大需求，AI5芯片预计2027年量产。

2025-11-21

特斯拉日报 2025-11-20

- 特斯拉Robotaxi获亚利桑那州全州运营批准，是继德州奥斯汀和加州湾区后的第三个运营州。 - FSD在欧洲推出迹象显现，更新代码以符合当地严格监管要求，如去除“beta”标签、增强驾驶员监控和准备按国界管理功能可用性。 - 特斯拉下一代AI5芯片将延迟至2027年中期，但Cybercab将按计划使用AI4硬件发布。 - 特斯拉正式在哥伦比亚开放Model 3和Model Y订单，以具有竞争力的价格进入南美洲的第二个市场，并计划2026年初交付。 - 首个“Supercharger for Business”站点在佛罗里达州Land O’ Lakes开业，标志着特斯拉与第三方合作扩展充电网络的商业模式启动。 - 欧洲超级充电站支付体系升级，开始支持34家充电卡提供商，未来数周内将扩展至70多家，极大便利车队司机。 - Cybertruck越野灯条召回问题已获硬件修复方案，通过结合粘合剂与机械支架解决松动或脱落问题。 - 马斯克在X平台亲自驳斥了关于其2025年薪酬包和某次宴会言论的“不实报道”。 - Q3 2025超级充电站投票结果公布，加拿大不列颠哥伦比亚省的Courtenay和阿尔伯塔省的Banff获胜，将新建超级充电站。 - 特斯拉租赁计划正在积极扩张，继加州之后，计划在德克萨斯州、田纳西州和马萨诸塞州推出该服务。

2025-11-20

特斯拉日报 2025-11-19

特斯拉App 4.51版本更新，新增Powerwall沉浸式天气可视化、商城商品送礼功能、FSD受影响警报及希伯来语支持。 特斯拉Robotaxi应用向北美所有iOS用户开放，取消等待名单，并引入清洁费和行程评分机制。 特斯拉获得亚利桑那州带安全驾驶员的Robotaxi运营许可。 更新版Model Y在Euro NCAP碰撞测试中获得五星评级，安全辅助软件表现出色。 特斯拉全球超级充电桩数量突破75,000个，在过去不到五个月内新增5,000个。 Stellantis集团正式宣布采纳特斯拉NACS充电标准，并将于2026年在北美、2027年在日韩推行。 特斯拉Model Y在中国市场2025年订单已基本售罄，显示强劲需求。 特斯拉在哥伦比亚启动首次客户试驾活动，预示即将正式进驻该南美市场。 埃隆·马斯克表示xAI的Grok 4.1愿为苹果Siri提供AI支持。 特斯拉中国起诉30余家企业，追讨未达里程要求的电动车补贴。洛杉矶特斯拉Diner餐厅将于明年1月转型为全服务餐厅。

2025-11-19

特斯拉日报 2025-11-18

- 欧洲Supercharger充电站开始支持包括34种主流服务商的第三方电动汽车充电卡，未来数周内将增加40余种。 - 特斯拉Robotaxi服务今日起向美国和加拿大所有iOS用户全面开放，覆盖奥斯汀和旧金山湾区。 - 埃隆·马斯克确认下一代AI5芯片量产将推迟至2027年中，Cybercab将搭载AI4硬件于2026年4月投产。 - 特斯拉与Syrah Resources的石墨供应协议因技术问题再次延期，最终资质认定截止日期为2026年2月9日。 - 特斯拉已开始推送2025.44软件更新，为即将到来的年度假日更新做准备，包含Dashcam和Cabin Overheat Protection改进。 - 加州法院驳回了针对特斯拉弗里蒙特工厂的涉及6,000名黑人员工的种族歧视集体诉讼。 - 亚马逊旗下的Zoox和Alphabet旗下的Waymo在自动驾驶领域均取得新进展，分别在旧金山和迈阿密开放或拓展了服务。 - 有乘客在旧金山湾区搭乘特斯拉Robotaxi时，报告安全驾驶员在驾驶过程中多次睡着。 - 飞迪拜航空宣布将从2026年起在其全部机队上部署SpaceX的Starlink机载Wi-Fi服务。
